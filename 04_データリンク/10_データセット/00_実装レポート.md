## 🔑 主な実装特徴

### 1. JAXA衛星データの統合 ✨

```python
# JAXA Earth API Python SDKを直接利用
from jaxa.earth import je

# 特徴:
✅ リアルタイム性: 3-4日遅延で観測可能
✅ 解像度: ~1km (L2), ~10km (L3)
✅ 自動チャンク処理: 100日制限に対応
✅ 領域平均: 有明海・八代海の自動計算
```

### 2. 統一スキーマへの統合

```
複数ソース → 日時×地点でキー統合 → marine_daily_features.csv

マージ方式:
- 日付キー: 完全マッチ（YYYY-MM-DD）
- 地点キー: JMA駅 × 6地点
- 時系列: 2025-01-01～2026-05-11（496日間）
- クロロフィル: 共通の領域平均値を全地点に適用
```

### 3. 自動チャンク処理

```
問題: JAXA Earth APIは最大100日分のみ取得可能
解決: 自動的に100日単位に分割して処理

16ヶ月 = 488日
  → Chunk 1: 2025-01-01～2025-04-10 (100日)
  → Chunk 2: 2025-04-11～2025-07-19 (100日)
  → Chunk 3: 2025-07-20～2025-10-28 (100日)
  → Chunk 4: 2025-10-29～2026-02-06 (100日)
  → Chunk 5: 2026-02-07～2026-05-11 (93日)

処理時間: 約10-15分（全期間）
```
