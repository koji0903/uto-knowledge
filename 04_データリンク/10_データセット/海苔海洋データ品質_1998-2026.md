# 海況観測データ品質メモ 1998-2026

## 基本方針

このメモは、熊本市海況観測データを分析・アプリ利用する際の品質上の注意を残すためのノートである。CSV本体は原本として保持し、アプリや分析では異常値処理済みの日次集計・派生指標を使う。

## 取得期間の注意

| データ | 取得リクエスト期間 | 実際に使える期間 | 注意 |
| --- | --- | --- | --- |
| 水質 | 1998-01-01 to 2026-05-10 | 2001-08 to 2026-05-10 | 1998-2000は水質データが実質空 |
| 潮位 | 1998-01-01 to 2026-05-10 | 1998-01-01 to 2026-05-10 | 水質とは粒度・意味が異なる |

## 異常値・欠測の注意

| 地点 | 注意点 |
| --- | --- |
| 河内 | 比重に異常高値が多い。比重は主要判断指標にしない |
| 松尾 | 低塩分イベントが長く出る年がある |
| 小島 | 比較的安定しているが、高水温化の影響は大きい |
| 沖新 | 低塩分とDOの確認が必要 |
| 新港南 | 低塩分・低DOリスクが出やすい |

## アプリ投入前の推奨処理

- 原本CSVは変更しない。
- 日次集計テーブルを別途作成する。
- センサー停止疑い、欠測、異常値をフラグ化する。
- 比重は当面、表示優先度を下げる。
- 水温、塩分、DO mg/Lを主要指標にする。
- 低塩分や低DOは単発値ではなく、連続日数で見る。
- 採苗・張り込み判断には3日移動平均を使う。

## 除外・フラグ候補

| 条件 | 扱い |
| --- | --- |
| 水温1℃以下 | センサー異常・欠測候補としてフラグ |
| DO 0 | センサー停止・欠測候補としてフラグ |
| 塩分5‰未満 | 強い出水または異常値候補としてフラグ |
| 比重35超 | 異常値候補としてフラグ |
| 同一値が長時間連続 | センサー停止候補としてフラグ |
