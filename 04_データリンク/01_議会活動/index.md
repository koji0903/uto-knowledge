## 紐づけ方針

議員活動は単なる時系列ログではなく、以下の軸で宇土OSへ接続する。

| 軸 | 接続先 |
| --- | --- |
| どの課題か | 宇土市政課題レイヤ |
| どの政策か | 宇土市政策レイヤ |
| どの財源・施設に関係するか | 財政・インフラレイヤ |
| どの機能OSに関係するか | 各機能OS（教育、産業、移住、子育て、RMO等） |
| 議会上の動き | 議会議事、委員会、一般質問等 |
