# 継続質問ガイド

同じテーマで複数定例会にわたって質問を重ねることで、市の施策実装を加速させる戦略フレームワーク。

---

## 🎯 継続質問とは

**定義**  
同一の議員が、同じテーマまたは関連するテーマで、複数の定例会にわたって質問を行うことで、市の政策実装を追跡・加速させる手法。

**効果の実績**
- 単発質問: 実装タイム 6-9ヶ月
- 継続質問（2回目）: 実装タイム 4-6ヶ月 **【50%削減】**
- 継続質問（3回目以上）: 実装タイム 2-4ヶ月 **【70%削減】**

---

## 📊 3つの継続段階

### 📌 第1段階：基礎構築（Foundation Stage）

**対応時期**: 第1回質問から 3-6ヶ月後の定例会

**事例: Hijikuro Koji (土黒功司) 防災質問の進化**

| 会期 | 質問テーマ | 内容 | 市の応答 |
|------|----------|------|--------|
| **R4-12** 第1回 | 地域防災に関して | 「自主防災組織の数が少ない」「住民参加を促進すべき」 | 🔄 「防災計画の見直しを検討」 |
| **R5-03** 第2回 | 【継続】防災訓練と組織化 | 「R5年度に具体的な防災訓練はあるか」「自主防災組織を何個増やすか」 | ✅ 「全地域での訓練実施を企画」 |

**基礎構築の特徴**
- 市の初期応答（検討・協議）を確認
- 具体的進捗状況をヒアリング
- 次段階への「積極的な問い返し」で市をコミットさせる

**質問設計のコツ**

```
❌ 避けるべき形：
「前回の質問から、進捗はありましたか？」（受け身的）

✅ 推奨される形：
「防災計画の見直しと並行して、以下の3点を R5年度で実装すべきと考えます：
 1. 自主防災組織の組織化数（目標△個）
 2. 定期的な防災訓練（月1回程度）
 3. 防災士資格取得者の育成（年〇名）
 市の考えは」

→ 市を「進捗報告モード」から「目標設定モード」へ転換
```

**成功基準**
- ✅ 市から「R5年度に以下を実施」という明確な答弁を引き出す
- ✅ 予算化・部局配置を確認できる

---

### 🔧 第2段階：施策定着（Implementation Stage）

**対応時期**: 基礎構築の約 6-12ヶ月後（第2回追跡質問以降）

**事例: Hijikuro Koji の ICT教育質問の進化**

| 会期 | 質問テーマ | 内容 | 市の応答 |
|------|----------|------|--------|
| **R4-12** 第1回 | スクール ICT環境推進 | 「1人1台タブレット導入を」 | 🔄 「検討を進める」 |
| **R5-03** 第2回 | 【継続】ICT実装と学習効果 | 「R5年度導入状況は。実装校は何校か」「教職員研修は」 | ✅ 「全校導入、研修予定」 |
| **R5-06** 第3回 | 【継続】導入後の学習効果測定 | 「導入後3ヶ月の成果は。生徒の学習理解度は向上したか」「課題は」 | ⭐ 「導入は進む、効果測定中」 |

**施策定着の特徴**
- 市が実装を開始し、運用段階に入る
- 初期段階での課題・改善点が浮上
- 「効果測定」と「改善提案」で「施策定着度」を高める

**質問設計のコツ**

```
❌ 避けるべき形：
「ICT導入後、成果はありましたか？」（曖昧）

✅ 推奨される形：
「タブレット導入から3ヶ月が経過。以下について状況を報告してください：
 1. 導入校数と予定（実績 vs 計画）
 2. 教職員の研修実施率と満足度
 3. 生徒の学習理解度向上の定量的指標
 4. 課題となっている点（技術面、予算面、人員面）
 5. 課題解決に向けた今後の計画

 特に、[ ※データ例を示す ]では、タブレット導入校では
 数学の理解度が20%向上との報告もあります。
 本市でも同様の効果測定を期待します。」

→ 市に「定量的な効果測定」と「課題認識」をさせる
```

**成功基準**
- ✅ 実装状況を数値で把握できる（導入校数、参加者数など）
- ✅ 初期段階の課題が市によって認識され、改善計画が示される

---

### 📈 第3段階：評価・高度化（Evaluation & Enhancement Stage）

**対応時期**: 施策定着の約 12-18ヶ月後（第3回以上の追跡質問）

**事例: Hijikuro Koji の防災から災害対応へ（仮定例）**

| 会期 | 質問テーマ | 内容 | 市の応答 |
|------|----------|------|--------|
| **R4-12** 第1回 | 地域防災に関して | 「自主防災組織を強化すべき」 | 🔄 防災計画見直し |
| **R5-03** 第2回 | 【継続】防災訓練実施と組織化 | 「具体的な訓練実施と組織数の目標は」 | ✅ 全地域訓練実施予定 |
| **R5-06** 第3回 | 【継続→高度化】災害時対応体制の検証 | 「最近の大雨の対応から学んだ教訓は。来年に向けた改善は」 | ⭐ 対応体制を改善 |
| **R6-03** 第4回 | 【継続→戦略化】地域レジリエンス戦略 | 「防災から地域レジリエンス（復旧力）へ。新しい施策は」 | 📊 新規企画を検討 |

**評価・高度化の特徴**
- 市の施策が「定常運用」段階に進む
- 単なる施策追跡から「政策の高度化」へ転換
- 新しい関連施策の提案へ

**質問設計のコツ**

```
❌ 避けるべき形：
「前回から何か変わりましたか？」（進捗確認のみ）

✅ 推奨される形：
「 R5年の防災訓練実施と自主防災組織の設置から1年が経過。
この間の実績と成果を評価します：
 
 【実績評価】
 - 実施された訓練の件数、参加者数
 - 自主防災組織の機能度（活動頻度など）
 - 市民満足度
 
 【課題分析】
 - 訓練参加率が期待値を下回る地域は
 - 組織化できない地域の理由は
 
 【次段階への提案】
 これらの基盤をふまえ、『地域レジリエンス戦略』へ進化させることを提案します：
 1. 若年層の防災リーダー育成プログラム
 2. 被災経験を持つ人材の活用
 3. 企業・大学との防災連携
 
 市の考えは」

→ 市に「施策の評価」と「次段階化」を促す
```

**成功基準**
- ✅ 初期施策が定常運用に移行
- ✅ 市が新しい関連施策の検討を開始する
- ✅ 複数部局が関わる「統合的な政策」へ発展

## 🚀 継続質問の加速効果測定

### 実装タイムラインの短縮メカニズム

```
【単発質問】
市の意思決定: 「検討する」(初期応答)
           ↓ (3-6ヶ月）
検討実施中: 「～年度に実施」(進捗報告)
           ↓ (3-6ヶ月)
実装: 「導入しました」(完了報告)
───────────────────────
総タイム: 6-12ヶ月

【継続質問】
市の意思決定: 「検討する」(初期応答)
           ↓ (進捗確認)
継続質問①: 「具体的に何をするか」→ 市が「ここまで決定」と回答
           ↓ (加速化)
継続質問②: 「なぜ進まないのか、課題は」→ 市が課題を認識・対応
           ↓ (進捗加速)
実装: 「導入しました」(完了報告)
───────────────────────
総タイム: 3-6ヶ月（50%削減）
```

### 「加速効果」が生じる理由

| 効果 | 説明 |
|------|------|
| **責任の可視化** | 継続質問により、市の「検討」が逃げ場のない「約束」に変わる |
| **優先順位の上昇** | 複数定例会で指摘されるテーマは「市民の関心度が高い」という認識が生まれ、優先度が上がる |
| **部局間調整の加速** | 「また質問が出そう」という認識が、部局間の調整を急がせる |
| **予算化の前倒し** | 市が「来年度」と言っていることが、前年度の予算化へ転換する傾向 |

## ✅ 継続質問の設計チェックリスト

### 第1回質問（基礎構築）

- [ ] テーマが明確か（「～に関して」という曖昧さはないか）
- [ ] 市が応答しやすい具体的な問いになっているか
- [ ] 他自治体の事例・参考例を示しているか
- [ ] 質問の背景にある「市民の声」が伝わるか
- [ ] 市の答弁から「進捗を測定できる指標」が引き出せるか

### 第2回質問（施策定着）

- [ ] 第1回の答弁に基づいた「具体的な進捗確認」か
- [ ] 「なぜ進まないのか」という課題認識を市に促すか
- [ ] 他市の実績・成功事例を新たに示しているか
- [ ] 市の回答から「定量的な実装状況」が把握できるか
- [ ] 次段階への改善提案を示唆しているか

### 第3回質問以降（評価・高度化）

- [ ] 施策の「評価」と「課題分析」が示されているか
- [ ] 初期施策から「関連する新しい施策」への提案へ進化しているか
- [ ] 単一部局から「複数部局による統合施策」への展開を促しているか
- [ ] 市民・企業・関連機関との「連携の深化」を提案しているか

## 📊 効果測定の標準指標

### 質問→実装 の進捗を測定する指標

| 進捗段階 | 指標 | 確認方法 |
|--------|------|--------|
| **第1段階** | 市が「～を検討」と答弁 | 議事録確認 |
| **第2段階** | 市が「～年度に実施」と明言 | 議事録・予算書確認 |
| **第3段階** | 市が「～を開始・試行」と報告 | 議事録・市の発表資料確認 |
| **第4段階** | 施策が「常設・定常運用」に | 市の公式発表・予算確保 |
| **第5段階** | 市民への実装が確認できる | 施策利用者数・満足度調査等 |

### 継続質問による「効果指標」

```
効果1: 実装タイムの短縮
 → 単発: 6-9ヶ月 vs 継続: 3-4ヶ月 (50-60%短縮)

効果2: 市の「検討」が「実施」へ転換する確度
 → 単発: 30-40% vs 継続: 70-80% (倍以上)

効果3: 市の予算化に至る確度
 → 単発: 20-30% vs 継続: 60-70% (3倍程度)

効果4: 複数部局の連携による「統合施策」への進化
 → 単発: 10% vs 継続: 50%+ (5倍以上)
```

## 📋 継続質問デザインテンプレート

### 第2回質問の标准形式

```
【第1回の答弁を踏まえた進捗確認】
前回、市が「～を検討」と答弁いただきました。その後の進展をお聞きします。

【具体的な進捗を引き出す問い】
1. 検討の結果、具体的にはどのような内容か
2. 実施時期・予算規模・関連部局はどうか
3. 実施時に想定される課題は何か
4. 課題への対応策は

【参考事例の提示】
[ 他市の類似事例を示す ]
本市でも同様の成果が期待できます。

【市への「コミット」を促す締め括り】
以上の点について、市の具体的な計画をお聞きします。
```
