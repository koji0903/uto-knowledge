## 🎯 利用方法

1. **テーマを選択** - 上記のテーマ別リンクから目的のテーマを選択
2. **定例会ごとの進捗を確認** - 各定例会での質問・市の回答・進捗状況を確認
3. **関連する質問分析ノートを参照** - [[../10_質問分析|質問別分析ノート]]にリンクして詳細を確認

## 📋 テーブル構造

各政策追跡ファイルは以下の構造を採用：

| 列 | 説明 |
|----|------|
| 定例会 | R4-12、R5-03 など |
| 質問者 | 議員名 |
| 質問テーマ | 具体的な質問内容の要約 |
| 市の回答 | 執行部の対応・方針 |
| 進捗状況 | ✅ 実行中 / 🔄 検討中 / ⏳ 計画段階 / ✓ 完了 |
| 関連ノート | 詳細分析へのリンク |
