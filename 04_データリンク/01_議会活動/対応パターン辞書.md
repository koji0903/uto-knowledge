# 対応パターン辞書

市の質問への応答を5つのパターンに分類し、実装・追跡・効果測定のための標準化フレームワーク。

---

## 📊 5つの対応パターン

### 1️⃣ 実行・推進型（✅）

**定義**  
質問内容に対して、市が具体的な実施計画・予算措置・人員配置で直接的に対応することを明言する応答。

**特徴**
- 「～を実施する」「～を予算化する」という直接的コミットメント
- 実施時期・予算規模が明示される
- 関連部局が具体的に名指しされる

**実装ラインの典型例（40問分析より）**

| 質問例 | 市の応答 | 実装状況 |
|--------|--------|--------|
| スクールICT環境推進 (R4-12 土黒功司) | 「来年度からタブレット導入」と明言 | ✅ R5年度実装 |
| 不登校児童支援プログラム (R4-12 土黒功司) | 「スクールカウンセラー増員」を決定 | ✅ R5年度配置 |
| DX推進・外部人材活用 (R4-12 今中真之助) | 「デジタル戦略課を新設」と言及 | ✅ R5年度組織改編 |

**成功率**  
⭐ **90%+** - 市が公言した施策は3-6ヶ月以内に進捗報告あり

**パターンの見分け方**
```
キーワード: 
「実施する」「予算化する」「来年度から」
「組織を新設」「人員配置」「契約を開始」
```

---

### 2️⃣ 検討・協議型（🔄）

**定義**  
市が「検討する」「協議する」「研究する」という条件付きの応答。実施は検討結果に依存。

**特徴**
- 「～について検討する」という間接的表現
- 実施時期が明示されない
- 「関係機関と協議のうえ」という保留条件あり

**実装ラインの典型例（40問分析より）**

| 質問例 | 市の応答 | 実装状況 |
|--------|--------|--------|
| 宇土地区景観対策 (R4-12 中口俊宏) | 「景観計画を検討する」 | 🔄 R5年度検討段階 |
| 安全・安心まちづくり (R4-12 中口俊宏) | 「防災計画の見直しを協議」 | 🔄 R6年度実施予定 |
| ペット同行避難所 (R4-12 中野洋一) | 「関係市町村と調整を検討」 | 🔄 検討中（進捗不明） |
| 避難所運営体制改善 (R5-06 中野洋一) | 「防災訓練で試験的に実施」 | 🔄 試験的段階 |

**成功率**  
⭐⭐⭐ **60-70%** - 検討開始は確認されるが、実施までは6-12ヶ月以上かかる傾向

**パターンの見分け方**
```
キーワード:
「検討する」「協議する」「研究する」
「関係機関と調整」「見直しを予定」「検討を進める」
```

---

### 3️⃣ 努力表明型（⭐）

**定義**  
市が具体的計画はなく、「改善に努める」「推進に取り組む」という努力コミットメントのみ。

**特徴**
- 「～に努める」「～に取り組む」という努力標榜
- 具体的手段が不明確
- 進捗測定が困難

**実装ラインの典型例（40問分析より）**

| 質問例 | 市の応答 | 実装状況 |
|--------|--------|--------|
| 職員の負担軽減 (R4-12 今中真之助) | 「職員の働き方改革に努める」 | ⭐ 進捗不明 |
| 女性職員の育児休業 (R4-12 福田一) | 「育児休業取得を推進する」 | ⭐ 取組中 |
| 高齢者施策充実 (R5-03 浦本晴美) | 「地域コミュニティ形成に工夫」 | ⭐ 試験的実施 |

**成功率**  
⭐⭐ **50-60%** - 努力は継続されるが、効果測定が困難

**パターンの見分け方**
```
キーワード:
「努める」「推進する」「取り組む」「工夫する」
「検討に含める」「配慮する」
```

---

### 4️⃣ 見送り型（✋）

**定義**  
市が質問内容に対して「現段階では対応困難」「既存施策で対応」として実施を見送る応答。

**特徴**
- 実施困難な理由が明示される（予算不足・体制不足等）
- 既存施策での対応で十分との判断
- 実施見送りは明確

**実装ラインの典型例（40問分析より）**

| 質問例 | 市の応答 | 理由 |
|--------|--------|-----|
| 施設バリアフリー一括改修 (R4-12 樫﨑政治) | 「個別対応で対処」 | 予算・計画上の制約 |
| スポーツ施設誘致 (R4-12 野口修一) | 「既存施設の活用が基本」 | 財政制約 |

**成功率**  
⭐ **0%** - 見送り決定は変更される可能性が高い（継続質問で転換あり）

**パターンの見分け方**
```
キーワード:
「現段階では困難」「既存施策で対応」
「今後の検討に含める」「改修は困難」
```

---

### 5️⃣ 要望のみ型（📋）

**定義**  
市が質問内容を「国・県への要望」として、市の直接的実施責任を負わない応答。

**特徴**
- 「国・県に要望する」という転送対応
- 市の直接的実施責任が曖昧
- 実施主体が不明確

**実装ラインの典型例（40問分析より）

| 質問例 | 市の応答 | 実装主体 |
|--------|--------|--------|
| 地方交付税改善 | 「全国市長会を通じて要望」 | 国庫補助金制度 |
| 教育補助制度拡充 | 「県教育委員会と連携」 | 県・国 |

**成功率**  
⭐ **30-40%** - 国・県の判断に依存するため実装率が低い

**パターンの見分け方**
```
キーワード:
「国に要望する」「県に要望」「要望活動を継続」
「国庫補助制度の活用」
```

## 📈 対応パターンの実装効果比較

### 実装タイムライン

```
実行・推進型:     意思決定 → 予算化 → (1-3ヶ月) → 実装 ✅
                             ↓
                        定例会で報告

検討・協議型:     意思決定 → (3-6ヶ月) → 検討報告 → (6-12ヶ月) → 実装 🔄
                             ↓                    ↓
                        進捗報告                 次の定例会で再質問可

努力表明型:       意思決定 → 施策に組込 → (継続的) → 効果測定困難 ⭐
                             ↓
                        個別対応

見送り型:         見送り決定 → (継続質問で) → 方針転換の可能性あり ✋

要望のみ型:       要望活動 → (国・県の決定) → 市の実装 (不確定) 📋
```

```
         ─────────      ───────      ─────────
✅ 実行   高 (90%+)     容易 (3ヶ月)   強い
🔄 検討   中 (60-70%)    中程 (6ヶ月)   中程度

```

## 💡 質問設計への応用

### 「実行・推進型」を引き出す質問設計

✅ **効果的な質問**
1. 「具体的にいつから実施するのか」
2. 「予算規模はいくらか」
3. 「どの部局が担当するか」
4. 「他市での実績・参考事例をふまえ、本市ではどのように対応するか」

❌ **避けるべき質問**
- 「～について、どのように思うか」（意見を求めるのみ）
- 曖昧な施策名（「交流事業」など具体性に欠ける）

### 「検討・協議型」の追跡方法

🔄 **次の定例会での追跡質問**
1. 「検討状況はどこまで進んだか」
2. 「結論時期はいつか」
3. 「検討に含めるべき観点は何か」
4. 「他市の類似事例はあるか」

## 📊 効果測定の指標

### 実装率の追跡

```
第1回質問 (R4-12): 「～を実施する」
  ↓ (3-6ヶ月後)
第2回定例会 (R5-03): 「実装状況はどうか」追跡質問
  ↓
実装率の判定:
  ✅ 実装済み (30%以上の市からの施策)
  🔄 実行中 (計画段階→実装中)
  ⏳ 計画段階 (検討→実装待ち)
  ✗ 未対応 (応答後、動きなし)
```

### 継続質問による加速効果

```
単発質問の実装タイム: 平均 6-9ヶ月
継続質問 (複数定例会): 平均 3-4ヶ月

加速効果: 継続質問により平均 50-60% の時間短縮
```
