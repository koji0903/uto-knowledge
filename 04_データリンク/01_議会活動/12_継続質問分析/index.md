# 継続質問効果分析一覧

複数の定例会にわたって継続された質問が、施策実現をどの程度加速させたかを分析したナレッジベース。

## 🎯 継続質問とは

同じテーマ・課題について、複数の定例会で質問を続けることで：

1. **市の優先順位上昇** - 繰り返しの質問により重要度が認識される
2. **庁内合意形成加速** - 部局内での意思統一が進む
3. **予算化の前倒し** - 次年度予算ではなく補正予算での対応
4. **施策実現の加速** - 計画より6～9ヶ月早い実現例が多数

## 📈 効果指標の定義

### 施策加速度の測定方法

```
加速期間 = 当初計画実現時期 - 実際の実現時期

例）
- 当初計画: R6年度予算化（R6-03定例会の次年度予算）
- 実際: R5-12定例会での継続質問後、R6-01補正予算で前倒し
- 結果: 2ヶ月の加速
```

### 実現率の算出

```
実現率(%) = 継続質問後に実現した施策数 / 継続質問対象の全施策数

例）継続質問10テーマ中、8テーマが実現 → 80%
```

## 📚 分析フレームワーク

### 継続質問の分類

#### 1. **目標達成型**
- 目的: 特定の施策実現を目指す
- 例: ICT環境推進（完全実現まで継続）
- 特徴: 目標達成後、質問終止

#### 2. **段階推進型**
- 目的: 施策の段階的拡大・高度化を目指す
- 例: 学校給食費補助の拡充（毎年段階的に拡大）
- 特徴: 段階ごとに新たな質問内容に発展

#### 3. **進行監視型**
- 目的: 市の施策実行の監視・督促
- 例: 公共施設再編計画の進捗確認
- 特徴: 市のペース遅延時に注力

#### 4. **方針転換型**
- 目的: 市の政策方針自体の変更を目指す
- 例: 地域経済戦略の根本的転換
- 特徴: 複数年の継続質問を経て初めて方針転換

## 🎯 利用方法

### テーマ別の継続質問効果を調べたい場合
1. テーマ別効果分析表から該当テーマを選択
2. 該当ファイルで継続質問の推移を確認
3. [[../09_政策追跡/index|政策追跡テーブル]]で各定例会の詳細を参照

### 特定議員の継続質問戦略を学びたい場合
1. 議員別効果分析表から該当議員を選択
2. 該当ファイルでテーマ別の継続質問パターンを確認
3. [[../05_議員/index|議員別プロファイル]]で全体活動を把握

### 施策実現と継続質問の相関を確認したい場合
1. [[../09_政策追跡/index|政策追跡テーブル]]で施策の実現時期を確認
2. 該当継続質問分析ファイルで質問との時間関係を追跡
3. 市の加速度指標を算出
