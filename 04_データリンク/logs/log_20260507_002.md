# 複数AI運用のハンドオフ生成とCI検証を整備

## 概要

Claude、Gemini、ChatGPT / Codex が同じVaultを安全に扱えるよう、共通AIコンテキスト、AI別ハンドオフ生成、運用ドキュメント検証を整備した。

## 追加・更新したもの

- [[../../AGENTS|AI運用ガイド]]
- [[../../mcp/ai_profiles/handoff_prompt|AIハンドオフプロンプト]]
- `scripts/generate_handoff_prompt.sh`
- `scripts/start_work.sh --ai claude --task "依頼内容"`
- `scripts/validate_ai_operations_docs.sh`
- [[../decisions/decision_20260507_ai_handoff_operations|複数AI運用の意思決定ログ]]

## 詳細

- `tmp/ai_context.md` を複数AIの共通前提として使う流れを明示した
- AI別の依頼文を `tmp/handoff_<ai>.md` として生成できるようにした
- `claude`、`gemini`、`chatgpt`、`codex` の4種類のハンドオフ生成を検証対象にした
- GitHub Actions `Validate Vault` で、AI運用ドキュメント、DataLink、Obsidianリンク、Firestore dry-runをまとめて確認できる状態にした

## 次アクション

- 実際にClaude / Geminiへ作業を渡す時は `bash scripts/start_work.sh --ai claude --task "依頼内容"` を使う
- Google Drive資料やFirestore反映を伴う作業では、dry-run結果と公開可否を確認してから本番反映する
- AI利用ガイドラインや行政DXの政策実行カードに、運用実績として紐づける
