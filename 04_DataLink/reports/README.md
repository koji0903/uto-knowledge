## 📖 各レポートの利用ガイド

### 長期分析レポート (`analysis_YYYY.md`)

**対象:** 多年度にわたる環境変動の分析

**含まれる内容:**
- 水温の長期トレンド
- 塩分の季節変動
- 溶存酸素の傾向
- 赤潮発生パターン
- 気候変動への影響分析

**推奨用途:**
- シーズン計画の立案
- 長期的な環境トレンド把握
- 他シーズンとの比較分析

### ステータスレポート (`status_report_YYYYMMDD.md`)

**対象:** 最新のシーズン進捗状況

**含まれる内容:**
- 現在の環境状況
- リアルタイム警報
- 収穫推奨情報
- 次期予報

**推奨用途:**
- 農家への意思決定支援
- 週次の操業計画立案
- 緊急対応の判断
