# 議員活動ログ

視察、地域相談、政策提案、会派活動、勉強会、行政ヒアリングなどを記録する場所。

## 運用目的

- 議員活動を宇土OSの政策・課題レイヤへ接続する
- 後から「どの活動がどの政策につながったか」を追えるようにする
- 一般質問、委員会、議会決定との関係を残す

## 記録する項目

| 項目 | 内容 |
| --- | --- |
| 活動日 | 実施日 |
| 活動種別 | 視察、相談、調査、提案、会議など |
| 関係者 | 議員、行政、市民、団体 |
| 関連課題 | [[L2_issue_layer]] のどの課題か |
| 関連政策 | [[L6_policy_layer]] のどの政策か |
| 関連OS | 教育OS、産業OS、RMO OSなど |
| 次アクション | 質問化、資料請求、政策提案など |
