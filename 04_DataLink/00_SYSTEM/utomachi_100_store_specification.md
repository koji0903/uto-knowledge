## 📋 概要

**ウトマチ百貨店**は、宇土市の農水産物・加工品を全国に販売する**地域商社**です。実店舗・ECサイト・ふるさと納税を統合し、生産者の所得向上と市の自主財源化を実現するプラットフォーム兼流通企業です。

**目的：**
- 宇土市の農水産物の高付加価値販売
- 生産者の所得向上（平均 +100%）
- 市の自主財源化（年1.5～3億円）
- 新規雇用創出（50～100名）
- 「宇土」ブランドの全国展開

**事業形態：**
- 株式会社（市が51%出資する公民連携企業）
- または：市の特別会計事業部門

## 🏗️ ビジネスモデル

### 収益構造

```
【販売チャネル別の売上**】

1. 実店舗（ウトマチ百貨店 直営）
   └─ 月売上：800万円
   └─ 利益率：25%
   └─ 月利益：200万円

2. ECサイト（ウトマチ.jp）
   └─ 月売上：1,500万円（全国配送）
   └─ 利益率：18%（配送コスト含む）
   └─ 月利益：270万円

3. ふるさと納税プラットフォーム
   └─ 月売上：2,000万円（返礼品として配送）
   └─ 利益率：15%（返礼品代、配送、手数料等控除後）
   └─ 月利益：300万円

4. 卸売（飲食店・量販店）
   └─ 月売上：1,000万円
   └─ 利益率：12%（薄利多売）
   └─ 月利益：120万円

【月間合計】
├─ 総売上：5,300万円
├─ 総利益：890万円
└─ 年間売上：6.36億円、年間利益：10.68億円
```

### 生産者への還元

```
【生産者への支払いフロー】

生産者が米1,000kg を提供
  ↓
卸売価格：60円/kg ＝ 60万円をウトマチから支払い
  ↓
ウトマチが販売
  ├─ 実店舗：150円/kg で販売 → 粗利90円/kg
  ├─ EC：200円/kg で販売 → 粗利140円/kg
  └─ ふるさと納税：300円/kg相当 → 粗利240円/kg（一部）

※ 生産者には「卸売価格」を支払い、その後の付加価値化はウトマチが担う
→ 生産者は「生産」に専念、販売リスクなし
```

## 📊 主要機能

### 1. 商品管理システム

```
【Firestore テーブル】
products コレクション
├─ product_id
├─ name（商品名）
├─ producer_id（生産者ID）
├─ category（野菜、米、加工品等）
├─ pricing: {
│  ├─ wholesale_price（生産者に支払う価格）
│  ├─ utomachi_retail（実店舗での売価）
│  ├─ ec_price（EC での売価）
│  └─ furusato_value（ふるさと納税での返礼品価値）
├─ inventory: {
│  ├─ store_stock
│  ├─ ec_stock
│  ├─ furusato_stock
│  └─ reorder_level
└─ images[], description, certifications等

【在庫同期】
・リアルタイム同期（全チャネル）
・自動在庫不足アラート
・売上データのリアルタイム集計
```

### 2. 生産者ポータル

```
【生産者が利用できる機能】
- 月間販売実績確認（チャネル別）
- 売上・振込予定の確認
- 新商品提案フォーム
- 質問・相談窓口
- 認証取得の進捗確認
- 地元メディアでの紹介情報
```

### 3. 実店舗運営

```
【実店舗の特徴】
- 宇土市内（中心商店街）に立地
- 常時 100-150品の商品を展示
- 季節商品の入替
- 「生産者紹介コーナー」で顔が見える販売
- イベント開催スペース
- 試食・ワークショップの実施
```

### 4. EC事業

```
【ウトマチ.jp の機能】
- 商品検索・カテゴリ分類
- 「生産者ストーリー」表示
- 定期便システム（野菜セット等）
- 会員ポイント制度
- SNS連携（Instagram で新商品告知）
- メールマガジン（週1配信）
- レビュー・評価機能
```

### 5. ふるさと納税統合

```
【ふるさと納税返礼品の統合管理】
- 楽天ふるさと納税
- さとふる
- ふるさとチョイス
- 宇土市HPのふるさと納税ページ

【統合メリット】
- 複数サイトの在庫を一元管理
- 返礼品の説明文を一度入力すれば、全サイトに反映
- 受注データをリアルタイムで集計
- 生産者への振込管理を自動化
```

### 6. ブランド・マーケティング

```
【「宇土」ブランド戦略】

1. 商品ブランド化
   └─ 「宇土産有機米」「宇土のいちご」等、地域名を前面に

2. SNS戦略
   ├─ Instagram：生産者顔写真 + 商品の紹介
   ├─ TikTok：若年層向けのレシピ動画等
   └─ X（Twitter）：日々の商品情報・イベント告知

3. メディア戦略
   ├─ 食品雑誌への掲載
   ├─ テレビ・ラジオへの商品紹介
   └─ インフルエンサーとのコラボ

4. オフライン施策
   ├─ 都市部でのPOP UP ストア
   ├─ 百貨店とのコラボ販売
   └─ 食品見本市への出展
```

## 💰 財務モデル

### 初期投資

```
【ウトマチ百貨店 立ち上げに必要な投資】

1. 実店舗
   └─ 店舗内装・設備：1,500万円
   └─ POS・在庫システム：300万円
   └─ 初期商品仕入：500万円

2. EC事業
   └─ Webサイト構築：800万円
   └─ 物流システム（ヤマト等との連携）：200万円

3. 人件費（初年度）
   └─ スタッフ給与：1,200万円

4. ふるさと納税
   └─ 各サイト登録・手数料：50万円

【総初期投資】
約4,550万円

【資金調達】
- 市の財政投資（50%）：2,275万円
- 民間パートナーシップ（50%）：2,275万円
  └─ 地域金融機関のファンド等
```

### 損益分岐点

```
【初年度の財務予測】

売上：6.36億円（フル稼働時）
  ※初年度は段階的立ち上げで 50% 程度 = 3.18億円

営業利益：1.07億円（フル稼働時）
  ※初年度は 50% 程度 = 5,350万円

初期投資の回収期間：1年以内
```
