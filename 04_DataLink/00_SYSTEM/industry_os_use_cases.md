## ケース 1: 農家の6次産業化 - 山田さん（米農家）

### 背景

**状況：**
- 宇土市北部で米作りを30年
- 毎年のコメ売上：約200万円（1haあたり）
- 課題：「コメ価格は下落。後継者もいない。このままでは...」

---

### Before：単純な農産物販売、売上頭打ち

**過去の状況：**
- 全量を農協に卸売（価格決定権なし）
- 毎年の売上：約200万円で変わらず
- コメ加工への自分での挑戦：失敗（機械費用＋販路がない）
- 結果：収入が増えず、経営難が徐々に深刻化

---

### After：産業OS で6次産業化を実現

#### **ステップ1：「米粉メーカーを探している」と登録（2026年4月）**

山田さんは、産業OS にログイン。プロフィールを作成：

```
【山田農家のプロフィール】
名前：山田太郎
生産物：米（有機JAS認証）
生産量：10t/年
販売希望：「米粉メーカーに販売したい」
品質：高品質有機米（粉用）
希望単価：60円/kg（通常卸売 50円/kg）

【生産者ストーリー】
30年、地域の水田を守ってきた。
土壌改良で有機米を実現。
次世代のために、付加価値の高い米作りを目指す。
```

#### **ステップ2：自動マッチング（AI提案）**

産業OS が自動マッチング。複数の米粉メーカーから提案が来る：

```
【マッチング提案】

✓ A社：「米粉パンメーカー」（福岡県）
  └─ 月500kg の米粉需要
  └─ 単価：65円/kg（市場価格）
  └─ 契約期間：1年（更新可）

✓ B社：「米粉プリン製造」（熊本県）
  └─ 月300kg の米粉需要
  └─ 単価：70円/kg（高品質向け）
  └─ 契約期間：3年

✓ C組合：「給食用米粉」（市内学校）
  └─ 月200kg の米粉需要
  └─ 単価：55円/kg（公共調達）
```

#### **ステップ3：複数契約で売上を分散**

山田さんは戦略的に契約：

```
【複合販売戦略】

1. A社（米粉パンメーカー） × 12ヶ月
   └─ 月500kg × 65円 = 月32,500円
   └─ 年間390,000円

2. B社（米粉プリン） × 12ヶ月
   └─ 月300kg × 70円 = 月21,000円
   └─ 年間252,000円

3. 学校給食（市内）×12ヶ月
   └─ 月200kg × 55円 = 月11,000円
   └─ 年間132,000円

【合計月販売額】
月：32,500 + 21,000 + 11,000 = 64,500円
年間売上：774,000円 ← 通常の卸売（年200万円）にプラス

でも、ここからが大事。粉にするための加工者を探す必要がある。
```

#### **ステップ4：加工業者（米粉メーカー）とのマッチング**

産業OS の「メーカー検索」機能で、米を粉に加工できる業者を探す：

```
【加工メーカー検索結果】

✓ 株式会社「熊本ミル」
  - 米粉加工実績：10年以上
  - 月加工能力：5t
  - 加工費：10円/kg（100kg以上）
  - 立地：熊本県（配送あり）
  - 認証：食品衛生法対応、FSSC認証

✓ 「宇土市地域商社」（ウトマチ百貨店傘下）
  - 米粉加工サービス開始予定：2026年6月
  - 月加工能力：2t（初期）
  - 加工費：8円/kg（市内生産者向け優遇）
  - 立地：宇土市内（配送なし）
  - 特色：地域内で完結、利益も地元に還元
```

#### **ステップ5：バリューチェーン構築**

山田さんは、宇土市地域商社での加工を選択。システムが自動で「バリューチェーン」を構築：

```
【米 → 米粉 → 最終商品のバリューチェーン】

段階1：生産（山田さん）
├─ コスト：種子・肥料・労働力 = 40円/kg
├─ 利益：60円/kg（売上） - 40円（コスト） = 20円/kg
└─ 月販売量：1,000kg

段階2：加工（宇土市地域商社）
├─ 仕入：60円/kg（山田さんから）
├─ 加工費：8円/kg
├─ 売上：米粉として85円/kg
├─ 利益：85円 - 60円 - 8円 = 17円/kg
└─ 月販売量：1,000kg

段階3：最終商品（米粉パンメーカー等）
├─ 仕入：85円/kg（米粉）
├─ 製造費：20円（パン製造）
├─ 売上：250円/個（パン）あたり米粉20円相当使用
├─ 利益：（パン販売利益）- 85円（米粉仕入）

【収益分配】
生産者（山田さん）： 20円/kg × 1,000kg × 12ヶ月 = 240,000円/年（+売上）
加工者（地域商社）： 17円/kg × 1,000kg × 12ヶ月 = 204,000円/年
最終製品販売者： パン利益の一部

※ すべての契約・支払いが産業OS で自動追跡・自動分配される
```

#### **ステップ6：ウトマチ百貨店での販売**

加工された米粉は、ウトマチ百貨店（実店舗＆EC）で販売。山田さんの「生産者ストーリー」とともに：

```
【商品名】「山田さんの有機米粉」

【商品説明】
30年、宇土市の水田を守ってきた山田農家の有機米。
土壌改良で実現した、香り豊かな有機米粉です。

【生産者ストーリー】
山田さんは、化学肥料を使わず、毎年土作りに力を入れてきました。
「後世に良い土を残したい」という想いで30年。
この米粉は、その想いが詰まった一品です。

【栄養・特徴】
- 有機JAS認証
- 粉の細かさ：80メッシュ
- 用途：パン、お菓子、給食

【価格】
- 1kg：850円（ウトマチ百貨店小売価格）
- 販売者：ウトマチ百貨店
- 売上配分：山田さんへ一部還元

【購入者からのレビュー】
「このお米粉でパンを焼くと、香りが違う。また買いたい！」★★★★★
```

---

### 効果

| 項目 | 改善前 | 改善後 |
|------|--------|--------|
| **年間売上** | 200万円（米のみ） | 200万円 + 240万円（米粉販売利益） = 440万円 |
| **販売先** | 農協1社のみ | 複数の米粉メーカー＋地域商社＋ふるさと納税 |
| **加工への手間** | 挑戦したが失敗 | 地域商社が加工（山田さんは生産に専念） |
| **ブランド価値** | なし | 「山田さんの有機米粉」として販売（ストーリー付き） |
| **後継者への見通し** | 赤字で不可能 | 売上2倍以上で、事業継続が現実的に |

## ケース 2：企業マッチングによるビジネス拡大 - 鈴木さん（米粉パンメーカー）

### 背景

**状況：**
- 福岡県で米粉パンを製造・販売（従業員5名）
- 月売上：300万円
- 課題：「原材料費が高騰。安定供給できる米粉メーカーがほしい」

---

### Before：定価での仕入、品質・供給の不安定性

**過去の状況：**
- 米粉を複数の流通業者から購入（単価80円/kg）
- 品質にばらつき（粒度が一定でない）
- 供給不安定（欠品が時々発生）
- コスト削減できず、利益率 15% に留まる

---

### After：産業OS で直接生産者と契約

#### **ステップ1：「安定供給できる米粉メーカーを探している」と登録**

鈴木さんは産業OS にビジネス要件を登録：

```
【米粉パンメーカーのニーズ登録】
名前：鈴木パンメーカー
必要な原材料：米粉
月需要量：500kg
品質要件：粒度80メッシュ、水分12%以下
希望単価：65円/kg以下
契約期間：12ヶ月以上（長期安定供給）
```

#### **ステップ2：自動マッチング＆品質検証**

産業OS が自動提案。山田さん（農家）× 地域商社（加工）の組み合わせを提案：

```
【提案内容】
生産者：山田さん（有機米農家）
加工者：宇土市地域商社
米粉品質：80メッシュ、水分12%
単価：65円/kg
供給能力：月500kg確保可能
契約期間：12ヶ月（2026年7月～2027年6月）
品質保証：FSSC22000認証
```

#### **ステップ3：契約・自動配送**

契約完了。自動配送システムが稼働：

```
【配送スケジュール】
毎月20日：前月の需要実績に基づいて自動発注
毎月25日：宇土市地域商社から配送手配
毎月末日：納品、自動請求書作成

【支払い】
毎月15日：銀行振込（自動）
単価 65円/kg × 500kg = 32,500円/月

【品質保証】
毎月：米粉の品質検査（粒度・水分・タンパク質）
不良品：全額返金
欠品：代替メーカーから自動手配
```

#### **ステップ4：コスト削減＆品質向上による利益拡大**

```
【経営改善の実績】

Before（流通業者経由）：
- 米粉単価：80円/kg
- 月使用量：500kg
- 月仕入費：40,000円
- 品質：ばらつきあり

After（直接契約）：
- 米粉単価：65円/kg
- 月使用量：500kg
- 月仕入費：32,500円
- 月削減額：7,500円
- 年削減額：90,000円
- 品質：安定（FSSC認証）

【利益率の改善】
従来：300万円売上 × 15% = 45万円/月利益
改善：300万円売上 × 17% = 51万円/月利益
月増加：6万円 × 12ヶ月 = 年72万円の増益
```

#### **ステップ5：新商品開発への機会**

コスト削減された費用を活用して、新商品開発を決定：

```
【新商品「米粉デニッシュ」開発】
- 使用米粉：「山田さんの有機米粉」
- 販売価格：250円/個
- 原価：60円（米粉含む）
- 利益率：76%
- 月目標販売数：500個
- 月売上追加：125,000円

【販売チャネル】
- ウトマチ百貨店（実店舗）
- EC サイト（全国配送）
- ふるさと納税返礼品

【生産者とのWin-Win関係】
・鈴木さん（パンメーカー）：新商品で売上増加
・山田さん（農家）：需要増加で栽培面積拡大 + ブランド化
・地域商社：加工量増加で経営安定化
```

---

### 効果

| 項目 | 改善前 | 改善後 |
|------|--------|--------|
| **米粉単価** | 80円/kg | 65円/kg（-15円） |
| **月仕入費削減** | 0円 | 7,500円 |
| **品質** | 不安定 | 安定（認証取得） |
| **利益率** | 15% | 17% |
| **月利益増加** | 45万円 | 51万円（+6万円） |
| **新商品開発** | 不可能 | 「米粉デニッシュ」開発実現 |

## ケース 3：起業支援プログラムで新ビジネス立ち上げ - 田中さん（起業者）

### 背景

**状況：**
- 30歳、会社員（月給25万円）
- 2年前、親から農地（5ha）を相続
- アイデア：「親の農地で新しい農業ビジネスをしたい」
- 課題：「何をしたらいい？資金はどうする？」

---

### Before：起業断念（資金・知識不足）

**過去の状況：**
- 農業の知識がない
- 初期投資に必要な資金が不明確
- 銀行融資も難しい（事業計画がない）
- 相談相手がいない
- 結果：農地を賃貸に出すだけで、ビジネス化の道は諦めていた

---

### After：産業OS で起業支援プログラムに参加

#### **ステップ1：産業OS で起業アイデア登録（2026年4月）**

田中さんは、産業OS の「起業」セクションにアイデアを登録：

```
【起業プロジェクト】
名前：「親の農地で苺農園を」
ビジネスモデル：イチゴの高級栽培＋直売・観光農園
目標売上：年500万円（3年後）
資金必要額：初期投資500万円
チーム：田中さん（代表）+ メンター募集

【アイデアの背景】
親の5ha農地のうち、1ha でイチゴの高級栽培。
「摘み取り体験」「直売」「ふるさと納税返礼品」で販売。
地域の観光資源化も目指す。
```

#### **ステップ2：メンター（起業経験者）とマッチング**

産業OS が自動マッチング。メンターが決定：

```
【メンター紹介】
名前：佐藤さん（60歳）
経歴：20年前、地域商社を起業・成功
専門知識：農業ビジネス、地域活性化、資金調達
メンタリング実績：過去15人の起業家を支援（成功率80%）

【メンタリング契約】
期間：6ヶ月（2026年5月～10月）
頻度：月2回、1時間のセッション
無料（宇土市の起業支援制度）
```

#### **ステップ3：ビジネスプラン作成サポート**

メンターとのセッションを通じて、ビジネスプランを完成させる：

```
【ビジネスプラン概要】

【市場分析】
・イチゴの直売市場：年20億円（全国）
・観光農園ニーズ：増加傾向
・ふるさと納税：イチゴ返礼品の人気高い

【生産計画】
・栽培面積：1ha
・品種：高級イチゴ（ブランド化）
・年産量：30t（一般農家の2倍：高級栽培）
・単価：直売 3,000円/kg（一般農家 500円/kg）

【販売チャネル】
1. 直売（摘み取り体験）：月15万円
2. EC 直売：月20万円
3. ふるさと納税返礼品：年50万円
4. 地域商社経由：月10万円
→ 月合計55万円 × 12ヶ月 = 年660万円売上予想

【財務】
・初期投資：500万円
  ├─ ハウス建設：300万円
  ├─ 灌漑設備：100万円
  ├─ 農機具：50万円
  └─ 流動資金：50万円
・月運営費：30万円（人件費・肥料等）
・目標利益：年300万円（売上660万円 - 360万円費用）
・投資回収期間：1.7年
```

#### **ステップ4：資金調達支援**

産業OS が自動提案。複数の資金調達オプションを提示：

```
【資金調達プラン】

1. 宇土市起業支援金：200万円
   - 給付金（返済不要）
   - 条件：起業計画書提出、メンター指導受ける
   - 給付期間：最大2年間（月10万円）

2. 農林水産業融資：200万円
   - 日本政策金融公庫の農業融資
   - 金利：1.5%（低利）
   - 返済期間：10年
   - 月返済額：約2万円

3. 自己資金：100万円
   - 田中さんの貯金

【合計資金】
支給金：200万円 + 融資：200万円 + 自己資金：100万円 = 500万円 ✓
```

#### **ステップ5：起業実行＆進捗管理**

2026年6月、農園のハウス建設を開始。産業OS で進捗を管理：

```
【マイルストーン】

2026年6月：ハウス建設開始
2026年7月：灌漑設備整備
2026年8月：苗植え付け
2026年12月：初収穫
2027年3月：直売開始（摘み取り体験）
2027年4月：EC サイト販売開始
2027年5月：ふるさと納税返礼品登録

【月別目標売上】
2026年12月（初収穫後）：5万円
2027年1月～3月：各月15万円（冬期は販売少ない）
2027年4月～9月：各月50万円（ピークシーズン）
2027年10月～11月：各月30万円
2027年年間売上予想：420万円（初年度、半年営業）

【成功指標】
- メンターセッション参加率：100%
- ビジネスプラン達成度：80%以上
- 顧客満足度：4.5/5以上
```

#### **ステップ6：ネットワーク活用による事業拡大**

産業OS の「コミュニティ」機能を使って、地元事業者とネットワークを構築：

```
【地域ネットワーク構築】

1. ウトマチ百貨店との提携
   └─ 実店舗での「田中農園のイチゴ」コーナー設置
   └─ EC での販売

2. 地域商社との協業
   └─ ふるさと納税返礼品の共同企画
   └─ 宿泊施設への卸売

3. 教育OS との連携
   └─ 学校の「うと学」で農業体験受け入れ
   └─ 子どもたちが摘み取り体験 → 親も来園

4. RMO OS との連携
   └─ 地域イベント（夏祭り等）での販売出店
   └─ PTA の観光農園ツアー受け入れ

【事業拡大の実績】
初期計画売上（年600万円）→ ネットワーク活用後（年900万円）
30年後：「宇土市の観光拠点」として確立
```

---

### 効果

| 項目 | 改善前 | 改善後 |
|------|--------|--------|
| **個人の職業** | 会社員（月給25万円） | 農業起業家（年利益300万円） |
| **農地の活用** | 賃貸のみ（活かされていない） | 自分で経営（ビジネス化） |
