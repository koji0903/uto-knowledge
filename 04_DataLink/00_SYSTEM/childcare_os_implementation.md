## 📋 実装概要

子育てOSの開発を6ヶ月で完成させるための段階的実装計画。

**開発方針：**
- 制度DBと基本UI から始める
- ベータテストで市職員と保護者からフィードバック
- AI ナビ実装はユーザー数が増えてから

---

## 🎯 全体スケジュール

```
Phase 1: 制度DB構築 & 基本UI（2026年5月～6月）2ヶ月
  ↓ 制度検索機能リリース
Phase 2: ライフイベントナビ（2026年7月）1ヶ月
  ↓ ベータテスト開始（100家庭）
Phase 3: AIナビ実装（2026年8月～9月）2ヶ月
  ↓ 本運用開始
Phase 4: マイページ・マップ（2026年10月）1ヶ月
  ↓ 全機能リリース
```

## Phase 1: 制度DB構築 & 基本UI（2ヶ月）

### Sprint 1-2: インフラ & 制度DB設計（2週間）

```
【タスク】
□ Firebase プロジェクト作成
□ Firestore セキュリティルール設定
□ 制度情報スキーマ設計
□ 市からの制度情報収集
  ├─ 福祉課から全制度一覧
  ├─ 教育委員会から教育関連制度
  └─ 保健センターから妊婦・乳幼児支援
□ 制度DB初期化（宇土市の制度100件入力）

【制度DB作成】
- services コレクション初期化
- 各制度の eligibility（対象者条件）入力
- 制度カテゴリ分類（保育、医療、助成金など）
- ライフイベントタグ付け（pregnancy, birth など）

【成果物】
- 初期制度DB（100件）
```

### Sprint 3-4: 基本UI & 制度検索機能（2週間）

```
【タスク】
□ Next.js プロジェクト初期化
□ 認証機能（Firebase Auth）
  ├─ メール/パスワード登録
  ├─ Google ログイン
  └─ LINE ログイン
□ トップページ UI
□ 制度検索画面（逆引き）
  ├─ 年齢選択
  ├─ 世帯構成選択
  ├─ 所得入力（任意）
  └─ 該当制度一覧表示
□ 制度詳細ページ
  ├─ 対象者条件
  ├─ 給付額
  ├─ 申請方法
  └─ 連絡先

【テスト】
□ 検索ロジック確認
□ データベースクエリ最適化

【成果物】
- 基本的な制度検索機能
- 制度詳細表示機能
```

### Sprint 5-6: ベータテスト準備（2週間）

```
【タスク】
□ 市職員向けマニュアル作成
□ 保護者向けUIガイド作成
□ ベータテスター募集（100家庭）
□ 制度DB最終確認
□ バグ修正・パフォーマンス最適化
```

## 技術実装詳細

### 環境構築

```bash
# リポジトリ初期化
git clone https://github.com/uto-city/childcare-os.git
cd childcare-os

# 依存インストール
npm install

# 環境変数設定
cp .env.example .env.local
# FIREBASE_API_KEY, GEMINI_API_KEY などを設定

# 開発サーバー起動
npm run dev
```

### CI/CD パイプライン

```
Git Push
  ↓
自動テスト実行
  ↓
コード品質チェック
  ↓
Pass → Vercel へ自動デプロイ
  ↓
Staging 環境で検証
```
