## ケース1: 妊娠～出産～乳幼児（鈴木さん家族）

### 背景
- 初めての妊娠・出産
- 30代夫婦、世帯年収600万円
- 妊娠5ヶ月の時点で妊婦検診で宇土市に転入

### ユースケース：「妊娠したのに、何をして良いか分からない」

#### Step 1: 妊娠ナビゲーション（妊娠5ヶ月）

```
【鈴木さんの行動】
1. 子育てOS にアクセス
2. トップページで「妊娠した」をタップ
3. 画面に「妊娠周期は？」と聞かれる
   → 「妊娠5ヶ月（19週）」と入力
4. 自動的に「出産予定日」が計算される
   → 「2026年11月頃」と表示

【システムが自動表示する内容】
┌─────────────────────────────────────┐

│   └ 宇土市では7ヶ月から開始         │

│                                     │

│   └ 30万円（自動支給）              │

│                                     │

│ □ 妊婦検診                          │
│ □ 両親学級への参加                  │
│                                     │
│ ⏰ リマインダー：                     │

「なるほど！妊娠5ヶ月の今やることが分かった。

```

   └ 妊娠関連の診療は補助対象
   └ 自己負担200円/回

⑤ 両親学級
   └ 無料
   └ 7ヶ月から開始

【鈴木さんが「出産祝い金」をタップ】

├─────────────────────────────────┤
│ 対象：宇土市に住んでいる家庭      │
│ 金額：第1子30万円                │
│      第2子以降50万円              │
│ 支給時期：出産後2ヶ月以内         │

│                                 │

│ □ 出産祝い金について理解OK       │
│ □ 申請不要だと分かった            │

【AI ナビでも確認】
「出産祝い金はいくらですか？」
→ AI回答：
「宇土市の出産祝い金は第1子が30万円です。

## ケース2: 保育園探し（田中さん家族）

### 背景
- 子ども：2歳（現在、家庭保育中）
- シングルマザー、世帯年収280万円
- 4月から仕事を始めるため、保育園を探している

### ユースケース：「保育園を探したいけど、情報がない」

#### Step 1: 保育園検索（12月）

```
【田中さんの行動】
1. 子育てOS のマップ検索をタップ
2. 「保育園を探す」をタップ
3. フィルター設定
   ├─ 年齢：2歳
   ├─ 開園時間：7:30～18:30
   ├─ 給食：必須
   └─ 「検索」

【システムが表示する情報】
宇土市の認可保育園（10件）

① △△保育園
   ├─ 住所：宇土市△△町
   ├─ 距離：1.2km
   ├─ 空き状況：あり（2歳児 3名）
   ├─ 月額保育料：22,000円
   │  （シングルマザー世帯減免率40%適用）
   ├─ 実額：13,200円
   ├─ 電話：○○○-○○○○
   └─ 「詳しく見る」ボタン

② ◆◆保育園
   ├─ 住所：宇土市◆◆町
   ├─ 距離：0.8km（駅に近い）
   ├─ 空き状況：あり（2歳児 1名）
   ├─ 月額保育料：25,000円
   │  （シングルマザー減免後：15,000円）
   ├─ 特徴：給食＆おやつ完備、延長保育あり
   └─ 「詳しく見る」ボタン

【AI ナビで質問】
「シングルマザーで、保育料はいくらくらい？」

→ AI回答：
「お子さんが2歳で、
世帯年収280万円の場合、
宇土市の保育料は約20,000～25,000円です。

ただし、シングルマザー向け減免制度があり、
通常の40%減免が適用されるため、
実際の負担は約13,000～15,000円になります。

さらに、ひとり親向けの医療費助成（全額無料）
もあります。」
```

#### Step 2: 申し込み手続き（1月）

```
【田中さんが「◆◆保育園」を選択】
1. 詳細ページから「この園を申し込む」
2. 入園申込フォーム（4ページ）
   ├─ お子さん情報（事前入力済み）
   ├─ 保護者情報
   ├─ 保育の理由（就職予定）
   ├─ 特別な対応（アレルギー等）
   └─ 添付書類：
      ├─ 健康診断書（PDF）
      ├─ 予防接種記録（写真）
      └─ 所得証明書（市から取得）

3. 「送信」

【状況確認】
「申し込み状況」ページ：
- 1月5日：申し込み受付
- 1月20日：面接日時決定
  └ 1月28日 14:00 に園で面接
  └ リマインダー通知
- 2月15日：入園可否決定
  └ 「入園予定です。ようこそ！」
  └ 次のステップ表示
```

#### Step 3: 制度確認（3月）

```
【入園前に確認すること】
「保育園入園に伴う制度」

□ 保育料補助：シングルマザー向け
   └ 毎月15,000円が実際の負担額

□ 医療費助成（ひとり親世帯）
   └ 就学前：全額無料
   └ 小学生：自己負担200円/回

□ 児童手当：継続受給
   └ 毎月15,000円（変更なし）

□ 給食費
   └ 月額5,000円（保育料に含まれる）
   └ 別途負担なし

【新しく活用できる制度】
□ 延長保育利用時の減免
   └ 18:30～19:00：無料
   └ 19:00～20:00：月額3,000円

□ 家庭内での就職支援
   └ ひとり親向けの職業訓練補助
   └ 通園と仕事の両立支援
```

## 子育てOS の効果（全ケース共通）

### Before: 子育て支援が分からない

```
【鈴木さん】妊娠中
- HP で「妊婦検診」を検索 → 見つからない
- 市役所に電話 → 「福祉課に聞いてください」
- 福祉課に電話 → 込んでいて繋がらない
- 結局 2週間後にやっと情報入手

【田中さん】保育園探し
- 市の資料をもらう → 10園の一覧が書いてある
- 自分で電話して一つ一つ聞く（3時間）
- 空き状況を確認する → 「ちょっと待ってください」と保留
- 制度（減免）については、別途福祉課に電話

【佐藤さん】小学校準備
- 学校説明会で「費用について書いた資料」をもらう
- でも「医療費はいつまで？」など細かいことは書いていない
- ネットで「宇土市 医療費」と検索 → 古い情報が出てくる
```

### After: 子育て支援がスマートフォンで完結

```
【鈴木さん】妊娠中
- アプリを開く → 「妊娠した」をタップ
- 5分で「今月やること」が全部見える
- 不明な点は AI に聞く → すぐに回答
- リマインダーで期限を逃さない

【田中さん】保育園探し
- マップで一覧 → 待遇を比較 → 申し込み
- 全部スマートフォンで完結（30分）
- 制度計算も自動（実額が即座に分かる）

【佐藤さん】小学校準備
- 「小学校入学」をタップ → チェックリスト表示
- 不安なことを AI に質問 → 回答
- 医療費の変更も即座に分かる
- 就学援助の相談窓口が一覧表示される
```

## 子育てOS がもたらす根本的な変化

```
【保護者レベルの変化】

■ 時間削減
- 情報収集時間：20時間 → 1時間
- 手続き時間：30時間 → 5時間
- 月20時間の余裕が生まれる

■ 安心感
- 「何かやり忘れていないか」という不安が減少
- 自動リマインダーで期限を逃さない
- 困った時はいつでも AI に相談

■ 費用削減
- 制度を知らずに払っていたお金が減少
- 自動マッチングで最適な支援を受けられる

【市レベルの変化】

■ 窓口負担削減
- 「制度について教えてください」という電話：80%削減
- 窓口対応者の業務が30%軽減
- その分、相談や困難事例対応に専念可能

■ 制度利用率向上
- 知らずに使わなかった制度：取りこぼし 40%削減
- 給付がすぐに受け取られる
- 市民満足度が向上

■ データ活用
- 「何歳で何の制度が必要か」がデータで見える
- 来年の施策改善に活用可能
- 「どの制度が使われないのか」が判明 → 改善へ
```
