## ユースケース概要

教育OSが学校統廃合を円滑に進め、地域学習の質を向上させる3つの実例。

---

## ケース 1: 学校統廃合への不安解消 - 田中さん（保護者）

### 背景

**状況：**
- 宇土市北部の小規模校（児童数40名）に子ども2人が在学
- 2026年8月に市内の中核校（児童数200名）への統廃合が予定されている
- 田中さんは心配：「小さい学校から大きい学校に移って、子どもが不安になったり、いじめられたりしないか」

**課題：**
- 統廃合の詳細情報がない
- 新しい学校の様子がわからない
- 子どもがどのようにサポートされるか不明確

---

### Before：情報が散在、不安が増加

**過去の統廃合事例（2010年）：**
- 学校からのプリント数枚で情報提供
- 保護者説明会は月1回、限定的
- 統廃合前後の児童サポート体制が不明確
- 結果：転学後の不登校が10%を超える

---

### After：教育OS で段階的な情報提供と支援

#### **段階1：統廃合予定の公開（6ヶ月前）**

田中さんは教育OS にログイン。ダッシュボードに**「統廃合に関する情報」** タイルが出現。

```
【統廃合スケジュール】
├─ 2026年5月：公式告知・説明会
├─ 2026年6月：転学手続き説明
├─ 2026年7月：新学校オリエンテーション
└─ 2026年8月1日：統廃合実施

【子どもへのサポート】
├─ バディシステム：7月中旬から開始
├─ 新学校訪問会：7月20日、27日（複数回参加可能）
└─ 転学児童向けカウンセリング：随時利用可能（無料）
```

#### **段階2：新学校の様子を動画で確認（4ヶ月前）**

教育OS 内の「新学校紹介」セクションで：
- 新学校の校舎ツアー動画（5分）
- 既在学児童へのインタビュー（「新しく来る子たちへのメッセージ」）
- 新学年の担任紹介（自己紹介動画）
- 新学校のうと学プログラム紹介（何を学ぶのか）

**田中さんの印象：**
> 「あ、新しい学校いい雰囲気だ。子どもたちも元気そう。うと学で有明海の学習をするんだ。」

#### **段階3：子どもがバディとつながる（3ヶ月前）**

教育OS には「バディマッチング」機能がある。

田中さんの上の子（4年生）は、新学校の4年生とバディペアリング。

```
【バディ情報】
名前：佐藤太郎（新学校4年生）
趣味：サッカー、プラモデル
メッセージ：「野球部に一緒に入ろうよ！」
```

教育OS の**バディチャット機能**で、転学前から交流できる。

**子どもの変化：**
- 1週間で10回以上のメッセージ交換
- 「佐藤くんと同じ野球部に入ろうかな」と本人が決定
- 統廃合への不安が「新しい友達ができる」という期待に変わる

#### **段階4：段階的な新学校訪問（2ヶ月前）**

教育OS で予約した「新学校訪問会」に参加。複数回参加可能。

**1回目（体験中心）：**
- 校舎ツアー（実際に教室を見学）
- 体育の授業体験（一緒に体育をする）
- 図書室見学・貸出手続き

**2回目（人間関係構築）：**
- バディとの顔合わせ（バディと一緒に過ごす30分）
- 新学校の児童と給食体験

**3回目（新学年準備）：**
- 新学年の学習内容説明
- クラブ・委員会選択説明
- 教科書配付

#### **段階5：転学後のカウンセリング体制**

転学後、教育OS に「カウンセリング予約システム」が統合されている。

田中さんの下の子が「お友達ができない...」と少し落ち込んでいても、教育OS から簡単に予約できる。

```
【カウンセリング予約】
日時：2026年9月10日（木）15:30
相談内容：友人関係について
カウンセラー：田中先生（認定スクールカウンセラー）
```

---

### 効果

| 項目 | 改善前 | 改善後 |
|------|--------|--------|
| **統廃合までの日数** | プリント数枚で情報提供 | 段階的な情報提供（6ヶ月）|
| **保護者の不安度** | 高い（説明会に多数の不安質問） | 低い（事前に情報得られた） |
| **児童の転学前の交流** | なし | バディチャットで事前交流 |
| **転学後の新学校訪問** | なし | 3回の体験訪問で段階的適応 |
| **転学後のサポート体制** | 不明確 | カウンセリング予約で迅速対応 |
| **転学児童の不登校率** | 過去実績 10%以上 | **目標：3%以下** |

## ケース 2: うと学プログラムの充実 - 佐藤さん（教員）

### 背景

**状況：**
- 佐藤さんは、統廃合後の新しい学校の4年生担任
- 新学校での最初のうと学プログラムは「有明海の生態系」
- 課題：「有明海の学習は初めて。どうやって教えたらいい？」

---

### Before：教員が単独で準備、地域連携が困難

**過去の地域学習：**
- 教員が自分で指導案を作成（インターネット検索等）
- 地域人材への連絡は電話・FAXのみ
- 地域連携先との日程調整が難しい
- フィールドワークの内容が体験中心で、学習の系統性がない

**結果：** 教員の負担が大きく、地域連携が進まない

---

### After：教育OS で体系的な学習設計と地域連携

#### **ステップ1：うと学プログラムテンプレートの活用**

教育OS にログインした佐藤さんは、**「うと学プログラム設計ツール」** を開く。

```
【プログラム設計ウィザード】

1. プログラム名：「有明海の生態系」（自動入力）

2. 学習目標を選択：
   ✓ 有明海がどのような海か理解する
   ✓ 干潟の生物の適応と食物連鎖を理解する
   ✓ 有明海の環境問題と解決策を考える
   
3. 実施時期：7月～9月（全12時間）

4. モジュール選択：
   ✓ 教室学習（有明海について）... 4時間
   ✓ フィールドワーク（干潟体験）... 4時間
   ✓ 地域人材による講話（海苔漁師の話）... 2時間
   ✓ 学習成果まとめ（ポスター作成）... 2時間
```

#### **ステップ2：学習リソースの自動提示**

教育OS に「ジオパーク学習リソース」が統合されている。

佐藤さんが「有明海」を選択すると、自動的に以下が表示される：

```
【ジオパーク学習リソース：有明海】

【ビデオコンテンツ】
✓ 「有明海の干潟はどうしてできたのか」（7分）
  - 地質学者による解説
  - 宇土市ジオパークセンター提供
  
✓ 「海苔養殖の現在」（8分）
  - 実際の漁師の仕事紹介
  
✓ 「干潟の生物多様性」（5分）
  - インタラクティブ映像（生物の分類を学べる）

【対話式学習ツール】
✓ 干潟の生物図鑑（詳細情報・写真・動画）
✓ 有明海の環境問題クイズ
✓ 食物連鎖シミュレーター

【フィールドワークガイド】
✓ 干潟への行き方（GPS・地図）
✓ 潮時表（観察に最適な時間）
✓ 観察シート（PDF ダウンロード）
✓ 安全ガイド（危険生物・潮の急変）

【対応する教科書単元】
✓ 理科4年「季節と生き物」
✓ 社会4年「地域の産業」
```

**佐藤さんの効果：**
> 「あ、資料がもう全部揃っている。指導案もほぼ完成だ。」

指導案作成の時間が、従来の3日 → 2時間に短縮。

#### **ステップ3：地域パートナーの自動マッチング**

教育OS に「地域パートナー検索機能」がある。

佐藤さんが「有明海・干潟学習 + 専門家講話」で検索すると：

```
【マッチした地域パートナー】

1. 宇土市漁業協同組合
   - 実績：海苔養殖・貝類採取の実体験提供
   - 得意分野：漁業の仕事、海の生態系
   - スケジュール：7月～9月で対応可能
   - 人数：15名まで対応可
   → 選択

2. 宇土市ジオパークセンター
   - 実績：地質学習・フィールドワークガイド
   - 得意分野：有明海の成因、地質学
   - スケジュール：毎週土曜日対応可能
   → 選択

3. NPO「有明海を守る会」
   - 実績：環境問題学習・干潟保全体験
   - 得意分野：有明海の環境問題、保全活動
   - スケジュール：要相談
   → 選択予定

【自動連絡メッセージ（教育OS が送信）】
「2026年7月～9月に小学4年生40名を対象に『有明海の生態系』プログラムを実施します。 貴組織のサポートをお願いしたいです。日程：...」
```

**従来の負担：** 電話・FAX で複数の地域機関に個別連絡 → 返答待ち → 日程調整（1週間以上）

**教育OS での実行：** システムが自動提案 → メール送信 → 相手が教育OS で返答 → 日程自動調整

**時間短縮：** 1週間 → 2日

#### **ステップ4：フィールドワークの実施・記録**

7月20日、佐藤さんと児童40名が干潟でのフィールドワークを実施。

教育OS の「フィールドワークログ」に：

```
【フィールドワーク実績】

日付：2026年7月20日
場所：有明海干潟（GPS座標記録）
参加児童：40名
実施時間：9:30～11:30
講師：漁業協同組合・鈴木組合長

【活動内容】
✓ 潮干狩り体験（15分）
✓ 観察シートに記入（30分）
  - 採集した生物の写真・名前・特徴
✓ 組合長による講話（15分）
  - 「海苔養殖の仕事」

【児童の気づき（一部抜粋）】
- 「貝には目がないのに、どうやって食べ物を探すの？」
- 「海苔ってすごい手間がかかるんだ」

【撮影した写真】
✓ 干潟全景（10枚）
✓ 採集した生物（各児童の分）
✓ グループ写真（5枚）

→ 自動的に児童の学習ポートフォリオに記録
```

**画像の自動処理：**
教育OS の AI が、写真から生物を自動認識し、児童の学習ポートフォリオに自動タグ付け。

```
【児童・山田太郎の学習ポートフォリオ】
→ 有明海フィールドワーク
   ├─ 採集した生物：巻貝・ヤドカリ・シオフキ貝
   ├─ 気づき：「貝はどうやって食べ物を探すのか？」
   └─ 学習スキル：「観察力」「生物分類」
```

#### **ステップ5：地域パートナーからのフィードバック**

フィールドワーク終了後、教育OS で地域パートナー（鈴木組合長）が自動的にフィードバック入力の通知を受け取る。

```
【地域パートナーフィードバック】

from：漁業協同組合・鈴木組合長

「今日は40名の児童との学習時間をありがとうございました。

児童の皆さんの観察力に感心しました。特に『貝の食べ方』など、 細かい質問が出て、次世代への期待を感じました。

ぜひ来年も協力させていただきたいです。また、児童が『海苔づくりの大変さ』を理解してくれたので、 今後の食育につながるといいですね。」

推奨：【協力を続ける】【スキル向上のため研修相談】
```

このフィードバックは、教育OS で記録され、次年度のプログラム設計の参考に。

#### **ステップ6：児童の学習ポートフォリオに統合**

フィールドワークの実施、地域パートナーのフィードバック、児童の振り返りなどが、すべて児童のポートフォリオに統合される。

```
【山田太郎のポートフォリオ：うと学「有明海の生態系」】

【学習目標】
✓ 有明海の干潟の生態系について理解する
✓ 生物の適応と食物連鎖を理解する
✓ 環境問題と解決策を考える

【プロセス】
1. 教室学習：有明海について（ビデオ視聴 + クイズ）
2. フィールドワーク：干潟体験（2026年7月20日）
   - 採集生物：巻貝・ヤドカリ・シオフキ貝
   - 気づき記録：3項目
3. 地域人材講話：海苔漁師の話（2026年7月27日）
   - 学んだことをレポートにまとめた
4. 学習成果：干潟の食物連鎖ポスター（A3版）

【成果物】
✓ ポスター画像（アップロード）
✓ フィールドワーク時の自分の写真
✓ 「海苔づくりをしてみて」レポート

【学習スキルの成長】
┌─ 観察力：★★★★☆（向上度：+1）
├─ 科学的思考：★★★☆☆（向上度：0）
├─ 表現力：★★★★☆（向上度：+1）
└─ 協働性：★★★★★（向上度：+1）

【教員コメント（佐藤先生）】
「太郎さんは、フィールドワークを通じて、『海の生き物がどうやって生きているか』に深い興味をもつようになりました。 ポスターでも、食物連鎖を正確に表現できており、科学的思考の成長が見られます。
今後も、地域の学習を通じた『体験→理解→表現』のサイクルを大切にしていきましょう。」

【保護者コメント（母親）】
「家で『有明海の干潟ってすごいんだよ』と子どもが説明してくれました。 地元の学習を通じて、地域への愛着が深まっているのを感じます。」

【児童自身の振り返り】
「有明海は、いろんな生き物がいる大事な場所だと分かりました。 特に、干潟の生き物たちは、すごい工夫をして生きています。 将来、海を守る仕事をしたいです。」
```

---

### 効果

| 項目 | 改善前 | 改善後 |
|------|--------|--------|
| **指導案作成時間** | 3日間 | 2時間 |
| **地域連携先の確保** | 1週間（電話・FAX） | 2日（自動マッチング） |
| **フィールドワーク準備** | 個別連絡・日程調整 | システムが自動手配 |
| **児童の学習記録** | 教員が手動記入 | 自動ポートフォリオ統合 |
| **保護者への説明** | 紙媒体レポート | ポートフォリオで動的確認 |
| **うと学プログラム数** | 年3-4個 | **年8-10個（倍増）** |
| **地域連携機関数** | 5機関 | **20機関以上** |

## ケース 3：小規模校のメリット活用 - 鈴木校長（学校管理職）

### 背景

**状況：**
- 統廃合により、5校 → 2-3校へ
- 新学校は「小規模校の良さ」を活かしたい
- 課題：「40-50名の学年で、本当に『質の高い学習』ができるのか？」

---

### Before：小規模校のメリットが見える化されていない

**過去の課題：**
- 児童1人ひとりの成長が「点の記録」（成績票等）で管理
- 学年間・校間のデータ比較がない
- 「小規模校はいい」という一般論はあるが、実績データがない
- 保護者の説得材料がない

---

### After：教育OS で小規模校のメリットを可視化

#### **ステップ1：児童の成長を「ポートフォリオ」で一元管理**

教育OS により、各児童のポートフォリオが1つの「成長の記録」として統合される。

```
【山田太郎のポートフォリオ（4年生）】

【スキル進捗】
・読み書き：★★★☆☆（学年平均：★★★☆☆）
・計算：★★★★☆（学年平均：★★★☆☆） ← 個別指導の効果
・科学的思考：★★★★☆（学年平均：★★★☆☆）
・協働性：★★★★★（学年平均：★★★★☆） ← 小規模校のメリット
・創造性：★★★★☆（学年平均：★★★☆☆）

【成長ナラティブ（教員が記述）】
「太郎は、4月の入学時には、数学に苦手意識がありました。しかし、小規模校では、 教員が1人ひとりのペースに合わせられるため、週2回の個別指導を実施。 9月までに計算スキルが大幅に向上しました。

また、全学年40名という小規模集団での学習により、 プレゼンテーション・協働学習の機会が多く、 『発言する・聞く』スキルが飛躍的に成長しました。」

【学習時間の使い方（教員の個別指導比率）】
小規模校（新学校）：30%（個別/グループ指導）
中規模校（旧データ）：5%
大規模校（他自治体）：2%

→ 小規模校では、個別指導に30%の時間をかけられる！
```

#### **ステップ2：異学年交流の実績を可視化**

小規模校では、自動的に異学年交流が増える。

教育OS で「異学年学習・交流」を記録。

```
【2026年度 異学年交流実績】

【計画された交流】
✓ 月1回の「異学年混合朝礼」
✓ 週2回の「異学年共同学習時間」（図書館・美術室）
✓ 月1回の「異学年スポーツ大会」

【実績（教育OS 記録）】
- 異学年交流実施回数：計45回/年（月3.75回）
- 1児童あたりの異学年交流時間：月平均3時間
- 児童の「協働性」スキル成長：+35%（年間平均）

【効果（保護者フィードバック）】
「上級生が下級生の面倒を見る姿勢が育っている」
```
