# 移住・定住OS

## 🎯 移住・定住OSとは何か

移住・定住OSは、単なる「人口を増やす施策」ではありません。

宇土OSにおける本質は、

> **産業・教育・地域を「持続可能に回すための人材循環OS」**

です。つまり、

- ❌ 誰でも来てほしい
- ⭕ **宇土に合う人が、無理なく住み続ける**

この前提で設計されています。

---

## 📊 宇土市の移住施策の現状

### 情報発信は整ってきている

- 移住・定住サイト「うと暮らし」の構築
- 補助制度の整備
- お試し移住体験住宅の設置

➡ **入口（集客）は改善している**

### しかし「詰まっている」最大要因：空き家供給不足

```
需要と供給のギャップ：
移住希望者：増加傾向
利用可能な空き家：減少傾向

原因：
- 空き家は存在する
- しかし市場に出てこない
- 空き家バンク在庫は慢性的に少ない

結果：
需要 ＞ 供給 = 多くの希望者が定住できない
```

---

## 🏚️ 空き家問題の構造的本質

### なぜ空き家が市場に出ないのか

```
【所有者の心理的障壁】
- 「貸すのが不安」（トラブル懸念）
- 「誰に任せるか信頼できない」
- 「相続で兄弟姉妹と調整が必要」（意思決定困難）

【実務的障壁】
- 家財撤去の負担（コスト + 手間）
- 登記整理の複雑さ（費用 + 時間）
- 税務上の判断不可能（専門知識必要）

【動機不足】
- 「貸しても赤字」（収入 ＜ 維持費）
- 「手間をかける価値がない」

結果：
所有者が「貸す」という判断に至らない
```

### 行政の従来アプローチの限界

```
従来のアプローチ：
→ 移住者向け補助金中心（需要側への支援）
→ 空き家バンク制度（情報提供）

限界：
→ 所有者への直接インセンティブなし
→ 供給側が置き去り
→ 新規物件の掘り起こしができない
```

---

## 🎯 移住・定住OSの設計思想

### 軸① 「移住者支援」から「空き家創出支援」へ転換

**供給側の行動を起こす**

対象：空き家所有者

施策：

```
【家財処分補助】
課題：撤去費用が高い（50～150万円）
施策：撤去費用の50～70%を行政負担
効果：所有者の実務的障壁を低減

【登記整理支援】
課題：相続登記の手続きが複雑
施策：専門家（司法書士）を無償紹介
効果：法的障壁を除去

【管理代行スキーム】
課題：家の日常管理が大変
施策：移住者マッチング後も、定期的な家屋管理を行政が支援
効果：「貸した後の不安」を解消
```

### 軸② 「いきなり移住」をさせない

**失敗しない移住プロセス**

```
段階1：お試し滞在（1～3月）
段階2：施設周辺での人間関係構築
段階3：仕事・地域・学校を体験
段階4：定住の判断
段階5：本移住

このプロセスなしに移住させると：
→ 数年で流出（移住失敗）
```

## 🏠 お試し移住住宅の戦略的再定義

### 現在のお試し住宅

**短期滞在施設として機能**
- 利用者：数十人/年
- 滞在期間：1～2週間が中心
- 利用者満足度：高い

### OS的再定義

**お試し住宅 = 「移住コンバージョン装置」**

お試し住宅での活動：

```
【RMOスタッフとの面談】
└ 地域の文化・慣習を理解
└ 自分が適応できるか判断

【先輩移住者との交流】
└ 実際の移住生活を聞く
└ リアルな課題を知る

【空き家候補の内覧】
└ 実際に住む可能性のある家を見学
└ 具体的な生活をイメージ

【地元産業体験】
└ 職場（地域商社など）の見学
└ 仕事内容を現場で確認
```

### 効果

```
従来：一時的な「体験」
  ↓
OS的：「判断のための材料収集」
  ↓
結果：定住成功率が大幅向上
```

## 🎯 移住ターゲットの再設計

### 優先順位付けられた3つの層

#### 1. 継業（事業承継）移住者

**最優先ターゲット**

対象：
```
【農業】
- 新規就農者
- 農業研修修了者
→ 田畑 + 農業研修 + 資金支援

【小規模商店】
- 商店承継者（現所有者の子どもなど）
- 新規商店開業希望者
→ 店舗 + 仕事 + 資金支援

【製造業補助人材】
- 地域商社・企業の従業員予定者
→ 確実な仕事 + 住宅 + サポート
```

特徴：
- 「仕事ありき」なので継続性が高い
- 定住率が高い（80～90%）
- 地域経済への貢献が大きい

#### 2. リモートワーカー

**成長するセグメント**

対象：
```
都市部（主に福岡・熊本近郊）で勤務
│
宇土市からリモートで従事
│
地域との接点を増やせる人材
```

特徴：
- 給与は都市部水準を維持
- 自然環境・コミュニティを求める層
- 子育て世帯が多い

支援：
```
【テレワークセンター整備】
学校跡地を活用したリモートワークスペース
└ 固定オフィスより柔軟
└ コミュニティ形成の場

【通勤手段の工夫】
熊本都市圏への移動を容易に
└ 週1～2回の通勤も可能
```

#### 3. 子育て世帯（限定）

**教育OS・子育てOSとの連動**

対象：
```
「教育の質」で移住先を選ぶ世帯
│
小規模でも高品質な教育環境
│
地域との強い人間関係
```

選別の視点：
- 「すべての子育て家庭」ではなく
- 「宇土の教育・地域に価値を感じる家庭」
- **適合度重視**

## 🔗 移住・定住OS × 他OS連動

### 産業OS との連動

```
仕事付き移住プログラム

農業：新規就農支援 → 田畑提供 + 技術研修
      ↓
      地域商社での農産物加工・販売

製造業：企業就職 → NTF等での就業
       ↓
       地元産業の担い手に

商業：新規商店開業 → 資金 + 商圏分析
     ↓
     地元商業の活性化
```

### 教育OS との連動

```
子育て世帯への説明資料

学校統廃合のメリット：
- 適正規模での教育環境
- うと学による地域教育
- 小規模だからこその個別対応

「教育の質で選ばれる市」というポジション
```

### RMO OS との連動

```
地域の受け皿整備

移住受け入れの準備：
□ 地域行事への参加ガイド
□ 人間関係構築の支援
□ 地域課題への参加機会提供

「孤立しない移住」の実現
```

## 📊 移住・定住OS実装による効果

### 定住成功率の向上

```
Before（従来の施策）
移住1年以内の流出率：30～40%（多くの移住施策）

After（移住・定住OS実装）
移住5年以内の定住率：70～80%（見込み）

理由：
- プロセスを踏むことで「判断が確実」
- 仕事がセットなので「継続性がある」
- 地域との接点が多いので「孤立しない」
```

### 人口増への貢献

```
目標：年30～50世帯の移住受け入れ

5年累計：150～250世帯
10年累計：300～500世帯

定住人口の維持：3.0万人へ（2040年）
```

### 経済波及効果

```
移住1世帯あたりの年間経済効果：約2～3百万円

移住30世帯 × 年3百万円 = 年9千万円
     ↓
地元での消費 + 産業への従事 + 税収

10年累計：9～15億円の経済効果
```

## ⚠️ 移住・定住が失敗するケース

```
【失敗パターン1】
住宅だけ提供
→ 仕事がない
→ 数年で流出

【失敗パターン2】
補助金だけ支給
→ 地域との接点なし
→ 孤立感から流出

【失敗パターン3】
「来たい人は来て」方式
→ 適合度考慮なし
→ 文化摩擦で早期退出
```
