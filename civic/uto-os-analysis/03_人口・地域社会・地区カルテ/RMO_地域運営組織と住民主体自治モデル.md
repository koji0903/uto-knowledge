# RMO 地域運営組織と住民主体自治モデル

人口減少・高齢化が進む宇土市において、行政サービスを全域で一律維持することが困難になる中、地域住民が主体となって生活機能を維持する「地域運営組織（RMO: Regional Management Organization）」の構築戦略です。

## 🏛️ 行政依存から「共創型自治」への転換

```mermaid
flowchart TD
    subgraph 従来モデル (行政丸抱え)
        Gov["市役所・行政"] -->|全域一律サービス提供| Citizen["住民・町内会 (要望・陳情)"]
    end

    subgraph RMOモデル (パートナーシップ共創)

        RMO <-->|参画・受益| Residents["住民・多世代"]
    end
```

## 🎯 宇土市におけるRMO重点4事業

### 1. 「小さな拠点」の管理運営
- 老朽化した単独公民館を廃止し、小中学校の余裕教室や集約施設をRMOが管理運営。
- 喫茶サロン、移動販売ステーション、図書コーナーなど住民が集う場を創出。

### 2. 地域生活交通の運行支援
- 市がAIオンデマンド配車システムを提供し、運行ダイヤの調整やボランティアドライバーの組織化をRMOが担う。
- 医療機関、スーパー、市役所へのラストワンマイルを確保。

### 3. 多世代見守りと生活支援
- 一人暮らし高齢者の安否確認、ゴミ出し支援、草刈りなどを地域内有償ボランティアとして仕組み化。

### 4. 地域資源の収益化
- 轟水源の保全観光、網田の特産品販売など、自主財源を獲得する小規模ビジネスの展開。

---

## 💡 議会・政策判断のポイント
> [!tip] 議員・政策担当者のアクション
> - 「地域運営交付金」の創設と一括交付（使い道を地域が自由に決められる使途自由度）を条例化し、行政の下請けではない真の住民自治を制度設計すること。
