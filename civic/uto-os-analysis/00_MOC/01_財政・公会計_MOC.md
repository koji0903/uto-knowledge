# 財政・公会計 MOC

宇土市の普通会計決算、公会計4表、地方債・基金、他会計繰出金に関する構造分析のハブノートです。

## 📊 構造の核心（公会計アナリスト診断）
1. **固定費率の硬直化**: [[自治体経営KPIハンドブック_定義と市民翻訳#経常収支比率|経常収支比率]] は **94.2%**。義務的経費（人件費・扶助費・公債費）で税収の大半が消え、政策的自由度が低下。
2. **震災復旧債のピークアウト**: [[自治体経営KPIハンドブック_定義と市民翻訳#実質公債費比率|実質公債費比率]] は **12.0%**。熊本地震復旧事業債の償還が進行中であり、R9年度には10%未満の安全圏へ復帰見通し。
3. **基金耐久力**: 財政調整基金は **35.6億円**（標準財政規模の4.2ヶ月分）を確保。災害や急激な歳入減へのクッション機能は維持。
4. **他会計繰出の重圧**: 一般会計から特別会計・企業会計へ **年間16.5億円**（世帯あたり年10.3万円）を繰出補填。
