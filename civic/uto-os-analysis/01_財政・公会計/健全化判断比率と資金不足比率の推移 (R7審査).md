# 健全化判断比率と資金不足比率の推移 (R7審査)

地方公共団体の財政の健全化に関する法律（財政健全化法）に基づき公表される「健全化判断比率4指標」および「公営企業資金不足比率」の最新審査結果と安全性の検証です。

## 📊 健全化判断比率の現状と判定

| 指標名 | 宇土市の数値 | 早期健全化基準 (黄色) | 財政再生基準 (赤色) | 判定結果 |
| :--- | :---: | :---: | :---: | :---: |
| **① 実質赤字比率** | **-** (黒字) | 13.56% | 20.00% | **極めて良好** |
| **② 連結実質赤字比率** | **-** (黒字) | 18.56% | 30.00% | **極めて良好** |
| **③ 実質公債費比率** | **12.0%** | 25.0% | 35.0% | **適正 (改善中)** |
| **④ 将来負担比率** | **68.4%** | 350.0% | - | **安全圏** |

※実質赤字比率・連結実質赤字比率は赤字額がないため「-（該当なし）」表示。

## 💧 公営企業等 資金不足比率

| 会計名 | 資金不足比率 | 経営健全化基準 (黄色) | 判定 |
| :--- | :---: | :---: | :---: |
| **上水道事業会計** | **-** (資金剰余) | 20.0% | 基準内 |
| **公共下水道事業会計** | **-** (資金剰余) | 20.0% | 基準内 (※繰出金補填後) |
| **漁業集落排水事業会計** | **-** (資金剰余) | 20.0% | 基準内 (※繰出金補填後) |

> [!warning] 表向きの「資金剰余」に潜むリスク
> 下水道事業会計および漁業集落排水事業会計は資金不足比率が「該当なし」となっていますが、これは **一般会計から毎年4億円超の公費繰出金（穴埋め）を行っているから** です。
> 一般会計からの繰出金を停止した場合、即座に20%の経営健全化基準を突破して赤字経営に転落する構造です。

## 🔍 指標の深層分析

### 実質公債費比率（12.0%）の評価
- 起債許可団体となる18.0%を大きく下回っており、起債手続き上のペナルティはありません。
- ただし、類似団体（人口3万〜5万人の都市平均：8.5%前後）と比較すると約3.5ポイント高く、過去の震災復旧投資の返済負担がまだ残存しています。

### 将来負担比率（68.4%）の評価
- 将来負担比率は一般会計の借金だけでなく、公営企業債や退職手当引当金、土地開発公社等の偶発債務を含めた実質負担を測る指標です。
- 上限基準（350%）に対して68.4%と極めて余裕があり、債務不履行のリスクは皆無です。
