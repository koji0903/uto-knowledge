# 宇土OS Obsidian ナレッジベース

本リポジトリは、熊本県宇土市の自治体経営ダッシュボード「宇土OS（uto-os.jp）」における多岐にわたる分析結果・公会計データ・政策シミュレーション・議会論点を、**Obsidian用ナレッジベース（PKM: Personal Knowledge Management）** として体系化したものです。

## 📂 Vault フォルダ構成
- **`00_MOC/`**: 各テーマを鳥瞰できる Map of Content（目次・全体マップ）
- **`01_財政・公会計/`**: 決算カード9か年、将来償還カーブ、基金耐久力、他会計繰出金、健全化判断比率
- **`02_公共施設・インフラ経営/`**: 431億円問題、更新ギャップ、上下水道公営企業会計（逆ザヤ・回収率）、40年更新需要
- **`03_人口・地域社会・地区カルテ/`**: 人口動態、市内7地区カルテ、RMO地域運営、福祉・教育
- **`04_政策・未来シナリオ/`**: 2040未来予測、スマートシュリンク戦略、PFU政策実験、地域商社、行政DX
- **`05_市議会論点・監査検証/`**: 補正予算審議、一般質問逆引き、施策台帳・政策ROI
- **`06_KPI辞書・指標ハンドブック/`**: 経常収支・公債費・有収率などの指標定義と市民翻訳

## 🚀 活用方法
1. **既存のObsidian Vaultへの統合**:
   - 本フォルダ（`docs/obsidian-vault/`）内の各フォルダを、お使いのObsidian保管庫へそのままコピーしてマージしてください。
2. **新規Vaultとして直接開く**:
   - Obsidianの「保管庫を開く（Open folder as vault）」から、`docs/obsidian-vault/` を選択してください。
3. **Graph View（グラフビュー）**:
   - 全ノートに `[[00_宇土OS_総合ナレッジMOC]]` 等の内部リンク（WikiLink形式）が張られているため、人口・財政・施設・政策の連鎖構造がグラフとして可視化されます。
4. **議会活動・政策提言への活用**:
   - 一般質問、予算・決算審査、委員会審議の準備メモとして、各ノートの「議会・政策判断のポイント」を直接ご活用いただけます。

## 🔄 自動更新
データ更新時や再生成時は、下記コマンドを実行してください：
```bash
npm run export:obsidian
```
