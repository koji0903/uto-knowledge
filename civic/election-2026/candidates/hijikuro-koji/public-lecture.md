# 🎤 市民向け講演会 30分スピーチ＆対話ガイド

全市民対象・大ホールでの講演会（スピーチ30分＋対話30分）の完全原稿と運営ガイド。
文体は [[civic/election-2026/candidates/hijikuro-koji/voice-style-guide|スタイルガイド]] に準拠（伴走者トーン・一文短く・構造を主語に・未来で締める）。
数字は [[civic/election-2026/current-values|現状値データ集]]、実績は [[civic/election-2026/candidates/hijikuro-koji/achievements-1st-term|実績棚卸し]]に基づく。

## 📜 スピーチ全文（約30分）

### 0. つかみ（2分）

```
皆さん、こんにちは。
ひじくろこうじです。

今日は、お忙しい中、そしてお休みのところ、
この会場に足を運んでいただき、ありがとうございます。

今日は、私の演説を聞きに来た、というより、
「宇土のこれからを、一緒に考えに来た」。
そんなふうに思っていただけたら、嬉しいです。

これからの30分。
私は、宇土の今を、できるだけ正直にお話しします。
良いことも、そうでないことも。
そのうえで、これからの宇土を、皆さんと一緒に描きたいと思います。
```

### 1. 私の原点（4分）

```
はじめに、少しだけ私自身の話をさせてください。

私は、宇土で生まれ育ちました。
宇土小学校、宇土東小学校、鶴城中学校。
そして宇土高校を出て、熊本大学へ進みました。

大学を出たあとは、東京のIT企業で働きました。
海外で暮らした時期もあります。
外から宇土を見て、あらためて思いました。
私は、この宇土が好きなのだと。

だから、熊本に戻ってきました。
そして、二つの活動に出会います。

一つは、地域の活動です。
宇土の食を、宇土の景色の中で味わう。
「宇土飯を喰らう会」という、小さな集まりから始めました。

もう一つは、災害支援です。
熊本地震。そして、たび重なる豪雨災害。
私は、その現場に立ち続けました。

その中で、私は学びました。
いざという時に、人を支えるもの。
それは、ふだんからのつながりです。

困ってから動いても、間に合わないことがあります。
人と人、地域と行政。
そのつながりを、平時からつくっておく。
その役割を、誰かが担わなければならない。

そう考えて、私は4年前、市議会議員に立候補しました。
議員になることが、目的ではありませんでした。
子どもたちが誇れる宇土を残したい。
その思いが、すべての始まりです。
```

### 2. 1期目の学び（5分）

```
おかげさまで、私は1期目の4年間を務めさせていただきました。
まず、心から御礼を申し上げます。
ありがとうございました。

この4年、私は一つのことを、自分に課しました。
毎回の議会で、必ず質問に立つ。
逃げずに、問い続ける。

その数は、4年間で約77回になりました。
子どもの学び。子どもの居場所。
公共施設。防災。地域の産業。

正直にお話しします。
議員は、予算を決める立場ではありません。
私ひとりで、すべてを変えることはできません。

それでも、できることがあります。
課題を見つけ、議会で問い、市が動く後押しをする。
市民の皆さんの声を、市政に届ける。

たとえば、子どもたちの居場所づくり。
たとえば、学校のタブレットを、本当に学びに活かすこと。
こうしたテーマを、私は1期目から問い続けてきました。

そして、問えば問うほど、見えてきたことがあります。
宇土の、ありのままの姿です。
1期目は、私にとって「学びの4年」でした。
次は、その学びを、行動に変えていきたいと思います。
```

### 3. 宇土の現実（6分）

```
ここからは、少し数字の話をします。
難しくは、しません。
皆さんの暮らしに関わる話として、聞いてください。

まず、人口です。
宇土の人口は、3万5千人台まで減りました。
毎年、少しずつ減り続けています。
65歳以上の方の割合は、3割を超えました。

次に、公共施設です。
学校や公民館など、市の施設は142あります。
そのうち4割以上が、古い耐震基準のままです。
建て替えや修繕に必要なお金は、毎年15億円以上、足りていません。

そして、産業です。
宇土の農業の担い手は、この20年で半分になりました。
お店や事業所の数も、少しずつ減っています。

市の財布も、楽ではありません。
自由に使えるお金には、ほとんど余裕がない。
そういう状態です。

……厳しい数字が続きました。
不安に思われた方も、いるかもしれません。

でも、ここで一番大切なことをお伝えします。
私は、悲観していません。

なぜなら、これらは「知ることができた」課題だからです。
見えない問題は、解けません。
けれど、見えた課題には、必ず手を打てます。

大事なのは、先送りしないこと。
ごまかさないこと。
そして、市民の皆さんと一緒に考えることです。
数字を直視する勇気さえあれば、宇土の未来は、変えられます。
```

### 4. 5つの挑戦（8分）

```
そこで私は、これからの宇土へ、5つの挑戦を掲げます。

一つ目。
人口が減っても、暮らしを支える土台をつくること。

施設の話を、思い出してください。
全部をこのまま持ち続けるのは、難しい。
そのままでは、負担が子どもたちの世代に回ります。

だから、「減らす」か「残す」かではありません。
建物をまとめたり、別の使い方に変えたりして、必要な機能は守る。
そして、その決め方を、市民の皆さんに開いて、一緒に選ぶ。
人口が減っても、安心して使い続けられる宇土へ。

二つ目。
子どもたちが、誇れる宇土へ。
これが、私の原点です。

一つ、良い報告があります。
保育所の待機児童は、ゼロにできました。
けれど、放課後の学童保育は、まだ足りていません。
4つの地区で、定員を超えています。

子育てしやすいまちかどうか。
それは、若い世代が宇土に住みたいと思えるかを、左右します。
次の世代が宇土を選ぶこと。
それが、人口減少への、一番の答えです。
だから次は、学童に取り組みます。

三つ目。
宇土が、自分で稼ぐ力を育てること。

「使う」話ばかりでは、続きません。
ふるさと納税や、地域の産品をまとめて売る仕組み。
こうした力で、お金を地域に呼び込みます。
補助金に頼るのではなく、地域の中でお金がめぐる形へ。
稼ぐ力は、子育ても、福祉も、暮らしも支える力になります。

四つ目。
行政任せにせず、ともに創る宇土へ。

人口が減れば、市役所の人も、予算も限られます。
行政だけで、全部を担うのは難しい時代です。
私が災害支援で学んだのは、支え合う力でした。
その力を、ふだんのまちづくりにも、活かしていきます。

五つ目。
見える化と対話で、未来を考える宇土へ。

市のお金や施設の様子を、誰もが見えるようにする。
見えるから、一緒に考えられます。
難しいことを、やさしく伝える。
それが、私の役割だと思っています。

この5つに共通する目印は、ただ一つです。
「子どもたちが誇れるか」。
私は、すべての判断を、この物差しで考えます。
これが、私の掲げる UTO PRIDE です。
```

### 5. 財源と進め方（3分）

```
ここで、こう思われた方もいるはずです。
「財源は、どうするのか」と。

新しい負担は、求めません。
私の考えは、三つの言葉に集約されます。
「縮める。稼ぐ。組み替える」。

縮める。
施設をまとめ、民間の力も借りて、無駄を抑えます。

稼ぐ。
ふるさと納税や地域の産品で、入ってくるお金を増やします。

組み替える。
今あるお金を、子どもや未来へ、向け直します。

新しい財布をつくるのではありません。
今ある力を、未来へ向け直す。
そして何より、一人で決めません。
市民の皆さんと対話しながら、一歩ずつ進めていきます。
```

### 6. 締め（2分）

```
最後に、もう一度だけ、申し上げます。

1期目は、学びの4年でした。
2期目は、行動の4年にしたいと思います。

宇土には、課題があります。
でも、それ以上に、可能性があります。
海も、川も、人の温かさも。
誇れるものが、たくさんあります。

私が目指すのは、たった一つです。
子どもたちが、「宇土に生まれてよかった」と思える。
そんなまちです。

世代を超えて。
立場を超えて。
ともに、共に。

10年後の宇土を、今日ここから、一緒に育てていく。
そのために、私は、学びを行動に変えていきます。

今日は、最後までお聞きいただき、ありがとうございました。
このあとは、ぜひ皆さんの声を、聞かせてください。
```

## 💬 対話・質疑応答 運営ガイド（30分）

### 進め方の型
1. **趣旨説明（1分）**: 「ここからは、皆さんと一緒に考える時間です。賛成も、ご心配も、どんな声でも歓迎です」
2. **挙手 → 指名**: 司会（後援会スタッフ）が進行。1人1問を目安に
3. **回答（1問2〜3分）**: 下記の心得に沿って
4. **時間管理**: 残り5分で「最後の質問」を告知 → 締めの一言

### 回答の心得（スタイルガイド準拠）
- **まず受け止める**。「良い問いをありがとうございます」「ご心配、もっともです」
- **人や立場を責めない**。問題があるのは「仕組み」と捉える
- **わからないことは正直に**。「確認して、後日お答えします」は誠実さ
- **一問一答を短く**。長い演説で返さない
- **最後は前向きに**。不安で終わらせず、次の一歩を示す
- 数字は**確認済みのものだけ**。あいまいな数字は言わない

### 場の空気づくり
- 厳しい質問ほど、笑顔で「ありがとうございます」から入る
- 専門用語が出たら、その場で言い換える
- 高齢の方・お子さん連れにも目を配り、ゆっくり話す
- 対立を煽る質問には乗らない。「対立より、一緒に考えたい」と返す

## 🛡️ 講演会 想定問答（ライブ版）

> 守りの[[civic/election-2026/candidates/hijikuro-koji/qa-defense|想定問答集]]＋市民向けQ&Aを、講演会の現場用に再編。声に出す前提の言い回し。

### 政策の核心

**Q.「5つもあると、結局どれが一番なのか分からない」**
> ありがとうございます。正直に申し上げます。一番は、二つ目の「子どもたちが誇れる宇土」です。残りの4つは、それを支える土台だと考えています。判断に迷ったときは、いつも「子どもたちが誇れるか」に立ち返ります。

**Q.「公共施設を減らすと、私たちの地域の施設もなくなるのか」**
> ご心配は、もっともです。お約束します。「なくす」ことが目的ではありません。建物をまとめたり、別の使い方に変えたりして、必要な機能は守ります。そして、私の地元も例外にはしません。何より、決め方を皆さんに開いて、一緒に選びたいと思っています。

**Q.「子育て支援というが、高齢者には関係ないのでは」**
> いいえ、関係します。子どもが誇れるまちは、すべての世代にとって良いまちです。若い世代が宇土に残れば、地域は元気になり、税収も支えられ、高齢の方の暮らしも守りやすくなります。世代は、つながっています。

### 実績・人物

**Q.「現職として、4年で何ができたのか」**
> 議員は、予算を決める立場ではありません。それでも、4年で約77回、議会で問い続けてきました。子どもの居場所や、学校のデジタル環境など、市が動く後押しをしてきました。1期目は「学びの4年」。次は、その学びを行動に変える番だと思っています。

**Q.「会社も経営しているが、議員と両立できるのか」**
> ご質問ありがとうございます。法令を守り、市との取引などは厳格に避けます。そのうえで申し上げれば、現場で経営をしてきたからこそ、「稼ぐ視点」を市政に持ち込めると考えています。

### 財源・実現性

**Q.「やりたいことは分かったが、お金はあるのか」**
> 大事なご指摘です。新しい負担は求めません。「縮める・稼ぐ・組み替える」。今あるお金を、未来へ向け直します。一度に全部はできません。優先順位をつけて、一歩ずつ進めます。

**Q.「どうせ何も変わらないのでは」**
> そう感じておられること自体が、私は課題だと思っています。変化はゆっくりです。でも、4年前と比べて、議会で語られる課題は確実に増えました。小さな一歩を、積み重ねます。10年後に振り返って「あの時から変わった」と思える宇土にしたいです。

### 投票・参加

**Q.「投票しても意味があるのか」**
> 投票率は、この16年で20ポイント以上下がりました。でも、一票は、宇土の未来を選ぶ一票です。投票に行くこと。それ自体が、まちづくりへの参加です。ぜひ、皆さんの意思を聞かせてください。

### 想定外の質問への備え
- **個別の苦情・陳情**: 「大切なお話です。後ほど個別に伺わせてください」と受け、連絡先を案内
- **答えられない数字**: 「確認して、責任を持ってお答えします」
- **挑発・対立を煽る質問**: 「対立をつくるより、一緒に考えたいと思っています」と静かに返す
- **長くなる質問者**: 司会が「ありがとうございます、論点は◯◯ですね」と要約してつなぐ
