## 📄 チラシ／リーフレット文面（A4想定）

### 表面
```
　　子どもたちが誇れる宇土へ。
　　　　　　　UTO PRIDE

　　宇土市議会議員　土黒功司（ひじくろこうじ）
　　― 学びを、行動に。共に、ともに。―

　私は、議員になることが目的ではありませんでした。
　子どもたちが誇れる宇土を残したい。
　その一心で、地域活動を続けてきました。

　1期目の4年間、毎定例会で問い続けました（約77回）。
　2期目は、その学びを「行動」に変えます。
```

### 裏面：宇土を進化させる5つの挑戦
```
① 人口減少時代に適応する宇土へ
   施設・財政の先送りをやめ、次世代にツケを残さない

② 子どもたちが誇れる宇土へ        ★最優先
   GIGA・居場所・子育て支援。子どもをまんなかに

③ 稼ぐ力のある宇土へ
   ふるさと納税・地域商社で「稼ぐ宇土」へ

④ 行政任せではない共創の宇土へ
   官民・市民がともに。防災・共助の力を平時にも

⑤ データと対話で未来を考える宇土へ
   市のお金や施設を「見える化」し、一緒に考える

　財源は「縮める・稼ぐ・組み替える」。
　新しい負担ではなく、今ある力を未来へ。

　［プロフィール／QR：詳しい政策はこちら］
```

### 5つの挑戦シリーズ（1日1投稿）
```
【挑戦①】人口減少時代に適応する宇土へ
40年で必要な施設更新は1,355億円、足りないのは年15.5億円。
「先送り」はもう終わり。痛みも含めて、対話で決めます。
#UTOPRIDE #宇土市議会議員選挙

【挑戦②】子どもたちが誇れる宇土へ ★私の原点
GIGA活用、子どもの居場所、こどもまんなか。
1期目から問い続けてきました。子どもを、まんなかに。
#UTOPRIDE

【挑戦③】稼ぐ力のある宇土へ
ふるさと納税と地域商社で「稼ぐ宇土」を。
補助金頼みから、循環する経済へ。
#UTOPRIDE

【挑戦④】行政任せではない共創の宇土へ
災害支援で学んだ「共助」を、平時のまちづくりに。
行政任せにしない。共に、ともに。
#UTOPRIDE

【挑戦⑤】データと対話で未来を考える宇土へ
市のお金と施設を「見える化」して、みんなで考える。
難しいことを、やさしく。それが私の役割です。
#UTOPRIDE
```

## 🎤 街頭演説 原稿

### 30秒版（辻立ち・選挙カー停車時）
```
宇土市議会議員候補、ひじくろこうじです。
私は、子どもたちが誇れる宇土をつくりたい。
1期目の4年、毎定例会で問い続けました。
2期目は、その学びを行動に変えます。
人口減少に適応し、子どもに投資し、稼ぐ宇土へ。
共に、ともに。ひじくろこうじに、もう一度お力を。
```

### 3分版（個人演説会・構成）
```
1【つかみ】私は議員になることが目的ではありませんでした。
　地域活動と災害支援の中で、民間と行政をつなぐ必要を痛感し、立ちました。

2【実績】1期目、毎定例会で約77回問いました。
　GIGA、子どもの居場所、公共施設、防災…前回トップで頂いた信任に、
　全力で応えてきました。でも「問う」だけでは足りない。

3【課題の直視】宇土は人口減少と、年15.5億円の施設更新ギャップに直面しています。
　先送りはできない。でも悲観もしない。

4【ビジョン】だから5つの挑戦を掲げます。
　（5つの挑戦を一言ずつ）
　最優先は、子どもたちが誇れる宇土。UTO PRIDE です。

5【財源】財源は「縮める・稼ぐ・組み替える」。新しい負担は求めません。

6【締め】学びを、行動に。世代を超えて、立場を超えて、共に、ともに。
　宇土市を次の時代へ進化させます。ひじくろこうじを、宇土市議会の壇上へ。
```
