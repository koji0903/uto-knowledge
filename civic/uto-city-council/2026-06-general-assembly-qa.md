# 令和7年6月定例会 一般質問 構成案

**テーマ**: 「人口減少時代における宇土市の構造改革について」

---

## 📋 質問の全体構造

本一般質問は、以下の考え方に基づいて構成する：

### 質問のタイプ
- **非 個別要望型** - 特定事業や予算要求ではない
- **非 単発課題型** - 特定の問題ではなく総合的なテーマ
- **非 陳情型** - 市民の代理申し立てではない

### 本質的な問い
**「人口減少時代において、宇土市をどう経営していくのか」**

### 質問の軸足
- 光井市長就任後初期議会における政策方向性
- [[civic/uto-city-council/mitsuii-mayor-manifesto|光井市長マニフェスト]]
- [[civic/concepts/population-decline|人口減少]]・[[civic/concepts/fiscal-constraint|財政制約]]の現実
- [[civic/finance/uto-city-public-facilities|公共施設の更新・維持管理]]
- [[civic/concepts/local-economy|地域経済の持続性]]
- [[civic/concepts/civic-participation|市民参画の仕組み]]

### 根本的な問掛け
**「理念をどう実装するのか」**

---

## 🎯 質問①: 人口減少時代における市政運営と政策判断

### 質問趣旨

市長は市長選マニフェストにおいて、防災、子育て、教育、健康、地域経済など幅広い政策を掲げられている。

一方で、以下の構造的制約が存在する：

- **人口減少・少子高齢化** の加速
- **担い手不足** による業務・事業の実行困難
- **財政制約** の進行
- **公共施設更新・維持管理費の増加** （議会でも継続的に議論）
- **限られた財源・人材** での持続可能な行政運営の必要性

### 具体的な質問項目

1. **政策優先順位の判断基準**
   - 今後の市政運営において、市長はどのような考え方で政策の優先順位を判断していくのか
   - マニフェストの掲げた複数の政策がある中での、選別・フォーカスの基準は何か

2. **構造改革への認識**
   - 人口減少時代においても持続可能な自治体経営を行うため、どのような構造改革が必要と考えているのか
   - 従来の「横並び行政」から脱却する方針はあるか

3. **公共施設・行政サービスの方向性**
   - 公共施設の維持や行政サービスの提供について、今後どのような方向性で取り組んでいく考えか
   - 統廃合、機能集約、[[civic/concepts/public-private-partnership|民間連携]]など、具体的な手法について（[[civic/finance/uto-city-public-facilities|公共施設問題]] 参照）

### この質問の狙い

| 側面 | 内容 |
|------|------|
| **問う対象** | 「何をやるか」ではなく「どう判断するのか」 |
| **位置づけ** | 公共施設問題・財政問題・行政サービス維持を「人口減少時代の自治体経営問題」として統合 |
| **対市長** | 「構造改革への覚悟」を問う |
| **期待される答弁** | 理念的な施策羅列ではなく、制約条件の中での優先順位・判断基準の明示 |

## 💼 質問②: 「仕事とにぎわいのある宇土」の実現に向けた地域経済戦略

### 質問趣旨

市長はマニフェストにおいて「仕事とにぎわいのある宇土」を掲げられ、以下の施策を提示：

- 農業・漁業支援
- 起業創業支援
- [[civic/concepts/public-private-partnership|民間との共創（民間連携）]]
- 観光振興
- [[civic/concepts/station-redevelopment|駅周辺再生]]

人口減少社会においては、**単発的な施策ではなく、地域内で経済が循環し、持続的に稼ぐことのできる地域構造**を構築することが必須である。

### 具体的な質問項目

1. **地域経済の軸の選択**
   - 宇土市として今後どの産業を地域経済の軸としていく考えか
   - 産業間の優先順位・フォーカスについて

2. **経済循環の構築**
   - 農業、漁業、商業、観光、起業支援などをどのように結び付け、地域内経済循環を高めていく考えか
   - 各産業セクターの連携メカニズムについて

3. **民間との共創の具体化**
   - 「民間との共創」について、今後どのような分野で民間連携を進めていく考えか
   - [[civic/concepts/public-private-partnership|官民連携]]の対象産業・事業・分野の具体イメージ

4. **長期的な経済ビジョン**
   - 人口減少時代における地域経済活性化について、市長はどのような将来像を描いているのか
   - 10年後、20年後の宇土市の経済構造のイメージ

### この質問の狙い

| 側面 | 内容 |
|------|------|
| **問う視点** | 「イベント型活性化」ではなく「地域経済構造」 |
| **統合的視野** | 農業、漁業、商業、観光、起業、DX、民間投資を "点" ではなく "構造" として問う |
| **民間連携の本質** | 「単なる委託・補助金」ではなく「地域課題を共に解決する構造」をどう設計するか |
| **期待される答弁** | 産業セクター間の具体的な連携戦略、民間投資・参加の仕組み |

## 👥 質問③: 「話を聞く市役所」の実現と行政運営

### 質問趣旨

市長はマニフェストにおいて「話を聞く市役所、動く市役所」を掲げられている。

人口減少や価値観の多様化が進む中、行政には以下が求められる：

- **多様な市民ニーズの把握** - 従来の方法では届かない声
- **政策形成への反映** - 市民の声の可視化と政策化
- [[civic/concepts/civic-participation|市民参画の仕組み]]の充実 - 若者・現役世代・子育て世代の参加
- **[[civic/concepts/dx-strategy|DX・データ活用]]** - 行政意思決定の高度化

### 具体的な質問項目

1. **市民の声の吸い上げと政策反映**
   - 市長は、市民の声をどのように市政へ反映していく考えか
   - 現在の公聴制度（市民説明会、アンケート等）の拡張・改善をどう考えるか

2. **潜在的な市民層への届け方**
   - 若者、現役世代、子育て世代など、これまで市政参加が限定的だった層の意見をどのように把握していく考えか
   - SNS、オンラインプラットフォーム等の活用について

3. **市民の声の可視化と政策へのフィードバック**
   - 市民の声を可視化し、政策形成や行政運営へつなげるため、[[civic/concepts/dx-strategy|データ活用やDX]]についてどのように取り組んでいく考えか
   - 市民参加→政策化→評価のサイクルの構築について

4. **人口減少時代における行政体制**
   - 人口減少時代における行政運営において、今後の職員体制や働き方改革についてどのような認識を持っているのか
   - **職員不足**、**業務量増加**、**行政効率化**のジレンマへの対応

### この質問の狙い

| 側面 | 内容 |
|------|------|
| **掘り下げ** | 「話を聞く」を、実際の政策形成プロセスまで掘り下げる |
| **統合的視野** | 市民参加、若者参加、データ活用、DX、行政意思決定の変革を統合的に問う |
| **行政体制** | 人口減少による職員不足への認識・対応を確認 |
| **期待される答弁** | 市民参画の具体的な仕組み、DX戦略の方向性、職員体制への現実的認識 |

## 🎯 一般質問 全体の狙い

### 根本的な問掛け

**「宇土市をどう経営していくのか」**

この一般質問では、以下の領域における根本的な経営判断を市長へ問う：

| 領域 | 課題 |
|------|------|
| **組織経営** | [[civic/concepts/population-decline\|人口減少]]の中での優先順位設定・資源配分 |
| **財政経営** | [[civic/concepts/fiscal-constraint\|財政の持続可能性]]と[[civic/finance/uto-city-public-facilities\|公共施設問題]] |
| **経済戦略** | [[civic/concepts/local-economy\|地域経済の構造設計]]と[[civic/concepts/public-private-partnership\|民間連携]] |
| **市民参加** | [[civic/concepts/civic-participation\|市民の声の政策化]]と[[civic/concepts/dx-strategy\|DX活用]] |
| **組織体制** | 職員体制の持続可能性 |

### 質問の特徴

| 特徴 | 説明 |
|------|------|
| **単なる批判ではない** | 「〜は間違っている」ではなく、「〜をどう実装するのか」を問う |
| **マニフェスト実装の確認** | 選挙公約の理念が、制約条件下でどう具体化されるのかを確認 |
| **構造的課題を統合** | 個別の課題ではなく、人口減少時代の自治体経営の根本を問う |
| **市長の覚悟を確認** | 「従来の延長線では対応不可能」との認識と、その先の戦略を確認 |

### 期待される答弁の質

| 次元 | 内容 |
|------|------|
| **理念レベル** | 人口減少時代の自治体経営への哲学・基本姿勢 |
| **戦略レベル** | マニフェストの複数施策を、どう優先順位付けし、統合するか |
| **実装レベル** | 具体的な組織、予算、人事の変更予定 |
| **覚悟レベル** | 従来の「できるだけ対応」から「選択と集中」への転換覚悟 |

---

## 📊 質問の連続性

```
質問①：人口減少時代の市政運営
    ↓
   「どう判断するのか」
    ↓
質問②：地域経済の持続的な構造設計
    ↓
   「どう経済循環を作るのか」
    ↓
質問③：市民参加と行政の変革
    ↓
   「どう市民とともに実装するのか」
```

3つの質問を通じて、**人口減少時代における宇土市の総合的な経営戦略**を浮き彫りにする。
