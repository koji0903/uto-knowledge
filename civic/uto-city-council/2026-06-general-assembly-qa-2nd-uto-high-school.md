# 令和8年6月定例会 一般質問②

## テーマ

**「宇土高校との連携による地域人材育成と地域課題解決について」**

---

## 📋 質問の全体構造

### 本質的な問い

**「宇土高校を『支援される存在』としてだけではなく、『宇土市の未来を共につくるパートナー』として、いかに連携していくか」**

### 質問の位置づけ

- 単なる「高校支援」ではない
- **地域人材育成戦略**として捉える
- **地域課題解決の主体**として高校生を位置づける
- 市長マニフェスト「学びと誇りのある宇土」の具体化

### 所管別の質問設計

| 質問 | 所管 | 観点 |
|------|------|------|
| ①②③ | 企画財政部 | 現状認識・方向性・具体的連携 |
| ④ | 教育部 | 教育理念としての地域人材育成 |
| ⑤ | 市長 | 宇土市の未来戦略としての高校活用 |

---

## 🎯 質問①: これまでの宇土市と宇土高校との連携について

### 質問対象
**企画財政部**

### 質問内容

宇土市総合戦略では、以下が掲げられている：

- 「こどもや若者が探求しチャレンジできる環境づくり」
- 「宇土高校魅力化支援」

また、宇土高校はSSH指定校として、地域課題研究や探究活動に取り組まれている。

**そこでまず、これまで宇土市として、宇土高校とどのような連携・取組を行ってきたのか、企画財政部としての認識をお伺いします。**

### この質問の狙い

| 項目 | 内容 |
|------|------|
| **目的** | 市側の現状認識を話させる |
| **確認する要素** | • 現在やっている取組<br>• 所管の整理<br>• 庁内体制の把握 |
| **重要性** | ★★★★★ 基礎となる現状確認 |
| **期待される答弁** | 具体的な連携事例、体制の説明 |

---

## 🎯 質問②: 宇土高校魅力化支援の具体的方向性について

### 質問対象
**企画財政部**

### 質問内容

宇土市総合戦略及び市長マニフェストでは、「宇土高校魅力化支援」が掲げられている。

一方で、市長マニフェストでは、「宇土高校の魅力を最大限にいかす支援方法を検討」とされている。

**そこで、現在、宇土市として、宇土高校魅力化支援をどのような方向性で考えているのか、また、今後どのような連携を想定しているのか、お伺いします。**

### この質問の狙い

| 項目 | 内容 |
|------|------|
| **目的** | 「検討」の中身を言語化させる |
| **問う対象** | 具体的な支援方向の方針 |
| **重要性** | ★★★★★ かなり重要 |
| **引き出し** | 市長マニフェストの実装イメージ |
| **期待される答弁** | 魅力化支援の具体的な方向性、連携の想定 |

---

## 🎯 質問③: 地域課題研究との連携について

### 質問対象
**企画財政部**

### 質問内容

宇土高校では、地域課題や社会課題をテーマとした探究活動・課題研究が行われている。

例えば、以下は宇土市にとっても重要な政策課題である：

- 公共交通
- 防災
- 商店街活性化
- 環境
- 人口減少
- 地域産業

**そこで、宇土高校の探究活動と、宇土市が抱える地域課題を接続し、以下などを進める考えはないか、お伺いします：**

- データ提供
- フィールド提供
- 成果発表
- 意見交換
- 実証的取組

### この質問の狙い

| 項目 | 内容 |
|------|------|
| **目的** | 「高校生＝地域課題解決主体」という流れを作る |
| **重要性** | ★★★★★ かなり強い質問 |
| **視点** | 高校との単なる「協力」から「主体的参加」へ |
| **具体的連携** | データ提供、フィールド提供、実証的取組等の具体化 |
| **期待される答弁** | 課題共有の具体的方法、高校との連携スキーム |

---

## 👥 質問④: 若者への学びと地域参画について

### 質問対象
**教育部**

### 質問内容

宇土高校SSHでは、探究活動を通して、地域課題を自ら考え、発信する取組が行われている。

人口減少時代において、若者が地域と関わり、地域への誇りや当事者意識を持つことは重要である。

**そこで、宇土市として、若者が地域課題へ関わる学びや地域参画について、どのように考えているのか、教育部の認識をお伺いします。**

### この質問の狙い

| 項目 | 内容 |
|------|------|
| **所管** | 企画財政部から **教育部** へ |
| **観点** | 「地域人材育成」という **教育理念** 側からの位置づけ |
| **重要性** | ★★★★★ 重要 |
| **視点** | 教育と地域課題のつながり |
| **期待される答弁** | 地域人材育成の理念、若者参画の考え方 |

---

## 🎯 質問⑤: 宇土高校を活かした今後のまちづくりについて

### 質問対象
**市長**

### 質問内容

宇土高校は、宇土市唯一の高校であり、SSH指定校として全国レベルの探究活動に取り組まれている。

また、市長マニフェストでは、以下が掲げられている：

- 「学びと誇りのある宇土」
- 「若者・女性の声が届く」
- 「宇土で働く、宇土で挑戦する」

人口減少が進む中、これからは「人材への投資」が重要になると考える。

**そこで最後に、宇土高校を、『支援される存在』としてだけではなく、『宇土市の未来を共につくるパートナー』として、今後どのように連携し、宇土市のまちづくりへ活かしていく考えか、市長の答弁を求めます。**

### この質問の狙い

| 項目 | 内容 |
|------|------|
| **質問構造** | 現状確認 → 方向性確認 → **市長の未来ビジョン** |
| **フレーミング** | 「救う」ではなく「**未来戦略として活かす**」 |
| **重要性** | ★★★★★ 最重要 |
| **視点** | 市長としての総合的なまちづくり戦略 |
| **期待される答弁** | 宇土高校との連携の長期ビジョン、人材投資戦略 |

---

## 📊 質問構成の強み

### なぜこの構成か

```
質問①：現状確認（市側の取組）
    ↓
質問②：方向性確認（マニフェスト実装）
    ↓
質問③：具体的連携（地域課題解決）
    ↓
質問④：教育理念（若者参画）
    ↓
質問⑤：市長ビジョン（未来戦略）
```

### 構成的な特徴

| 特徴 | 効果 |
|------|------|
| **いきなり批判しない** | 信頼構築し通りやすくなる |
| **段階的な深掘り** | 答弁の矛盾や課題を浮き彫りにする |
| **所管別の構成** | 庁内の連携体制の課題を抽出できる |
| **市長で統合** | 総合的な戦略意図を確認できる |

### 極めて重要なポイント

**「宇土高校を救う」ではない**

何度も強調するが、本質は：

> **「宇土市の未来戦略として、宇土高校をどう活かすか」**

これは：
- 自治体経営の視点
- 人材育成戦略の視点
- 地域課題解決の視点
- 人口減少時代の生き残り戦略の視点

から問う質問である。
