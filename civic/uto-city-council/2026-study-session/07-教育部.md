# 議員勉強会 部局別｜教育部

> ⬅ [[civic/uto-city-council/2026-study-session-summary|総合整理]] ／ 📌 財政正本 [[civic/election-2026/current-values|現状値データ集]]

学校教育課・図書館・公民館（中央+7地区）・文化課・給食センター・生涯活動推進課。児童生徒数減少・施設老朽化・地震復旧が重要課題。

---

## 🎓 学校教育課
- 学校運営支援係・教職員支援係・生徒指導係・特別支援係の4係、課長以下25名（会計年度2名）。

### 児童生徒数・学校数
| 区分 | 学校数 | 児童生徒数 | 推移 |
|------|--------|----------|------|
| 小学校 | 7校 | 1,380人 | 減少傾向 |
| 中学校 | 3校 | 709人 | 減少傾向 |
| **合計** | **10校** | **2,089人** | — |

- **令和8年度学級数**：小23学級・中7学級
- 📝 児童生徒数の5年・10年推移、他市比較は**提示なし**（推計含め確認推奨）。

### 教職員（小中学校）
- **小学校**: 約75人（県職員63+市職員12）
- **中学校**: 約37人（県職員32+市職員5）
- **合計**: 約112人

> 宮崎県配置＋市職員（非常勤講師・支援員等）。多子ジャンル支援（特別支援・日本語学習者・スポーツ等）に市が上乗せ配置。

### 特別な配慮が必要な児童生徒
| 区分 | 数値 |
|------|------|
| 特別支援学級在籍 | 約100人 |
| 通級指導・教室 | 約50人 |
| **日本語学習者** | **約30人（主にブラジル系）** |

- **日本語支援体制**：指導者配置・母語の代理者同席・教材整備。多国籍化に対応
- **特別な配慮の生徒**に対する進路支援も実施

### いじめ・不登校
- **いじめ認知件数（R7）**: 約30件（認知ベース、解決の有無別集計は提示なし）
- **不登校児童生徒数（R7）**: 約50人（小中別の内訳なし）
- 📝 「認知ベース」と「実解決」の区別・本人・保護者満足度の指標は**未提示**

### R8地震災害の学校への影響
- **避難所 11月1日時点**：小学校6・中学校0・その他施設
- **校舎被害**：構造体はおおむね安全、外壁・屋根・設備で部分的被害
- **給食再開**：10月中に回復
- **授業再開**：分散登校を経て通常授業へ（正式な「再開日」は別途）

### 災害対応の課題（参考）
- 避難所運営時の学校業務との両立
- 児童生徒の心理的支援（PTSD・不安）の体制

### 学力・学習支援
- **学力テスト（全国学力・学習状況調査）**の結果公表は市で**非公表方針**（個人情報・学校間序列化回避）
- 補習・家庭学習支援は学校ごとに実施（統一指標は提示なし）
- 📝 口頭（T027）：学力の他市・全国比較、学習支援の効果測定は**定量的指標を持たない**

## 📚 図書館（新規施設整備）
- 館長兼務・職員11名（正規2+会計年度9）

### 現在の蔵書・利用（R7）
| 指標 | 数値 |
|------|------|
| 蔵書数 | 89,187冊・点 |
| 年間開館日 | 290日 |
| 登録者数 | 19,970人（人口35,774の 55.8%） |
| 貸出し利用者数 | 17,487人 |
| 貸出し冊数 | 71,252冊 |

### **多目的市民交流施設整備事業** ⭐
- **用途**: 図書館+多世代交流スペース＋子育て交流+学習室+シャワー室+軽食販売
- **位置**: 民間施設跡（パチンコ店）をリノベーション
- **床面積**: 一般図書室 546㎡（現在の1.5倍）、児童図書室 351㎡（現在の5倍）
- **蔵書数**: 約12.7万冊を想定
- **オープン予定**: **令和10年3月**
- **事業費**: **14億800万円**（R7第4回定例会で債務負担行為設定済）
  - 本体等工事費・進入路新設工事費・備品購入費・監理業務委託費
  - **別途、R9年度に備品購入費・移転費用等が必要**（合計額未確定）
- **財源**: 地域未来交付金（国1/2）、一般補助施設整備等事業債
- **運営方法**: 指定管理者制度導入予定
- **実施体制**: 元テレビ局アナウンサー本橋馨氏を事業プロデューサーとして招聘
- **関連施設**: 隣接地に「子どもサードプレイス」「保健センター」。調整池周囲にジョギングコース・運動公園

### 市民アンケート・ワークショップ
- 市民アンケート（R6年度実施）
- 市民ワークショップ（R7年5月・8月開催）
- 設計業務：基本設計・実施設計（R6-7年度）

### 図書館業務の課題（参考）
- 蔵書が限定的 → 新施設で倍以上へ拡大
- 学習スペース不足 → 新施設で大幅増
- 📝 口頭（T028）：R10年3月の開館は工事進捗に依存。移転準備期間・従前施設の跡地活用は**未確定**

## 🎭 文化課
- 文化係、職員7名（学芸員4+会計年度3。被害認定調査室へ学芸員1名異動）

### 文化遺産・博物機能
| 施設 | 指定 | 入館者数（R7） |
|------|------|----------------|
| 宇土市民会館 | — | 40,218人 |
| 大太鼓収蔵館 | 直営 | 5,274人 |
| 網田焼の里資料館 | 指定管理 | 256人 |
| 旧高月邸 | 直営 | 153人 |

### 指定文化財
| 種別 | 件数 |
|------|------|
| 国指定 | 2件 |
| 国登録 | 1件 |
| 市指定 | 11件 |
| **計 災害被害** | **14件** |

- **R8地震被害**: 指定14件＋未指定文化財多数（お堂・祠等）
  - 復旧にあたり国・県補助金等を活用し、有識者等と連携
  - **大太鼓収蔵館・旧高月邸の早期再開を目指す**

### 主要事業（R8年度）
- **轟貝塚保存活用事業**：R5-7で史跡中心部を公有化→ R9-10年度に保存活用検討委員会開催→ R10年度末に整備計画策定予定
- **天神山古墳保存修理事業**: 平成28年地震の災害復旧と継続発掘
- **市内重要遺跡保存活用事業**：有識者による検討委員会で遺跡戦略を策定
- **宇土の雨乞い大太鼓（国指定重要有形民俗文化財）**：後継者育成、年1回のフェスティバル開催
- **新宇土市史編纂事業**で収集した歴史資料の保存と活用
- **轟泉水道・旧高月邸**の国指定に向けた調査研究（文化的景観整備事業）

### 課題
- **宇土市民会館の老朽化**: 昭和47年開館、経年劣化が進行。施設・設備・備品の改修・更新に大きな課題
- **文化財の災害復旧**: 本質的価値を損ねない工法で実施、工期・財源確保

## 🍚 給食センター
- 職員体制：市職員4名＋県職員（栄養教諭）3名＋調理委託28名（九州綜合サービス）**計35名**

### 給食提供
| 項目 | 数値 |
|------|------|
| 配食対象 | 小7校・中3校・幼稚園2園 |
| 給食提供数 | 約3,500食/日 |
| 米飯給食 | 週4回 |
| パン給食 | 週1回 |

### 給食費改定（R8年度から）
| 種別 | 新料金 | 政策対応 |
|------|--------|---------|
| 小学校 | 300円 | **実質無償化（国の負担軽減交付金）** |
| 中学校 | 340円 | — |
| 幼稚園 | 280円 | — |

> **小学校の実質無償化**: 国の学校給食費負担軽減交付金事業により、保護者負担を補助。中学校の無償化は国制度なし → 市単独実施を検討中

### 食物アレルギー対応
- **対応委員会** (H28年度設置)
- 詳細献立表配布・牛乳停止・代替食・除去食提供
- 📝 アレルギー対応がある児童生徒の数・対応成功率・重大事故 は**提示なし**

### 施設の老朽化
- **開設**: 昭和54年 (47年経過)
- **課題**: 調理方式「セミドライシステム（ドライ運用）」、経年劣化で散発的に不具合発生
- **今後の検討課題**: **建て替えの是非・時期・手法** (給食提供継続+工事の両立)
- **施設概要**:
  - 敷地面積: 3,009.7㎡
  - 建物総面積: 1,257.6㎡
