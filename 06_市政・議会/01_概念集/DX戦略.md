# DX戦略・データ活用（宇土市の文脈）

## 📊 定義

**DX（Digital Transformation）**とは、デジタル技術によって行政の業務プロセス、市民サービス、政策意思決定を変革する取り組みを指す。

宇土市においては、人口減少・職員不足の現実を踏まえ、**行政運営の持続可能性を担保する手段**として位置づけられる。

---

## 🎯 DXの3つのレイヤー

### Layer 1: デジタイゼーション（電子化）
- 紙書類のPDF化
- データのデジタル保存
- 窓口手続きのオンライン化

### Layer 2: デジタライゼーション（業務効率化）
- ワークフロー自動化
- RPAによる定型業務の代替
- データ連携基盤の整備

### Layer 3: デジタルトランスフォーメーション（変革）
- データドリブンな意思決定
- 市民との関係性の再構築
- 新しい行政モデルの構築

宇土市の現状：**Layer 1-2 中心**  
目指す方向：**Layer 2-3 への深化**

---

## 📊 データ活用の実例

### [[06_市政・議会/03_財政/overview|宇土市 財政戦略ビューア]]

DXの具体例として、9年度分の決算データを統合・可視化：

- 構造化データ (consolidated-data.json)
- 10種類のビューモード
- CSV形式エクスポート
- 統計分析機能

→ 議会審議、市民説明、政策立案に活用可能

### データソース統合の意義

```
従来:
決算書PDF → 紙の決算書 → 議員が個別に読み込み
    ↓
非効率、活用困難

DX後:
複数データソース → 統合JSON → Webビューア
    ↓
可視化、比較分析、エクスポート可能
```

## 🚨 人口減少時代におけるDXの必然性

### 職員不足への対応

```
人口減少
    ↓
税収減少
    ↓
職員定数の維持困難
    ↓
業務量は変わらない/増加
    ↓
DXによる効率化が「選択肢」ではなく「必須」
```

### 市民サービスの維持

```
窓口での対面サービス
    ↓
維持困難（職員不足）
    ↓
オンライン化、自動化が必須
```
