# 市民参加・市民参画（宇土市の文脈）

## 📊 定義

**「市民参加・市民参画」**とは、行政の意思決定プロセスに市民が関与し、政策形成・実行・評価に寄与する仕組みを指す。

[[06_市政・議会/06_議会/mitsuii-mayor-manifesto|光井市長マニフェスト]]の中核キャッチフレーズ **「話を聞く市役所、動く市役所」** を実装する概念。

---

## 🎯 市民参加のレベル

### 段階モデル

```
Level 1: 情報提供 (Inform)
  ↓ 一方向の情報発信
Level 2: 意見聴取 (Consult)
  ↓ 説明会、アンケート
Level 3: 関与 (Involve)
  ↓ 審議会、ワークショップ
Level 4: 協働 (Collaborate)
  ↓ 共に政策形成・実行
Level 5: 権限委譲 (Empower)
  ↓ 市民が主体的に意思決定
```

宇土市の現状：**Level 2-3 中心**  
目指す方向：**Level 3-4 への深化**

---

## 👥 多様な世代の参加

### 現状の課題

| 世代 | 参加状況 | 課題 |
|------|---------|------|
| **高齢世代** | 積極的 | 既得権の維持志向 |
| **現役世代** | 限定的 | 時間・余裕なし |
| **子育て世代** | 少ない | 平日昼間の会議に参加不可 |
| **若者** | ほぼなし | 情報届かない、関心薄い |

### 改善の方向性

```
1. 時間制約への対応
   - 夜間・休日開催
   - オンライン併用

2. 場所制約への対応
   - SNS活用
   - Webプラットフォーム

3. 関心喚起
   - 高校生・大学生との連携
   - 子育て世代向けの分かりやすい情報
```

## 🛠️ 実装手法

### 既存の仕組み

- 市民説明会
- パブリックコメント
- 各種審議会
- アンケート調査

### 新しい仕組み

- 市民ワークショップ
- オンライン意見投稿プラットフォーム
- SNSによる対話
- データ可視化による意思決定支援
- [[06_市政・議会/01_概念集/DX戦略|DX戦略]] による効率化

## 🏛️ 政策の実装課題

### 公共施設廃止等の難しい意思決定での活用

```
[[06_市政・議会/03_財政/uto-city-public-facilities|公共施設問題]] のような
痛みを伴う意思決定では、市民の理解・合意形成が必須。

市民参加なくして実装できない政策が増えていく。
```
