# 地域経済（宇土市の文脈）

## 📊 定義

**「地域経済」**とは、宇土市内における産業・雇用・消費・投資・税収の循環構造を指す。

人口減少時代において、「地域内で経済が循環し、持続的に稼ぐことのできる地域構造」を構築することが、自治体経営の本質的課題となる。

---

## 🏭 宇土市の産業構造

### 主要産業セクター

| セクター | 説明 | 課題 |
|---------|------|------|
| **農業** | 米、野菜、果樹（ナス・トマト等） | 担い手不足、価格低迷 |
| **漁業** | 有明海・八代海の漁業 | 漁獲量減少、後継者不足 |
| **商業** | 商店街、ロードサイド | 商店街シャッター化 |
| **観光** | マリーナ、レトロ館、物産館等 | 利用者数の伸び悩み |
| **建設業** | 公共工事中心 | 公共投資の縮小 |
| **製造業** | 食品加工等 | 小規模事業者中心 |

---

## 🔗 経済循環の概念

### 「域内循環」の重要性

```
お金の流れ:

[宇土市内]
   生産 → 消費 → 雇用 → 給与 → 消費
   ↑                            ↓
   └────── 循環 ────────────────┘
   ↓
   [域外流出] ←── 大手チェーン、Amazon等

域内循環率を高めることで、
地域内のお金の総量を増やす
```

### 「稼ぐ地域経済」とは

| 観点 | 内容 |
|------|------|
| **稼ぐ** | 域外から外貨を獲得 |
| **循環** | 域内でお金が回る |
| **投資** | 将来への種まき |
| **雇用** | 若者の定着 |

- 観光振興
- [[06_市政・議会/01_概念集/駅前再開発|駅周辺再生]]

### イベント型 vs 構造型

| アプローチ | 説明 | 限界 |
|-----------|------|------|
| **イベント型** | 一過性のイベント・補助金 | 持続性なし |
| **構造型** | 産業連携、域内循環、人材育成 | 効果が出るのに時間 |

**人口減少社会では構造型が必須**
