# 駅周辺再生・駅前活性化

## 📊 定義

**「駅周辺再生」**とは、JR宇土駅周辺エリアを **コンパクトシティの中核** として再構築する取り組みを指す。

[[06_市政・議会/06_議会/mitsuii-mayor-manifesto|光井市長マニフェスト]]の **「仕事とにぎわいのある宇土」** の中核施策。

---

## 🚉 JR宇土駅の現状

### 基本情報

- **路線**: JR鹿児島本線
- **熊本駅まで**: 約15分
- **特急停車**: あり
- **利用者数**: 減少傾向

### 駅周辺の課題

| 課題 | 内容 |
|------|------|
| **空洞化** | 商店街のシャッター化 |
| **公共施設分散** | 庁舎、図書館等が分散 |
| **歩行者環境** | 駐車場優先で歩きにくい |
| **居住** | 駅前のマンション・住宅少ない |
| **就業** | オフィス機能なし |

## 🏗️ 想定される再開発スキーム

### 公共施設の集約化

```
[現状]
庁舎（散在）
図書館（別立地）
交流施設（分散）
福祉事務所（分散）

[再開発後]
駅周辺複合施設
  ├── 庁舎機能（1-2階）
  ├── 図書館機能（3階）
  ├── 交流スペース（4階）
  └── 福祉関連（5階以上）
```

## 💰 財政・経済的意義

### [[06_市政・議会/01_概念集/財政制約と自治体運営|財政制約]] への対応

```
公共施設更新ギャップ: 年15.5億円不足
    ↓
駅周辺複合施設化により
    ↓
- 施設数の削減 → 維持費削減
- 民間活用 → 公的投資の最小化
- 集約による効率化 → 運営費削減
```

### [[06_市政・議会/01_概念集/地域経済|地域経済]] への波及

```
駅周辺活性化
    ↓
人流増加
    ↓
商業・飲食の活性化
    ↓
雇用創出・税収増加
    ↓
さらなる投資の呼び込み
```

## 💡 実装事例（宇土市での施策実例）

### 【事例1】駅周辺の土地利活用検討

**背景**  
駅周辺に未利用地が存在。有効活用による雇用・税収創出が期待される。

**実装施策**
- 宇土駅周辺の土地の利活用について ([[04_データリンク/01_議会活動/10_質問分析/R5-06_中口俊宏_5_インフラ・道路|R5-06 中口俊宏 Q5]])
- 跡地の複合施設化の検討

**進捗**
- R4-12: 初期質問で「安全で安定した水道水」関連で指摘
- R5-03: 継続質問で駅周辺活用を質問 ([[04_データリンク/01_議会活動/10_質問分析/R5-03_中口俊宏_1_インフラ・道路|R5-03 中口俊宏]])
- R5-06: さらに進捗確認

**検討内容**
- 公共施設複合化の可能性
- 民間活用による経費削減
- 雇用創出効果の試算

### 【事例2】JR網田駅等の利活用

**背景**  
市内に複数のJR駅がある。それぞれの駅周辺活性化が必要。

**実装施策**
- ＪＲ網田駅耐震診断結果と今後の動き ([[04_データリンク/01_議会活動/10_質問分析/R5-06_佐美三洋_4_インフラ・道路|R5-06 佐美三洋 Q4]])
- 駅舎改修の検討

**進捗**
- 耐震診断実施済み
- 改修計画の検討段階

---

### 【事例3】駅周辺複合化への議員提案

**背景**  
公共施設の老朽化と維持費増加。駅周辺への複合集約が最適解。

**実装施策**
- 複合化による施設集約
- 民間連携（[[06_市政・議会/01_概念集/公民連携|官民連携]])による建設・運営
- 新庁舎を核とした駅前複合化構想

**目的**
- 公共施設維持費削減 ([[06_市政・議会/01_概念集/財政制約と自治体運営|財政制約]] 対応)
- 駅周辺への人口・機能集約 (コンパクトシティ実現)
- 商業・雇用の創出 ([[06_市政・議会/01_概念集/地域経済|地域経済]] 活性化)

**関連施策**
- [[04_データリンク/02_POLICY_CARDS/finance_facilities/pc_finance_002_city_hall_utilization_revenue|新庁舎利活用]] による実装例
