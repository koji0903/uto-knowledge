# 財政制約（宇土市の文脈）

## 📊 定義

**「財政制約」**とは、自治体の収入（市税・地方交付税等）と支出（人件費・施設維持費・扶助費等）の関係から生じる、政策実行の構造的限界を指す。

宇土市においては、**人口減少と公共施設老朽化**という二重の圧力により、財政制約は今後さらに厳しくなる構造にある。

---

## 🔢 宇土市の財政制約 - 数字で見る現実

### 健全性指標（R6年度）

| 指標 | R6値 | 基準値 | 判定 |
|------|------|--------|------|
| 実質赤字比率 | 黒字 | 15.0% | ✅ 健全 |
| 連結実質赤字比率 | 黒字 | 20.0% | ✅ 健全 |
| 実質公債費比率 | 11.4 | 25.0% | ✅ 健全 |
| 将来負担比率 | 157.4 | 350.0% | ✅ 健全 |

→ **表面的には健全だが、構造的には危機的**

### 構造的な赤字傾向

| 年度 | 実質単年度収支 |
|------|---------------|
| R3 | +5.1億円 |
| R4 | +1.8億円 |
| R5 | **-23.1億円** ⚠️ |
| R6 | **-6.7億円** ⚠️ |

→ R5以降の連続赤字は構造的問題を示唆

### 公共施設更新の年15.5億円ギャップ

```
必要更新費用: 年33.9億円
確保可能予算: 年18.4億円
    ↓
構造的不足: 年15.5億円

→ 40年で約745億円の不足
→ 現実的には施設の45%削減が必須
```

## 🔗 財政制約の発生要因

```
人口減少
    ↓
市税減少（[[06_市政・議会/01_概念集/人口減少|人口減少]] 参照）
    ↓
地方交付税の縮小（国の財政逼迫）
    ↓
↓ 一方で

少子高齢化
    ↓
扶助費の増加
    ↓
公共施設の老朽化
    ↓
公共施設更新費用の増加
    ↓
↓ 結果

「収入は減るが、支出は増える」構造
= 財政制約の悪化
```

## 🎯 政策的含意

### 「すべてはできない」前提

```
従来:「希望する政策はすべて実装する」
    ↓
これから:「制約条件下での選択と集中」
```

### 「断捨離」の必要性

| 領域 | 従来 | これから |
|------|------|---------|
| **施設** | 全施設維持 | 集約・廃止 |
| **サービス** | 全サービス維持 | 選別・効率化 |
| **事業** | 横並び配分 | 重点配分 |
| **イベント** | 既存維持 | 取捨選択 |

## ⚠️ 中長期的なリスクシナリオ

### シナリオ1: 現状維持

```
施設廃止せず、サービス維持
    ↓
財政赤字の累積
    ↓
基金の枯渇
    ↓
財政破綻リスク
```

### シナリオ2: 計画的縮小

```
施設集約、サービス見直し
    ↓
痛みは伴うが財政持続可能
    ↓
将来世代への負担軽減
```

→ **シナリオ2への計画的移行が必須**
