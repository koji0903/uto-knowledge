# 財政制約（宇土市の文脈）

## 📊 定義

**「財政制約」**とは、自治体の収入（市税・地方交付税等）と支出（人件費・施設維持費・扶助費等）の関係から生じる、政策実行の構造的限界を指す。

宇土市においては、**人口減少と公共施設老朽化**という二重の圧力により、財政制約は今後さらに厳しくなる構造にある。

---

## 🔢 宇土市の財政制約 - 数字で見る現実

### 健全性指標（R6年度）

| 指標 | R6値 | 基準値 | 判定 |
|------|------|--------|------|
| 実質赤字比率 | 黒字 | 15.0% | ✅ 健全 |
| 連結実質赤字比率 | 黒字 | 20.0% | ✅ 健全 |
| 実質公債費比率 | 11.4 | 25.0% | ✅ 健全 |
| 将来負担比率 | 157.4 | 350.0% | ✅ 健全 |

→ **表面的には健全だが、構造的には危機的**

### 構造的な赤字傾向

| 年度 | 実質単年度収支 |
|------|---------------|
| R3 | +5.1億円 |
| R4 | +1.8億円 |
| R5 | **-23.1億円** ⚠️ |
| R6 | **-6.7億円** ⚠️ |

→ R5以降の連続赤字は構造的問題を示唆

### 公共施設更新の年15.5億円ギャップ

```
必要更新費用: 年33.9億円
確保可能予算: 年18.4億円
    ↓
構造的不足: 年15.5億円

→ 40年で約745億円の不足
→ 現実的には施設の45%削減が必須
```

## 🔗 財政制約の発生要因

```
人口減少
    ↓
市税減少（[[06_市政・議会/01_概念集/人口減少|人口減少]] 参照）
    ↓
地方交付税の縮小（国の財政逼迫）
    ↓
↓ 一方で

少子高齢化
    ↓
扶助費の増加
    ↓
公共施設の老朽化
    ↓
公共施設更新費用の増加
    ↓
↓ 結果

「収入は減るが、支出は増える」構造
= 財政制約の悪化
```

## 🎯 政策的含意

### 「すべてはできない」前提

```
従来:「希望する政策はすべて実装する」
    ↓
これから:「制約条件下での選択と集中」
```

### 「断捨離」の必要性

| 領域 | 従来 | これから |
|------|------|---------|
| **施設** | 全施設維持 | 集約・廃止 |
| **サービス** | 全サービス維持 | 選別・効率化 |
| **事業** | 横並び配分 | 重点配分 |
| **イベント** | 既存維持 | 取捨選択 |

### シナリオ1: 現状維持

```
施設廃止せず、サービス維持
    ↓
財政赤字の累積
    ↓
基金の枯渇
    ↓
財政破綻リスク

```

```
    ↓
痛みは伴うが財政持続可能
    ↓
将来世代への負担軽減
```

→ **シナリオ2への計画的移行が必須**

## 💡 実装事例（宇土市での施策実例）

### 【事例1】職員の負担軽減・DX推進による支出削減

**背景**  
職員不足と業務量増加の悪循環。DXによる業務効率化が不可欠。

**実装施策**
- 職員の負担軽減への取り組み ([[04_データリンク/01_議会活動/10_質問分析/R4-12_今中真之助_27_行政・財政|R4-12 今中真之助 Q27]])
- DX推進・外部人材活用 ([[04_データリンク/01_議会活動/10_質問分析/R4-12_今中真之助_18_産業・経済|R4-12 Q18, Q26]])
- RPA・自動化による定型業務削減

**効果**
- 労働時間削減 ⚠️要確認
- 支出削減額 ⚠️要確認

**議会での追跡**
- 継続質問により具体的施策を引き出す
- [[04_データリンク/01_議会活動/継続質問ガイド|継続質問ガイド]] 第2段階への応用例

---

### 【事例2】公共施設の指定管理者制度による経費削減

**背景**  
施設運営経費の増加。直営では対応困難。民間委託で経費削減。

**実装施策**
- 体育館（ecowin宇土アリーナ）: 4,005万円/年で指定管理
- 市民会館: 3,700万円/年で指定管理
- 福祉施設: 複数施設を指定管理

**成果**
- 直営との比較で経費削減率 ⚠️要確認
- サービス維持と経費削減の両立

**課題**
- 駐車場不足、設備老朽化への対応
- 利用者満足度の維持

---

### 【事例3】地域経済活性化による自主財源化

**背景**  
地方交付税削減への対抗策。域内経済の活性化により税収増を狙う。

**実装施策**
- 地域商社構想による経済循環強化
- 観光資源の付加価値化 ([[04_データリンク/01_議会活動/10_質問分析/R5-03_今中真之助_19_産業・経済|R5-03 今中真之助]])
- お試し移住・移住促進による転入者増

**目的**
- 市税収入の増加
- 地方交付税圧縮への対抗

**測定指標**
- 市税収入（前年比） ⚠️要確認
- 市内企業の売上 ⚠️要確認
- 転入者数 ⚠️要確認
