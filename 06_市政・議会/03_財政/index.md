- 📉 歳入が前年比-12.6%（R4との比較で大幅減）

**議員向けポイント**:
```

「その年に何が起きているか」を示す重要な指標。

R5の大幅赤字→R6で改善という動きは、
「施設更新事業の年度差」を示唆している可能性がある。

今後の市政運営において、
この赤字構造の本質を問う必要がある。
```
