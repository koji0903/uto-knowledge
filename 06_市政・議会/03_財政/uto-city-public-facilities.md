## ⚠️ 重大課題: 公共施設更新ギャップ

### 数値で見る規模感

| 指標 | 金額 | 単位 | 評価 |
|------|------|------|------|
| **40年間の必要更新費用** | **1,355** | 億円 | ⚠️ |
| **年平均必要額** | **33.9** | 億円 | ⚠️ |
| **現在の確保可能予算** | **18.4** | 億円 | 不足 |
| **年平均不足額** | **15.5** | 億円 | **過多** |
| **必要圧縮率** | **45.9%** | - | **要対応** |

### 問題の本質

```
今後40年間で

必要な更新費用   1,355億円
年平均           33.9億円
    ↓
市が支払える額   18.4億円
    ↓
年15.5億円 の永続的な不足

→ 施設の半分近くを廃棄 or 廃止する必要がある
```

## 🔴 抽出された主要課題

### 課題①: 更新費用の捻出不可能性

**事実**:
- 毎年33.9億円必要
- 毎年18.4億円しか確保不可
- ギャップ: **毎年-15.5億円**

**結果**:
- 40年で1,355億円 → 約745億円の不足
- **施設を45%廃止しないと成立しない**

**対応方針**:
1. 公営住宅の集約化
2. スポーツ施設の統廃合
3. 学校施設の複合化・多機能化
4. 民間活用（PFI/PPP）検討

### 課題②: 旧耐震基準の危機

**事実**:
- 公共建築物の43.6%が旧基準
- 特に学校（児童対象）が危険

**対応**:
- 優先度の高い施設から耐震補強
- または廃止・建替え
- 予算：大型化が必然

### 課題③: 施設の集約・多機能化の遅れ

**必要**:
- 学校機能 + 図書館 + コミセン
- 福祉施設の複合化
- 駅周辺への機能集約

**課題**:
- 用地確保が困難
- 既存施設の利用者調整が難しい

## 🎯 施設戦略の考え方

### 従来の「維持・管理」から「戦略的最適化」へ

| 観点 | 従来 | これから |
|------|------|---------|
| **スタンス** | 既得権維持 | 全施設を査定 |
| **判断基準** | 「持たせる」 | 「何が必要か」 |
| **対象** | 個別施設 | 施設体系全体 |
| **予算配分** | 均等配分 | 重点配分 |
| **民間活用** | 補完的 | 戦略的 |

### 施設集約の具体例

```
【駅周辺複合施設化】

従来:
├── 庁舎（駅から遠い）
├── 図書館（別立地）
├── 交流施設（分散）
└── 福祉事務所（分散）

これから:
└── 駅周辺複合施設
    ├── 庁舎機能（1-2階）
    ├── 図書館機能（3階）
    ├── 交流スペース（4階）
    └── 福祉関連（5階以上）
```
