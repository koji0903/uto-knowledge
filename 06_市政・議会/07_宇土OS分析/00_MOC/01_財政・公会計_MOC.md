# 財政・公会計 MOC

宇土市の普通会計決算、公会計4表、地方債・基金、他会計繰出金に関する構造分析のハブノートです。

> 📌 **数値の正本**: 財政指標の確定値は [[civic/election-2026/current-values#💰 財政（★ 主要指標 基準値：出典・年度つき）|現状値データ集（正本）]] と [[civic/uto-city-council/2025-r7-settlement-analysis|R7決算 精査]] に統一。下記はモデル診断値（年度・基準が異なる場合あり）。

## 📊 構造の核心（公会計アナリスト診断）
1. **固定費率の硬直化**: 固定費率 **94.2%**（モデル値）。※ 経常収支比率の確定値は **95.8%（R6決算）** → 正本参照。義務的経費で税収の大半が消え、政策的自由度が低下。
2. **震災復旧債のピークアウト**: [[自治体経営KPIハンドブック_定義と市民翻訳#実質公債費比率|実質公債費比率]] は **12.0%**（R7健全化判断比率）。R9年度には10%未満の安全圏へ復帰見通し。
3. **基金耐久力**: 財政調整基金は **R7末30.36億円**（確定値）。※従前記載の「35.6億円」はモデル/従前値 → 正本に統一。災害や急激な歳入減へのクッション機能を担う。
4. **他会計繰出の重圧**: 一般会計から特別会計・企業会計へ **年間約16.5億円**（モデル値・世帯あたり年10.3万円）を繰出補填。※R7制度繰入の内訳は [[civic/uto-city-council/2025-r7-settlement-analysis|R7決算 精査]] 参照。
