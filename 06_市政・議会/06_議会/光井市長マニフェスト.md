## 🏛️ 6つの柱別展開

### ① **安心して暮らせる宇土** 🛡️
**スローガン**: 「毎日の不安が、安心に変わるまち」

**基本理念**
- 雨の日も、夜道も、子どもの通学も安心
- 困ったとき、すぐ頼れる医療と交通
- 住み慣れた地域で、ずっと暮らせる

**具体政策**

| 領域 | 施策 |
|------|------|
| **大雨対策** | 松原排水機場改修の早期実現 |
| **氾濫対策** | 緑川、浜戸川、潤川、船場川、網津川、大坪川等の改修の早期実現 |
| **防災対策** | 砂防ダム整備、急傾斜地崩壊対策の早期実現 |
| **こどもの安全** | 通学路の点検・改善 |
| **生活利便向上** | 移動販売、買い物代行、デジタル活用による買い物支援強化 |
| **医療格差改善** | オンライン無料相談（医療）、医療MaaS検討 |
| **交通利便向上** | コミュニティバス増便検討、松原交差点渋滞解消 |
| **人口減少対策** | RMO地域運営組織設立支援、住宅支援制度継続 |

## 🔎 マニフェスト全体の特徴分析

### マニフェストの性質

| 特徴 | 評価 |
|------|------|
| **対立型か継続型か** | 「対立型」ではなく **「行政継続型」** - 従来施策の強化・改善が中心 |
| **重視分野** | 福祉・安心・地域維持を重視 |
| **市民参加** | 「市民の声を聞く」が強い軸として貫通 |
| **施策体系** | ハード整備＋生活支援の **「総花型」** |
| **改革姿勢** | 「構造改革」というより **「改善・調整型」** |
| **根拠の明示** | 財源論・優先順位・KPIが弱い |
| **産業政策** | 民間投資や産業構造転換への踏み込みは限定的 |

### マニフェストの強み

✅ **市民目線**
- 「話を聞く」が通底する
- 生活課題への応答性が高い
- 福祉・安心が重視

✅ **網羅性**
- 6つの柱で多くの領域をカバー
- 防災から文化財保護まで幅広い

✅ **継続性**
- 既存施策の強化であり、組織負担が比較的小さい

### マニフェストの課題・弱点

⚠️ **「何をやるか」の多さ**
- 複数の施策が多数列挙
- 限られた財源・人材での実現可能性が不明確

⚠️ **「何をやめるか」の不在**
- 優先順位の明示がない
- 既存事業との関係性が不明確
- 削減対象が明示されない

⚠️ **人口減少時代への根本的対応の欠如**
- 「行政規模をどう再設計するか」の視点が弱い
- 「維持・継続」から「選択と集中」への転換が見えない
- 限定的なリソースの中でのフォーカスがない

⚠️ **財源・実現性の議論不足**
- 各施策の財源確保方法が明記されない
- 実現スケジュール・段階性が不明確
- KPI（成果指標）が設定されない

⚠️ **産業政策の深さ不足**
- 農業・漁業支援は従来型
- 「地域経済循環」の構造設計が限定的
- 民間投資の呼び込みメカニズムが不明確
- デジタル化・DXへの戦略的位置づけが薄い

⚠️ **市民参加の具体化**
- 「話を聞く」の政策化プロセスが不明確
- 若者・現役世代への到達手段が曖昧
- 市民参加 → 政策化 → 評価 のサイクルが見えない

## ⚡ マニフェスト実装のジレンマ

マニフェストを見ると、いくつかの **「実装のジレンマ」** が浮かぶ：

### ジレンマ1: 「総花型施策」と「限定的リソース」

```
マニフェスト側：
  - 50以上の具体施策を列挙
  - 「これもやります、あれもやります」

現実側：
  - 宇土市の一般財源: 約100億円（概算）
  - 市職員数: 約500名（概算）
  - 毎年、この範囲内で運営

矛盾：
  複数の新規施策を同時実現することは、財政的に不可能
  → 必ず「優先順位」「取捨選別」が発生する
```

### ジレンマ2: 「人口減少」と「行政規模の維持」

```
マニフェスト側：
  - 安全（防災）、教育、福祉、経済...
  - 各領域で充実を掲げている

現実側：
  - 宇土市人口: 減少傾向（年1,000人程度）
  - 税収: 減少
  - 負債（公債費）: 高止まり

矛盾：
  人口が減っているのに、行政サービスを拡充することは難しい
  → 「何をやめるか」「どう再設計するか」が必須
```

### ジレンマ3: 「地域経済の維持」と「産業構造の転換」

```
マニフェスト側：
  - 農業支援、漁業支援、観光、起業、民間連携...
  - 複数の産業セクターを並列で支援

現実側：
  - 労働人口減少
  - 農業・漁業の後継者不足
  - 担い手が限定的

矛盾：
  限定的な担い手で、複数の産業を同時に盛り上げることは難しい
  → 「どの産業を軸にするか」の選択が必須
```

### ジレンマ4: 「市民参加の拡大」と「行政効率化」

```
マニフェスト側：
  - 「話を聞く市役所」
  - 市民参加を重視

現実側：
  - 職員数減少傾向
  - 業務量は増加
  - 働き方改革で残業削減

矛盾：
  職員が減る中で、市民参加対応を増やすことは難しい
  → 「デジタル化」「効率化」が必須
```

## 🎯 一般質問戦略との位置づけ

### 一般質問の根本的な狙い

6月定例会の一般質問は、**マニフェストのこの特性（「何をやるか」の多さと「何をやめるか」の不在）を、市長に直接問い掛ける**ものとして機能する。

具体的には：

```
一般質問①「市政運営と政策判断」
  ↓
「複数の公約がある中で、どう優先順位を付けるのか」
  ↓
マニフェストの「総花型」の矛盾を露呈させる

一般質問②「地域経済戦略」
  ↓
「複数の産業施策を、どう統合し構造化するのか」
  ↓
マニフェストの「産業セクター間の連携不足」を明確にする

一般質問③「市民参加と行政運営」
  ↓
「『話を聞く』を、具体的にどう政策化するのか」
  ↓
マニフェストの「市民参加プロセスの曖昧さ」を問う
```

### 質問の本質的な構図

| 段階 | 内容 |
|------|------|
| **表向きの構図** | 市長のマニフェストの具体化を確認する |
| **本質的な構図** | マニフェストの「曖昧さ」「課題」を、市長自身に気づかせる |
| **目的** | 市長が、「改善・調整型」から「選択と集中」へシフトせざるを得ない状況を作る |

## 💭 マニフェストの解釈・深掘り

### 「話を聞く市役所」の多層的理解

#### 表層的解釈
✗ 「市民の意見を聞く」 → 市民説明会・アンケート

#### より深い解釈
✓ **市民の多様なニーズを可視化し、政策形成プロセスに統合する仕組み**
- 従来型の公聴制度の限界
- 参加できる市民層の限定性
- 「聞きっぱなし」の危険性

#### 実装の課題
1. **ターゲットの多層化**: 若者、現役世代、子育て世代、高齢者など
2. **手法の多様化**: SNS、オンライン、リアルイベント等
3. **政策化プロセスの明示**: 市民の声 → 政策化 → 評価 のサイクル
4. **DX活用**: データ駆動的な市民参加

---

### 「仕事とにぎわいのある宇土」の構造的理解

#### 従来的施策の問題点
✗ イベント型活性化（キャンペーン、祭り等）
✗ 単発的な事業補助
✗ 官主導の「やってあげる」施策

#### マニフェストの問題意識（推定）
✓ **地域内経済循環の構築** - 持続的に稼ぐ仕組み
✓ **民間の創意工夫の活用** - 官民の役割分担
✓ **多産業間の連携** - 農漁業と観光・商業の結合

#### 実装の課題
1. **中核産業の選択**: 農業？漁業？観光？それとも複合か
2. **産業間連携の設計**: 具体的な事業モデル・経済循環の仕組み
3. **民間投資の呼び込み**: 補助金から民間ビジネスへ
4. **起業・イノベーション**: 新規事業による経済創造

## 📊 マニフェスト実現への評価軸

### 進捗評価のポイント

| 評価軸 | 確認事項 |
|--------|---------|
| **理念の明確性** | マニフェストの各施策の背景・価値観は何か |

| **市民との関係性** | 市民参加・協働の仕組みの構築状況 |
