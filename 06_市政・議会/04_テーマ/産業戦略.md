## 🔢 主要データ・産業構造

### 宇土市の主要産業セクター

| セクター | 状況 | 課題 |
|---------|------|------|
| 農業 | 米・野菜・果樹 | 担い手不足、価格低迷 |
| 漁業 | 有明海・八代海 | 漁獲量減少、後継者 |
| 商業 | 商店街・ロードサイド | 商店街シャッター化 |
| 観光 | マリーナ、レトロ館 | 利用伸び悩み |
| 製造業 | 食品加工等 | 小規模事業者中心 |

## 🎯 政策の方向性

### 「点」から「構造」へ

```
従来:「個別施策の集合」
    ↓
これから:「産業間連携 × 域内循環 × 域外稼ぎ × 民間連携」
```

### 地域商社モデルの中核

```
[生産者]      [地域商社]      [販路]
農家     →               →   ふるさと納税
漁師     →   ウトマチ百貨店  →   観光客
製造業者 →               →   首都圏
                              EC・通販
```
