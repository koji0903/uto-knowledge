## 🟢 v2（2026-06-27）｜スタイルガイド準拠版 ⭐

> 伴走者トーン・一文短く・未来で締める。

```
私が市議会議員になったのは、議員になることが目的ではありませんでした。

私は、子どもたちが誇れる宇土を残したい。
その思いで、地域の活動を続けてきました。
議員という役割も、その一つです。

1期目の4年間で、私は宇土の現状と課題を学びました。
学べば学ぶほど、見えてきたことがあります。

人口は減っています。施設は古くなっています。
それでも、悲観してはいません。
課題は、皆さんと一緒に考えれば、必ず手を打てます。

1期目が「学びの4年」だったなら、
2期目は「行動の4年」にしたいと思います。

世代を超えて。
立場を超えて。
ともに、共に。

学びを、行動に変えていく。
そうして10年後、子どもたちが「宇土に生まれてよかった」と思える。
私は、そんな宇土へ、もう一歩を進めます。
```

### v1からの改善点（ガイド準拠）
- 締めを「進化させていきます」→ **未来の情景**（10年後/子どもたちの実感）で終える
- 課題を**構造として静かに提示**（「人口は減っています／施設は古くなっています」）
- 一文をさらに短く分割・スマホ可読性
- 「静かな情熱」のトーン（テンションを上げない）

## 🟡 v1（2026-06-26）｜初稿

> ステータス: 初稿（本人提供原文）

```
私は市議会議員になることが目的だったわけではありません。

子どもたちが誇れる宇土を残したい。

そのために地域活動を続け、
その役割の一つとして市議会議員になりました。

一期目の4年間で宇土市の現状と課題を学びました。

二期目は、その学びを未来への行動につなげる4年間にしたい。

世代を超えて、
立場を超えて、

ともに、共に。

宇土市を次の時代へ進化させていきます。
```

### 構造メモ
- **動機の否定 → 真の目的の提示**：「議員が目的ではない／子どもたちが誇れる宇土」
- **手段としての議員職**：地域活動の延長に位置づけ、生活者目線を担保
- **1期＝学び / 2期＝行動**：成長ストーリーで再選の必然性を語る
- **共創のスローガン**：「世代を超えて／立場を超えて／ともに、共に」
- **締め**：進化（=変化への前向きな約束）
