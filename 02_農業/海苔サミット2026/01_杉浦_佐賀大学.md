# 杉浦氏（佐賀大学）講演メモ

> 演題（推定）: 日本型海苔養殖の次世代化に向けた取り組み

## 1. 講演者プロフィール

- 佐賀大学 杉浦氏
- 経歴: 植物プランクトン・赤潮の研究 → 海藻研究（博士） → 赤潮研究 → 佐賀大学着任
- 佐賀大学で「海苔研究室」「赤潮研究室」を新設（2028年に研究室拡大、2人の教員体制→現在は海苔・赤潮・二枚貝の3テーマを2研究室で担当）
- 専門: 植物プランクトン（赤潮）のウイルス研究がライフワークの一つ
- 今回の講演は「海苔」と「赤潮（有明海）」の2テーマを中心に紹介

## 2. 海苔生産の現状

- 水産庁データ: 海苔生産量は減少傾向
- 要因
  - 需要減少 **以上に** 生産量の減少幅が大きい → 環境変化による生産不能が主因
  - 一方、韓国・中国は海苔生産が右肩上がり（国際競争上の課題）
- 有明海における中心課題
  1. 海苔の生産問題
  2. 赤潮（生産を抑制する要因）
  3. 二枚貝の減少（赤潮を悪化させる要因）

## 3. 悪循環の構造（気候変動 → 赤潮 → 海苔減産）

```
地球温暖化・気候変動
  → 水温上昇
      ├─ 海苔の生産適期（期間）が短縮 → 生産量減少
      └─ 赤潮生物が活性化 → 赤潮深刻化
            → 海域の栄養不足 → 海苔の「色落ち」→ 生産量減少
      → 貧酸素水塊の増加
            → 二枚貝が死滅（貝は逃げられないためダメージ大）
            → プランクトン捕食圧の減少（二枚貝が赤潮のもとを捕食する機能の喪失）
                  （参考: かつての有明海は二枚貝のろ過能力で「1週間で海水が全て入れ替わる」レベルの浄化力があったとされる）
            → 赤潮が減らない
            → 二枚貝が獲れない → 生産者が採取をやめる → 海底が撹拌されなくなる
            → 赤潮の"種"（休眠細胞）が減らされない → 赤潮がさらに増える（スパイラル）
```

- 一つの要因だけを改善するのは困難。複数のポイントに少しずつ介入していく方針。

## 4. 赤潮対策研究（休眠細胞の分布調査）

- 赤潮の元になる植物プランクトンは、増殖前に海底で「休眠細胞（種）」の状態で存在
- 休眠細胞がどこにどれだけ分布しているかを把握することが重要
- 佐賀県海苔漁場での調査例
  - 地点によって休眠細胞の量に大きな差（グラフは対数目盛り、1目盛り=10倍差）
  - 例: 331地点 vs 428地点で桁違いの差
  - 佐賀県という狭いエリア内でもこれだけの差がある
- 活用構想
  - 休眠細胞（＝将来の赤潮の種）が多い地点を特定
  - そこに二枚貝を配置し、捕食させることで赤潮の抑制を狙う
  - 現状: 分布調査手法が複雑なため、より簡易な手法の開発を進めている（研究は「2段階目」の途中）
  - 9月時点では沖合に分布 → 漁期が進むにつれ沿岸側へ分布が移動する傾向も確認（分布は日々変化）
  - → どこを対象に開発（対策）していくかの選定が重要な課題

## 5. 次世代の海苔養殖：陸上養殖について

- 気候変動により、海苔の色落ちに加えて魚・鳥の食害リスクも増加、赤潮増加による栄養増も含め、海面養殖の環境が厳しくなっている
- **陸上養殖**への注目が世界的に高まっている
  - 既存事例（青のり）: 富士すいこ、三島食品など既に産業化
  - スサビノリ（一般的な黒のり）は陸上養殖が難しいとされてきたが、
    - 日本国内で実証事例が登場
    - 韓国でも工場を建設し研究レベルで稼働
  - → 陸上養殖は「確実に今後普及・商用化される」という前提で講演者は捉えている
- **懸念点**
  - 陸上養殖を行う企業だけが儲かり、既存の海苔生産者を守らない構造になるリスク
  - 講演者のスタンス: 陸上養殖の普及は不可避 → 生産者が「陸上養殖を好きになれる」活用方法を模索すべき
- **具体的な活用アイデア**
  - 陸上で色落ちした（品質が落ちた）海苔を、陸上環境でリカバリーしてから出荷する
    - 色を戻すだけでなく、栄養成分・付加価値を高めてから出荷する技術開発
    - 商社側にも「このままの海苔で良いか」という課題意識がある
    - コストはかかるが、開発する価値のある方向性
  - 生海苔と加工海苔で色が変わる現象など、品質にまつわる知見も存在（詳細は今回は割愛）
  - コンセプト: 「困った海苔」を困ったままにせず、より良い形・新しい海苔の形にして出荷する

## 6. 佐賀大学の産官学連携プラットフォーム

- 海苔研究を核に、農業分野にも展開
- 陸上・海面を問わず、大学を中心に「自治体・生産者・企業」をつなぐプラットフォームを構築中
- 背景: 気候変動問題・食料安全保障への大学としての対応
- 体制: 農学部だけでなく複数学部（提携大学含む）が参加
  - 環境（赤潮など）、養殖技術、成分研究（ビタミン等）、ブランディングまで一気通貫
- 目的: 大学の研究成果を生産者支援・地域振興につなげる。教育研究に閉じず、地域を盛り上げる取り組みとして推進

## 7. まとめ・示唆

- 海苔生産の課題は「海苔単体」ではなく、赤潮・二枚貝・水温という複合的な生態系の問題として捉える必要がある
- 陸上養殖は脅威ではなく「生産者がどう使いこなすか」という視点で技術開発する余地がある
- 大学発のデータ・研究を、自治体や企業、生産者と接続するプラットフォームづくりが各地で進んでいる（Utomachi Platform の方向性と親和性が高い）
