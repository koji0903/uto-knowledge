**実装パターン (Repository Pattern)**:
- 各サービスは Firestore への CRUD を隠蔽
- コンポーネントはサービス経由でデータアクセス
- キャッシング・変換ロジックを集約

## 実装パターンのガイドライン

### ① データ取得パターン

1. `src/types/` に型を定義
2. `src/lib/services/` にサービスメソッドを実装
3. コンポーネントでサービスを呼び出し

```typescript
// 例: 会員マスタを取得
const member = await MemberService.getById(id);
```

### ② UIコンポーネント設計

- `src/components/ui/Agri*.tsx` を優先使用
- **農業らしい質感**: 緑ベースのクリーンなデザイン
- Tailwind + Framer Motion で統一感を維持

### ③ ステート管理

- Client Components で React Hooks (useState)
- グローバル状態は Firebase + Context で管理
- Firestore の実時間リスナーを活用
