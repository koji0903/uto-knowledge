# AgriOS 熊有研 - システム概要

## プロジェクト基本情報
- **システム名**: AgriOS 熊有研 (Kumayuken)
- **開発場所**: `/Users/hijikuro/ViveCoding/02_農業/熊本県有機農業研究会`
- **目的**: 農業団体（青年農業者クラブ等）の運営デジタル化
- **ターゲット**: 熊本県青年農業者クラブ連絡協議会（熊有研）および農業従事者

## システムの役割

農業団体の業務運営における以下を一元化：
- 会員管理
- 会計処理（経費・請求）
- タスク管理
- 生産・出荷データの可視化

## 主要機能モジュール

### 1. ダッシュボード
- KPI表示：月間出荷総量、新規組合員数、出荷エラー率、稼働農機数
- 生産推移・品目別ボリュームのグラフ表示
- 直近の生産・出荷状況リスト

### 2. マスタ管理
| マスタ | 説明 |
|---|---|
| 会員管理 | 基本情報、役職、道路情報、振込口座情報 |
| 取引先管理 | 経費等の支払先管理 |
| 品目・単位マスタ | 生産物や単位の標準化 |
| 部門マスタ | 組織内グループ（受入農家等）の管理 |

### 3. 会計・事務管理
- **経費明細**: 日々の経費入力、インポート、一覧表示
- **請求明細**: 請求データの管理
- **旅費計算**: 会員マスタの道路情報を利用した自動旅費計算
- **レポート生成**: 各種データの集計・分析、PDF/Excel出力

### 4. タスク管理 (Todos)
- 機能要望、不具合報告、メモの共有
- 優先度・ステータス管理
- 担当者割り当て・コメント機能

## 技術スタック

| 層 | 技術 |
|---|---|
| **Frontend** | Next.js 15+ (App Router), TypeScript, React 19 |
| **Styling** | Tailwind CSS, @tailwindcss/postcss v4, Framer Motion, Lucide React |
| **Backend/DB** | Firebase (Firestore, Authentication, Storage) |
| **Charts** | Recharts |

## 今後の拡張アイデア

1. **AI自動集計**: 経費明細から確定申告用データを自動生成
2. **領収書OCR**: 領収書画像をアップロードし自動登録
3. **出荷予測**: 過去データに基づき来月の出荷量を予測
4. **プッシュ通知**: Todoの更新や重要なアナウンスを通知
