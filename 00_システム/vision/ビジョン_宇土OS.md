# 宇土OS - 自治体デジタルプラットフォーム思想

## 1. ビジョン（Vision）

宇土OSは、宇土市における「行政・議会・市民・地域経済」を横断的につなぐ、統合型デジタルプラットフォームである。その本質は単なる情報整理ツールではなく、「意思決定の構造」を再設計するシステムである。

現在の自治体運営は、縦割り構造・情報分断・属人的判断に依存している。この状態では、人口減少時代における迅速かつ合理的な意思決定は不可能である。宇土OSは、この構造そのものを変革し、「データに基づく意思決定」を標準化することを目的とする。

また、市民にとっては「必要な情報に即座にアクセスできる状態」を実現し、制度や支援を"使えるもの"へと変換する。行政にとっては「判断のための統合データ基盤」、議会にとっては「政策判断の可視化基盤」として機能する。

最終的に宇土OSは、「自治体を一つのOSとして再定義する」ことを目指す。制度・データ・意思決定を統合し、持続可能な地域経営を実現するための基盤である。

---

## 2. コア思想（Core Philosophy）

- **原則1: 構造がすべてを決める**  
  問題は個別事象ではなく構造に存在する。情報・業務・意思決定を構造化することで、自治体は進化可能になる。

- **原則2: データは資産であり、統合されて初めて価値を持つ**  
  財政データ、議会データ、市民サービス情報などは分散している限り無価値に近い。統合・構造化により意思決定資源へ変換する。

- **原則3: 市民をインターフェースの中心に置く**  
  行政都合ではなく、市民視点で設計されたUI/UXを持つことで、制度は初めて機能する。宇土OSは「市民が使える行政」を実現する。

## 3. システムアーキテクチャ（Architecture）

### レイヤー構成

```
┌─────────────────────────────────────┐
│ 00_System (System Layer)            │ ← ビジョン・戦略
├─────────────────────────────────────┤
│ 04_DataLink (Data/Integration Layer)│ ← Projects, Decisions, Logs
├─────────────────────────────────────┤
│ 03_Knowledge (Knowledge Base)       │ ← Business, Tech, General
├─────────────────────────────────────┤
│ 01_Inbox (Staging Area)             │ ← ChatGPT Imports等
└─────────────────────────────────────┘
```

### 各レイヤーの役割：

- **00_System**  
  ビジョン、戦略、意思決定の定義。宇土OSの方向性を固定する最上位レイヤー。

- **04_DataLink**  
  実行レイヤー。議会活動、行政プロジェクト、意思決定履歴、ログを蓄積。  
  → 宇土OSの"現実"がここに集約される。

- **03_Knowledge**  
  汎用知識の蓄積。ビジネス、技術、制度理解など、意思決定の材料となる知識を管理。

- **01_Inbox**  
  外部情報の取り込み口。ChatGPTログ、メモ、PDFなど未整理データを一時保管。

## 6. L6 政策レイヤ（Policy Layer）

### 子育て・教育政策

#### 現状の課題
- 児童数が過去20年で50%減少
- 小規模校での教育条件が低下
- 保育・幼稚園の利用者減で施設が過剰

#### L6での施策
1. **「質」中心の教育へ転換**
   - 統廃合により1クラス25～35人の適正規模化
   - クラス替え・グループ学習が可能な環境へ
   - 少人数だからこそ可能な「個別対応教育」の実装

2. **子育て支援施設の集約・強化**
   - 学校跡地に「子育て支援複合施設」を構築
   - 認定こども園 + 一時預かり + 子育て支援センター
   - 親の就業支援と子育ての質向上を同時実現

3. **教育環境の充実**
   - ICT環境の整備（1人1台タブレット、高速インターネット）
   - 図書館・学習センターの充実
   - 体験学習の機会拡大（ジオパーク、産業体験）

#### 政策の連携関係
```
L5インフラ（統廃合） → L6政策（質の高い教育）
                   ↓
              若年層の定住促進
              「教育で選ばれる市」の実現
```

---

### 産業・経済政策

#### 現状の課題
- 若年層の流出が継続（給与が都市部より低い）
- 1次産業の高齢化と後継者不足
- 商業機能の衰退（大型商業施設の進出）

#### L6での施策
1. **地域商社を核とした産業振興**
   - ウトマチ百貨店ブランドで全国販売
   - 農産物の6次産業化（加工・パッケージング）
   - 農家所得の向上 → 後継者確保

2. **雇用機会の創出**
   - 地域商社での雇用：20～30人
   - 学校跡地の加工施設での雇用：15～20人
   - テレワークセンターの利用者拡大
   - **新規雇用機会の創出：年50～100人**

3. **観光・交流産業の育成**
   - ジオパーク認定を機にした観光資源化
   - 有明海の自然体験プログラム開発
   - 農村体験・民泊の促進
   - 年間交流人口数千人～数万人への拡大

#### 政策の連携関係
```
L4財源（地域商社立ち上げ資金） → L6政策（産業振興）
L5インフラ（学校跡地の活用）  ↓
                        産業基盤強化
                        若年層の定住
```

---

### 移住・定住・空き家政策

#### 現状の課題
- 移住希望者はいるが「良い物件がない」
- 就業機会が限定的
- 移住後の生活サポートが不十分

#### L6での施策
1. **「家 × 仕事 × 暮らし」のセット提案**
   - 質の高い空き家（リノベーション補助制度）
   - 産業振興で創出した雇用機会
   - 子育て支援・教育環境の充実

2. **移住サポート体制**
   - 移住相談窓口の充実（企画課）
   - 移住体験施設（学校跡地のテレワークセンター）
   - 移住後の地域コミュニティへの受け入れ支援

3. **関係人口の創出**
   - 農村体験・民泊受け入れ家庭の拡大
   - 遠方からのテレワーク利用者の増加
   - 年間来訪者数の増加 → 定住への段階的移行

#### 政策の連携関係
```
L4財源（ふるさと納税「空き家枠」） → リノベーション補助
L5インフラ（跡地活用）            → 移住拠点施設
L6政策（雇用・教育）              → 生活基盤確保
                                ↓
                        移住数：年30～50世帯
                        定住人口の維持
```

## 7. L7 ビジョンレイヤ（Vision Layer）

### 2040年の宇土市像

#### テーマ：「縮むのではなく、選ばれるまち」

```
【人口維持】
定住人口：3.0万人（2026年3.6万人から17%減）
　+
交流・関係人口：年数千人～数万人
　=
「活力ある小規模都市」へのシフト
```

---

### 2040年の具体的状況

#### 施設・インフラの変化
```
【学校】
2026年：5校（児童数650人）
2040年：2校（児童数500人）→ 1学年80～120人、クラス替え可能

【公共施設】
2026年：延床面積60万㎡、維持費26億円/年
2040年：延床面積48万㎡（20%削減）、維持費18～20億円/年
     →「質」は維持、「量」は選別

【下水道】
2026年：管路年齢40～50年の老朽化最盛期
2040年：計画的更新により耐用年数期間の新しい施設へ
```

#### 経済・雇用の変化
```
【産業基盤】
ウトマチ百貨店の全国ブランド化
  →売上：年5～10億円
  →雇用：直接50人、間接100人

【若年層雇用】
平均給与：現在比+10～20%
  →実現方法：産業振興による高付加価値化
  →結果：若年層流出の停止

【関係人口】
移住者数：年30～50世帯（累積：500～1000人）
交流人口：年数万人
  →経済波及効果：年2～3億円
```

#### 子育て・教育環境の変化
```
【教育の質】
「質で選ばれる」小学校の実現
  →全国からの視察地化
  →移住希望者の最優先希望理由に

【子育てサポート】
「子育てするなら宇土市」というブランド化
  →保育料の無料化・軽減
  →子育て支援施設の充実
```

#### 市民生活の実感
```
【移住者の声】
「限られた人数だから、子どもたち一人ひとりが見守られている。
 都市の大規模校では得られない教育環境」

「ウトマチ商品は全国で有名。地元で働いていることが誇り」

「海と山が近い自然環境と、充実した子育て支援が決め手」

【既住者の声】
「人口は減ったが、質の高い生活環境が整った。
 選ばれているという実感がある」
```

---

### 市民への約束（コア・メッセージ）

> **宇土市はこれから、人口減少・財政制約という「これまで経験したことがない時代」に入ります。**
> 
> しかし、宇土OSは「どうすれば、限られた資源の中で、未来を選べるか？」を科学的に示した"まちの設計図"です。
> 
> **この設計図を、市民と行政が一緒に育てていくことで、宇土市は「縮むのではなく、選ばれるまち」へ進むことができます。**

---

### ビジョンの実現への道筋

```
【L0：現実の直視】
人口減少・財政制約という動かせない前提
        ↓
【L1：一次情報の徹底収集】
施設・データの棚卸しで「事実」を可視化
        ↓
【L2：構造的課題の抽出】
個別問題の背景にある根本的課題を理解
        ↓
【L3：課題解決組織の構築】
PFUが横断的に課題を解く
        ↓
【L4：多元的財源の確保】
外部資金 + ふるさと納税 + 産業創出
        ↓
【L5：インフラの最適化】
施設配置・都市計画で選択と集中を実装
        ↓
【L6：政策の実装】
教育・産業・移住政策が一貫して動く
        ↓
【L7：2040年ビジョンの実現】
「選ばれるまち」として新しい価値創造
```

- 議会への基本構想の提示
- 市民向け説明会の開催

**目標：** 市内での認知度向上、理解促進

---

### フェーズ2（2027～2029年）：意思決定支援システムと初期実装

- 各PFU組織の立ち上げ（学校統廃合、施設最適化など）
- 学校統廃合の初回実行（A+B → 新統一校）
- 外部資金OSの本格稼働（年2～3億円の追加確保）
- ふるさと納税「課題解決枠」の開始

**目標：** L3～L5の初期実装、市民への成果見せる段階

---

- 学校統廃合の完了、全跡地の活用開始
- 地域商社の本格展開（年5～10億円の売上）
- 移住施策による受け入れ体制の整備
- インフラ更新の継続進行

**目標：** L6政策の実装、「選ばれるまち」への転換

---

### フェーズ4（2037～2040年）：自治体間連携と横展開

- 宇土OSモデルの他自治体への提供開始
- 関係自治体との連携プラットフォーム化
- 2040年ビジョンの達成確認
- 次段階（2050年）への計画開始

**目標：** 宇土OSモデルの外部発信、自治体DXの先進事例化
