# 教育OS

## 🎯 教育OSとは何か

教育OSは、宇土OSの中で**「人を育てる仕組みを、人口減少時代にどう再設計するか」**を担うレイヤです。

単なる学力向上やICT導入ではなく、

> **学校・地域・財政を一体で再構築するための中核OS**

として位置づけられています。

### 教育OSの本質

教育OSは「**学校を残すOS**」ではなく、「**学びを残すOS**」です。

学校統廃合はゴールではなく、教育の質を再構築するためのスタート地点です。

---

## 📊 宇土市の教育を取り巻く現実

### 児童生徒数の減少

```
2006年：4,500人
2016年：3,200人（20年で28%減）
2026年：2,200人（20年で50%減）
2036年：1,500人（見込み、さらに30%減）
```

### 学校施設の老朽化

- 多くの校舎が築40年以上
- 耐震化後も更新費は未解決
- 維持費が今後増大
- **教育問題であると同時に、公共施設問題（L5連動）**

### 将来の課題

- クラス替えができない小規模校の増加
- 多様な人間関係が育ちにくい
- 教員配置の硬直化

---

## 🎯 なぜ「学校統廃合」が避けられないのか

### 教育の質の問題

#### 現状
```
A小学校：設計定員400人、現児童数150人（稼働率37%）
- 1学年25人程度の小規模学年が続く
- クラス替えができない
- グループ学習が形骸化
- 体験学習の機会が限定的
```

#### 問題点
- **「子どもの学びの機会格差」** が発生
- 小規模校では、4～5人グループを組むだけで、学習に参加できない生徒が出る
- 多様な人間関係の中での成長が難しい

### 財政の問題

#### 現状の非効率性
```
A小学校：児童150人
- 運営費年間：約4,800万円
- 児童1人当たり：約320万円

統廃合後：児童350人規模
- 運営費年間：約5,600万円（増加分あり）
- 児童1人当たり：約160万円（50%削減）

削減額：年間3～4億円（全学校統廃合時）
```

#### 14億円問題との関係
- 学校更新費も「年23.6億円必要で9.2億円しか投資できていない」問題に含まれる
- 施設数を減らすことが、唯一の構造的解決法

## 🏫 教育OSの基本原則

### 原則① 学校は「数」より「質」

- すべて残す、は最悪の選択
- どこかを守るために、どこかを変える
- **「選ばなかった結果」が、現在の状況**

### 原則② 教育は地域から切り離さない

- 学校統廃合 ≠ 地域消滅
- 学校以外の「学びの場」を地域に残す
- RMOと教育の再統合

### 原則③ 「うと学」による地域教育の強化

- 地域資源を活かした学び（ジオパーク、産業体験など）
- 人・産業・自然を教材化
- 統廃合後の「地域との接点」を確保

---

## 🌍 「うと学」の位置づけ

### うと学とは

**地域資源を活かした学び**

- **対象：** 小中学生
- **内容：** 探究・総合学習の核
- **教材：** 有明海のジオパーク、地域産業、農業・漁業
- **実施者：** 学校＋RMO＋地域人材

### 教育OSにおける役割

統廃合後の教育構成：

```
【学校（小学2校 → 集約化）】
- 基礎学力：国語、算数、理科、社会
- 体験型学習：うと学（週1～2時間）

【地域（RMO・公民館）】
- 探究学習の実践
- 産業人材との交流
- 自然体験プログラム

【地域人材】
- 漁師、農家、企業人による「職業講話」
- 伝統技術の継承学習
- ジオパークガイドとの連携

結果：
学校数は減ったが、学びの"種類"は増える
```

### 重要な点

統廃合によって失われるのは「学校数」であり、失われてはいけないのは「学びの質」です。

**うと学は、その代替装置** になります。

## 🔗 学校統廃合 × RMO × 公共施設（L5連動）

### 学校跡地の活用戦略

```
【元A小学校跡地】
↓
地域公民館 + 子どもの居場所 + 生涯学習拠点
↓
- 放課後児童室
- 公民館講座の充実
- 地域交流イベント
- RMOの拠点化

効果：
- 学校施設の廃止ではなく「機能転換」
- 地域の"居場所"が残る
- 教育機能は集約、地域機能は分散
```

### 教育の分散化モデル

```
学校＝基礎教育（集約化により質向上）
      ↓
地域＝実践教育（うと学・生涯学習・地域交流）

両者が相互補完し、教育を一極集中させない
```

---

## 💰 教育OS × 財政OS（L4連動）

### 更新投資の優先順位

```
L5での判断：
- すべての校舎更新は不可能
- 拠点校への集中投資が前提

対象例：
□ 統廃合後の新校舎（高品質化）
□ ICT環境整備（全校）
□ 耐震化未対応校の改築

対象外：
✗ 小規模校の個別改築
✗ 機能重複施設の更新
```

### 教育費の位置づけ

```
短期的な削減：不可
  ↓
「構造改革」を条件に、質への投資は継続
  ↓
守るために変える
```

## 🎓 教育OS実装による変化

### 学校側の変化

```
Before（2026年）
- 小規模校5校
- 児童1人当たり320万円の運営費
- クラス替え困難
- 教員配置の硬直化

After（2035年）
- 集約化された2～3校
- 児童1人当たり160万円の運営費（50%削減）
- 適正規模のクラス編成（25～35人）
- 専科教員の配置充実
```

### 地域側の変化

```
Before（2026年）
- 学校＝地域の唯一の交流拠点
- RMOと学校が別々に動く
- 地域教材が活かされていない

After（2035年）
- 学校＋地域 が一体で教育に関わる
- RMOが「地域教育」の担い手に
- 産業人材・地域人材が学びに参加
- 「うと学」が地域と学校をつなぐ
```

## 🎯 教育OSが描く2040年の教育像

### 「質で選ばれる教育」

宇土市立小学校が、以下の特徴を持つようになる：

- **適正規模教育環境**
  - 全学年で複式学級がない
  - クラス替えが可能な規模

- **地域連携教育**
  - うと学が通常教育に統合
  - 地域人材・産業が教室に参加

- **探究型教育の充実**
  - 従来の教科学習＋実践的な学び
  - ジオパーク、産業体験が教育の核

- **ICT・デジタル環境**
  - 小規模だからこその高密度ICT活用
  - 個別最適化学習の実現

### 市民の認識の変化

```
「子どもを育てるなら宇土市」
  ↑
自治体選択の理由が「教育の質」に

移住決定要因の上位3位：
1. 教育環境
2. 仕事・産業
3. 地域文化
```
