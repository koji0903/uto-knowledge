# 宇土市の施設老朽化と財政危機 - 構造的課題分析

## 🎯 このドキュメントの位置づけ

L4（財源レイヤ）と L5（インフラレイヤ）を貫く**構造的課題の深掘り分析**。

> 「なぜ23.6億円という数字が出てきたのか？」
> 「なぜそれが払えないのか？」
> 「どういう仕組みが機能不全なのか？」

これらを冷徹に説明する。

---

## 📋 Part 1: 公共施設は「消耗品」である

### 物理的現実：すべての建物に寿命がある

```
【建物の劣化スケジュール】

屋根・外壁      → 20～30年で修繕必要
建物構造（RC造） → 50～60年で建て替え必要
空調・電気設備  → 15～20年で更新必要
水道管          → 40年前後で交換必要
橋梁            → 50年前後で大規模補修必要
```

### この現実の意味

```
「建てた瞬間から老朽化は始まっている」

つまり：
- 人口が増えようが減ろうが関係ない
- 使い続けている限り、修繕と更新は避けられない
- 放置すれば劣化は加速する
```

### 宇土市の施設インベントリ

宇土市が保有する公共施設（一次情報：総合管理計画）：
- 学校（小中）
- 幼稚園・保育所
- 公民館
- コミュニティセンター
- 交流施設
- 文化施設（市民会館等）
- 体育施設
- 防災施設
- 道路・橋梁
- 水道・下水道インフラ
- 公園
- 図書館
- その他多数

**重要な事実：** これらは「使っていようがいまいが」維持費が発生する固定資産。

## 💰 Part 2: 宇土市の「必要な更新費用」の計算

### 公式数値（宇土市公共施設等総合管理計画より）

#### 40年間の総更新費用

```
【内訳】
建築物更新費：   611.2億円 ÷ 40年 = 15.3億円/年
道路更新費：     329.8億円 ÷ 40年 =  8.2億円/年
下水道更新費：   203.1億円 ÷ 40年 =  5.1億円/年
────────────────────────────────
合計需要額：    約1,144億円 ÷ 40年 ≈ 28.6億円/年

※ただし施設削減を前提とした見直し後は：
→ 約940億円 ÷ 40年 = 約23.6億円/年
```

### なぜ23.6億円という数字か？

```
40年間で必要な施設更新投資（940億円）を
年平均に平準化した値 = 毎年貯めるべき金額

【家計で例えると】

家の修繕費（外壁、屋根、エアコン、給湯器、配管など）を
30年分まとめて計算し、
「30年で900万円 → 毎年30万円貯金すべき」

と家計管理のプロがアドバイスするのと同じ。

宇土市も：
「40年間で940億円必要 → 毎年23.6億円貯めておかないと破綻する」
```

### 重要な誤解を正す

#### よくある誤解

```
Q. 「本当に毎年23.6億円『使う』の？」
A. いいえ。「必要な積立額」です。
```

```
23.6億円は、更新に備えるべき長期積立の「基準値」。
実際には、数年に一度、大規模工事の年にどんと出ていきます。

でも、対応する準備（ストック）がないと、
いざという時に「お金がない」で対応不能。
```

## 📊 Part 3: 実際に宇土市が積み立てられる額

### 現状：毎年9.2億円程度の積立

```
【2026年の一般財源（46.0億円）の使途】

社会保障費：16.5億円（36%）
  ├─ 高齢者福祉
  ├─ 児童福祉
  ├─ 障害者支援
  └─ 生活保護

人件費：14.0億円（30%）
  ├─ 職員給与
  ├─ 福利厚生
  └─ 退職手当

公債費：5.0億円（11%）
  └─ 市債返済

────────────────────────
小計：35.5億円（77%）

【残り】投資的経費：10.5億円（23%）
  ├─ 道路・橋梁修繕：2.0億円
  ├─ 施設修繕：1.5億円
  ├─ 下水道：3.0億円
  ├─ 新規事業：2.0億円
  └─ その他：2.0億円
```

### なぜ積み立てが進まないのか？

#### 理由① 人口減少で税収が減少

```
人口減少 → 市民の数が減少 → 市民税が減少
企業数減少 → 法人税が減少
高齢化 → 所得減少
```

#### 理由② 福祉関連費（扶助費）が増え続ける

```
高齢化率：35%超へ上昇
  ↓
高齢者向けサービス需要が増加
  ↓
福祉関連費が年3～5%で増加
  ↓
これは「減らせない」義務的支出
```

#### 理由③ 人件費・公債費で一般財源が圧迫

```
人件費（給与・退職手当）：組織維持に不可欠
公債費（市債返済）：過去の借金返却で必須
  ↓
この2つだけで約40%を占有
  ↓
その上に福祉費（36%）
  ↓
投資的経費に回る余裕が極限まで圧迫
```

#### 理由④ 国基準の財政指標に「更新費が考慮されていない」

```
国が自治体の財政健全性を判定する指標：
- 実質公債費比率
- 経常収支比率
- など

これらの指標には「将来の施設更新費」が含まれていない。

結果：
国の指標では「健全」でも、
実は施設更新の積立不足で、
将来は確実に破綻する
```

### 構造的矛盾

```
理想：毎年23.6億円を積み立てるべき
現実：毎年9.2億円程度しか積み立てられない
┌──────────────────────────────────┐
│  毎年14.4億円の不足 = 未来へのツケ  │
└──────────────────────────────────┘
```

## ⚠️ Part 4: この不足が生み出す悪循環

### 14.4億円の不足の実態

```
毎年の不足 = 以下のいずれか（またはその組み合わせ）

✔ 施設の廃止・統合を先送り
✔ 修繕を後回しに
✔ 建て替えが必要な施設を延命で対応
✔ 給付的サービス（福祉）を優先して投資を圧制
```

### 累積効果の恐怖

```
2026年：不足14.4億円
2036年：不足累計144億円（10年）
2046年：不足累計288億円（20年）

この累積不足は、将来の宇土市を直撃する。
```

### 具体的な弊害

```
【施設面での影響】
- 老朽化した学校での教育 → 教育環境の劣悪化
- 橋梁老朽化を放置 → 安全インシデント発生リスク
- 下水道更新遅延 → 計画的な処理が困難化

【財政面での影響】
- 緊急時の大規模修繕に対応不能
- 危機的状況での市債増発に依存
- 利息負担で一般財源がさらに圧迫

【市民生活への影響】
- 施設サービス低下
- 福祉サービス削減圧力
- 若年層流出加速
```

## 🔄 Part 5: なぜこんなことになっているのか？

### システムの設計欠陥

```
【問題の根源】

国の財政制度は、
「今年の支出」に基づいて自治体の健全性を判定している。

しかし現実は、
「今後40年間の施設更新」という長期的課題を
抱えているのに、
それを反映していない。

結果：
「目先の赤字は出ていない」と判定されながら、
実は構造的に破綻している
```

### 多くの自治体が同じ状況

```
宇土市も例外ではなく、
全国の地方自治体の大多数が、
この構造的矛盾に陥っている。

理由：
- 昭和時代に施設を建てすぎた
- その時代に人口増加を前提にしていた
- 現在は人口減少で維持できなくなった
- でも「廃止できない」施設ばかり
```

## ✅ Part 6: では、どうするか？

### 3つの対応軸（唯一の解決法）

#### 軸① 施設数を減らす（L5インフラレイヤ）

```
使っていない施設の廃止
小中学校の統合（児童数減への対応）
公民館の統合
文化施設の複合化・廃止

目標：施設面積を20～30%削減
効果：年3～5億円の維持費削減
```

#### 軸② 稼ぐ力を高める（L4財源レイヤ・産業OS）

```
地域商社による産業振興
ふるさと納税返礼品の高付加価値化
地場産業の6次産業化

目標：年1～2億円の外部収入獲得
効果：一般財源の拡大
```

#### 軸③ 外部資金を取る（L4財源レイヤ）

```
国庫補助金の毎年スキャン
地域創生交付金の活用
施設最適化事業への補助申請

目標：年2～3億円の補助金上乗せ
効果：市の負担を減少
```

### この3つの車輪が同時に回る必要性

```
軸①だけ → 施設は減っても、稼ぐ力がないまま
軸②だけ → 施設が老朽化し続けながら産業に投資
軸③だけ → 補助金に依存する体質が続く

⚠️ 3つが連動しないと、宇土市は2035～2040年頃に
構造的限界に達する。
```
