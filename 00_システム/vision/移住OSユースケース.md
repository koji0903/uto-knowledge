## ユースケース概要

移住・定住OSが人口減少に歯止めをかける3つの実例。

---

## ケース 1：試験住宅で「本当に移住できるか」を確認 - 佐藤さん（移住希望者）

### 背景

**状況：**
- 東京在住、IT企業勤務（年収700万円）
- 40代、配偶者あり、子ども2人（小学3年、4年）
- 心境：「田舎暮らしに興味があるが、本当に子どもたちが適応できるのか不安」

**課題：**
- 学校の環境が心配（都市部より教育水準が落ちないか）
- 子どもの友人関係（新しい環境で友達ができるか）
- 親自身の仕事（地方で同じレベルの仕事があるか）
- 生活費（都会と変わるのか）

---

### Before：「移住」は大きなリスク

**過去の状況：**
- 「田舎に移住」= 大きな決断（給与減・転職リスク等）
- 試行錯誤の余地がない
- 一度移住したら「やっぱり東京に戻る」が困難
- 結果：移住を諦める（現状維持）

---

### After：試験住宅で「安全にテスト」

#### **ステップ1：移住OS で物件検索（2026年4月）**

佐藤さんは移住OS にログイン。条件を指定：

```
【移住希望条件】
├─ 地域：宇土市（農村×市街地のバランス）
├─ 家族構成：4人家族
├─ 予算：月額 10万円以下
├─ こだわり：
│  ├─ 学校まで歩ける距離
│  ├─ 親が在宅勤務できるWiFi環境
│  └─ 古家でもOK（古民家活用に興味）
└─ 試験住宅希望：「3-4ヶ月試してから決める」
```

検索結果：試験住宅対応の物件が3件提案される。

```
【物件1】「築70年の古民家、3LDK」
├─ 月額：8万円（通常賃料の50%で試験可能）
├─ 試験期間：最大6ヶ月
├─ 小学校まで：徒歩10分
├─ 特徴：有機農家が隣
└─ オーナー：「新しい家族の笑顔が見たい」

【物件2】「平成10年建築の一戸建て、4LDK」
├─ 月額：9万円
├─ 試験期間：最大4ヶ月
├─ 小学校まで：徒歩5分
├─ 特徴：学校に近い、新しい設備
└─ オーナー：「若い家族を応援」

【物件3】「古家＋農地0.5ha」
├─ 月額：7万円
├─ 試験期間：最大3ヶ月
├─ 小学校まで：徒歩7分
├─ 特徴：菜園スペース、自給自足可能
└─ オーナー：「農業をやりたい人を探してた」
```

佐藤さんは物件2「平成10年建築」を選択。

#### **ステップ2：試験住宅の申し込み＆契約（2026年5月）**

移住OS 上で試験住宅申し込み：

```
【試験住宅契約】
物件：「平成10年建築、4LDK」
開始日：2026年6月1日
期間：4ヶ月（6月～9月）
月額：9万円 ÷ 2 = 4.5万円（試験時は50%割引）
合計：18万円（4ヶ月）

【契約に含まれるサポート】
✓ 学校見学・説明会の手配
✓ 子どもの転入学サポート
✓ 地域コミュニティの紹介
✓ 親の就職相談サポート
✓ 定期的な面談（市職員）

市職員からの初回面談予定：6月10日 15:00
```

#### **ステップ3：試験住宅での実際の暮らし（6月～9月）**

移住OS のアプリで、日々の体験を記録：

```
【6月初週】
日記（お母さん記載）：
「初めての朝。子どもたちは緊張している様子。学校は明後日。
古い家だが、この穏やかさ。東京ではなかった。
主人は今日から在宅勤務。WiFi問題なし。良かった。」

満足度：★★★☆☆（不安が大きい）
やることリスト：✓ 学校説明会参加、○ 子どもの友達作り

【6月中旬】
「子どもたちが学校から帰ってくる。担任の先生の対応が丁寧。
地域の子どもたちも優しい。お母さんが涙ぐんでいた。」

満足度：★★★★☆

【7月】
「隣の有機農家さんとの交流が自然に。
子どもたちも手伝って野菜を収穫。
親自身も仕事のペースが心地よい。」

コミュニティ交流ログ：
└─ 有機農家・山田さん家族と野菜畑で作業
└─ PTA役員さんに学校情報をもらう
└─ 自治会の盆踊り大会に参加

【8月】
「子どもが『友達と祭りに行く』と言ったのが嬉しかった。
定着の手応えを感じている。」

満足度：★★★★★

【9月末】
「別れが辛い。このまま居たい気持ちと、東京の生活と...
でも、この3ヶ月で人生が変わった。
絶対、戻ってくる。」

最終フィードバック：
定住意思：「YES（確定的）」
理由：「子どもたちの笑顔。親自身の心の余裕。
仕事も問題なく続けられた。
本当に移住できると感じた。」
```

#### **ステップ4：本格的な移住に向けて**

試験を終えて、佐藤さんは確信を持ち、正式に移住を決定：

```
【定住の意思決定】
決定日：2026年9月末
次のステップ：

1. 本住宅の選定
   └─ 試験住宅の「物件2」をそのまま購入検討
   └─ オーナーに「購入したい」と打診

2. 仕事の調整
   └─ 現在の東京の会社は「完全在宅勤務」に転換
   └─ 給与は15% 減（生活費が下がるので問題なし）

3. 子どもの転校
   └─ 正式に宇土市の小学校に転入
   └─ 既に友達がいるので適応は円滑

4. 市の移住支援
   └─ 「若年世帯移住支援」プログラムに申請
   └─ 初期家具補助：50万円
   └─ 月額家賃補助：2万円/月（最大12ヶ月）
   └─ 合計サポート：74万円

【佐藤さんの移住ストーリー】
「3ヶ月の試験がなかったら、絶対に移住できていない。
『実際に暮らしてみる』ことで、不安が確信に変わった。
子どもたちも、親も、新しい人生が始まったと思う。」
```

## ケース 2：空き家オーナーの有効活用 - 田中さん（空き家所有者）

### 背景

**状況：**
- 親が所有していた古い一戸建てが空いている
- 20年以上使用されず、老朽化が進行中
- 田中さん本人は都市部に住んでいるため、管理が困難
- 心境：「この家をどうしたらいい...」

**課題：**
- 毎年の管理費（固定資産税等）が負担
- 修復には大きな費用が必要
- 売却しても買い手がつきづらい（過疎地）
- 特に思い出の家なので、壊すのは嫌

---

### Before：空き家の放置

**過去の状況：**
- 固定資産税：年間 15万円
- 家屋税：年間 5万円
- 修繕・メンテ：年間 10万円
- 合計：年間 30万円の出費
- 結果：「赤字の資産」として放置

---

### After：移住・定住OS で「新しい家族」と出会う

#### **ステップ1：空き家を移住OS に登録（2026年5月）**

田中さんは不動産会社の協力を得て、物件を登録：

```
【空き家登録】
物件名：「田中家の古民家」
所有者：田中さん
利用希望：「若い家族に賃貸して、家を生かしたい」
賃料：「月額8万円で良い。修復費は自分で負担する」

【家の説明】
築年数：昭和40年（約60年）
間取り：6DK＋蔵
庭：広い（果樹園跡）
課題：
├─ 屋根瓦に割れあり（修復予定）
├─ 水回りは使用可能だが古い
├─ 床は傷みあり、部分的に修復が必要
└─ 雰囲気：「古いが、味わいがある」

試験住宅：「YES（修復後、可能）」
オーナーからのメッセージ：
「この家で親が暮らして、子どもたちが成長しました。
新しい家族が笑顔で暮らす場になったら、嬉しいです。」
```

#### **ステップ2：修復サポート＆マッチング**

移住OS が空き家の修復をサポート：

```
【修復サポートプログラム】
市の「空き家活用補助金」：300万円
内容：
├─ 屋根修復：150万円
├─ 水回り改修：100万円
├─ 床修復：50万円
└─ 合計：300万円

田中さんの負担：0円（市がサポート）
→ 家が新しく生まれ変わる

修復期間：3ヶ月（2026年5月～7月）

【マッチング】
修復が完了する と同時に、佐藤さんファミリーが現れる！
（ケース1と連動）
```

#### **ステップ3：佐藤さんファミリーの入居**

```
【賃貸契約】
開始：2026年8月（修復完了直後）
契約者：佐藤さん
賃料：月額8万円
期間：長期（定住）

【田中さんへの経済効果】
月額：8万円の家賃収入
年額：96万円
→ 従来の出費 30万円が、年間 96万円の収入に転換！
→ 資産が赤字から黒字に変わる

【田中さんのメリット】
✓ 毎月の赤字が黒字に
✓ 親の思い出の家が活用される
✓ 新しい家族の笑顔が見られる（関係構築）
✓ 市の評価：「地域への貢献」として認識
```

#### **ステップ4：持続可能な関係構築**

佐藤さん一家が定住すると、田中さんとの関係も継続：

```
【関係の深化】
・盆暮れの帰省時に、佐藤さんファミリーに家を見てもらう
・子どもたちが「親戚のおじさんおばさん」として成長
・親の思い出の場が、新しい家族の人生の舞台に

【経済的な安定】
修復費：市の補助で負担
運営費：毎月の家賃でカバー
将来：修復費用を全て回収可能（12-15年）
```

## ケース 3：就職マッチングで移住を実現 - 高橋さん（若年移住希望者）

### 背景

**状況：**
- 福岡在住、28歳、独身
- IT エンジニア（年収400万円）
- 思い：「田舎で自分の才能を活かしながら、のんびり暮らしたい」

**課題：**
- IT 企業が少ない地方への移住は「給与低下＝覚悟が必要」
- 実家への UターンなのでUターン支援があるかもしれないが、詳しくない
- 「本当に仕事があるのか」という不安

---

### After：移住・定住OS で「仕事×移住」を同時解決

#### **ステップ1：移住OS で求人検索＆企業マッチング**

高橋さんは移住OS の「求人検索」で条件を指定：

```
【求人検索条件】
├─ 職種：ITエンジニア、フロントエンド開発
├─ 給与：年450万円以上希望
├─ リモート：100% 対応希望
├─ 移住支援：あるなら活用したい
└─ 地域：宇土市

【検索結果】
✓ 「ウトマチ百貨店（地域商社）× EC サイト開発」
  - 給与：年480万円
  - 移住支援：あり（月5万円 × 12ヶ月）
  - リモート：100% 対応可能
  - 定着率：高（既に2名のエンジニアが地元から移住）

✓ 「農業法人× 農業 IT システム開発」
  - 給与：年450万円
  - 移住支援：あり（実家支援も可）
  - リモート：80% 対応可
  - やりがい：「農業の DX」への貢献
```

#### **ステップ2：企業面接＆内定**

高橋さんは「ウトマチ百貨店」での面接に進む：

```
【オンライン面接の記録】
日時：2026年6月
相手：採用担当者＋エンジニアリーダー

面接官：「なぜ移住を考えたのか」
高橋さん：「親の近くに住みたい。かつ、自分のスキルを地方でも活かしたい」

面接官：「当社は EC サイトで全国に販売しています。
あなたの UI/UX スキルは、絶対に必要です。
ぜひ、チームに参加してほしい。」

結果：内定
給与：年480万円（福岡の現職より +80万円）
移住支援：月5万円 × 12ヶ月
開始日：2026年8月
```

#### **ステップ3：引越し＆移住支援プログラム活用**

高橋さんは移住・定住OS の「支援プログラム」に申請：

```
【移住支援プログラム（若年IT人材向け）】

1. 企業からの支援：月5万円 × 12ヶ月 = 60万円
   └─ 給与に加えて支給（実質年490万円相当）

2. 市からの支援：
   ├─ 初期費用補助：50万円（引越し・敷金等）
   ├─ 月額家賃補助：1.5万円 × 12ヶ月 = 18万円
   └─ 小計：68万円

3. 親からの支援：実家での居住（家賃0）
   └─ 年間：120万円の家賃節約

【総合的な経済効果】
従来（福岡）：年収400万円、家賃6万円 = 年間家計72万円負担
移住後：年490万円 + 企業支援60万円、家賃 0 = 年間 550万円実質所得
→ 経済的に大幅に改善！
```

#### **ステップ4：仕事×暮らしの融合**

高橋さんの移住は、単なる「転職」ではなく、「人生の転換」に：

```
【入社後3ヶ月の変化】

仕事面：
- EC サイトのUI改善に貢献（売上 +15%）
- チーム内の地位：既に中堅メンバーとして認識
- リモート勤務：週3日出社、週2日自宅勤務で効率的

暮らし面：
- 親との食事：週3回（都市部では月1回が精々）
- 地域活動：自治会の若手として活躍
- 趣味：山登り（実家近く）で新しい友人と出会い

心理面：
「給与は少し上がったけど、人生の充実度が全く違う。
仕事も地域貢献になっている。
この選択、絶対に正解だった。」
```

## 総合的な効果と展開

### 3つのケースから見える移住・定住OS の価値

```
【ケース1：佐藤さん（試験住宅）】
→ 「不安」が「確信」に変わる
→ 4人家族の定住実現

【ケース2：田中さん（空き家所有者）】
→ 「赤字資産」が「黒字資産」に変わる
→ 親の思い出の家が新しい家族に引き継がれる

【ケース3：高橋さん（若年IT人材）】
→ 移住による給与低下なし（むしろ向上）
→ 仕事×暮らしの融合実現
```

### 宇土市全体への波及

```
【人口動態への影響】
毎年 30-50 世帯 × 平均 3.5 人 = 年 105～175 人の転入
対：現在の転出（-150～200人）
→ 人口動態が「-2%」から「-0.5%」へ改善

【経済効果】
移住による経済支援：年 6000～8000万円
→ 関連産業への波及（不動産、引越し、生活消費等）
→ 見える化：GDP 向上 + 雇用創出

【地域活性化】
空き家活用：年 50～80 件
→ 街の風景の改善
→ 若い世代の参加で地域イベント活性化

【社会的インパクト】
「縮むまち」 → 「選ばれるまち」への転換
市のブランド価値向上 + 市民の自信回復
```
