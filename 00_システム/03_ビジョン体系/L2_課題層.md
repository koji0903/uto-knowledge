## 🏢 課題1：公共施設の面積過多と老朽化

### 問題の構造

#### 面積過多（Oversupply）
- **客観指標** - 人口当たり施設面積が類似市の130%
- **原因** - 高度成長期に「右肩上がり人口」を前提に建設
- **結果** - 現在の人口に対して30%過剰
- **コスト** - 維持管理費が児童1人当たり2倍～3倍

#### 老朽化（Deterioration）
- **築年数** - 1970～1990年代建設が集中
- **更新期** - 建設40～50年で管理限界（2010～2030年に集中）
- **劣化スピード** - 今後10年で急加速
- **コスト** - 年23.6億円必要だが、9.2億円しか投資できていない

### 小学校を例にした分析

#### 現状の過剰性
```
A小学校：設計定員400人、現児童数150人（稼働率37%）
- 教室数：設計24教室 → 実稼働9教室
- 児童1人当たり年間運営費：320万円
- 教職員数：25人（児童6人当たり1人の過剰配置）
```

#### 統廃合による最適化効果
```
統廃合後のC小学校規模化：児童数350人
- 教室数：24教室（ほぼ満杯稼働）
- 児童1人当たり年間運営費：160万円（50%削減）
- 教職員数：30人（効率的配置）
```

## 💧 課題2：下水道インフラの一斉更新期

### 問題の構造

#### 同期的老朽化（Synchronized Aging）
- **敷設時期** - 1970～1980年代に集中（建設費確保が容易だった時期）
- **現在の年齢** - 40～50年（管路寿命の限界）
- **更新時期** - ほぼ同時期（2020～2035年）
- **費用集中** - 毎年数億円の支出が不可避

#### 平準化不可能性
```
通常パターン：10年ごとに10億円 → 政治的判断可能
宇土市パターン：5年間に50億円集中 → 市の財政では不可能
```

## 🎓 課題3：学校統廃合の必然化

### 問題の構造

#### 児童数減少の確実性
```
2006年：4,500人
2016年：3,200人（20年で28%減）
2026年：2,200人（20年で50%減）
2036年：1,500人（見込み、さらに30%減）
```

#### 統廃合が避けられない理由

**理由1：教育条件の維持**
- 1クラス15人では、10人グループを作ることで5人が取り残される
- グループ活動が本来的な学習方法なら、小規模校では教育の質が低下

**理由2：財政効率**
- 学校Aの児童1人当たり年間運営費：320万円
- 統廃合後：160万円（50%削減）

**理由3：社会的機能の維持**
- 小規模校では運動会やクラスマッチなどの行事が成り立たない

## 🏚️ 課題4：空き家と居住環境

### 問題の構造

#### 空き家の二面性（Paradox）

**パラドックス：**
- 空き家は「数」では多い（数千戸）
- しかし「使える空き家」は少ない（15～20%）
- 結果、移住希望者は「良い物件がない」と感じる

#### 利用可能な空き家の分類

| 特性 | 数 | 割合 | 課題 |
|-----|-----|------|------|
| 立地良好 + 構造良好 | 200戸程度 | 15% | 既に活用されている |
| 立地良好 + 改修必要 | 500戸程度 | 35% | 改修コスト＋時間必要 |
| 立地不適 + 廃屋 | 2500戸程度 | 50% | 取り壊し対象 |

## 💰 課題5：財政の構造的不足

### 問題の構造

#### 歳入減と歳出増の同時進行

```
     2006年     2026年     2036年（見込み）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
歳入（一般財源）50億円   46億円   44億円
     ↓        ↓        ↓
     ×(1 - 8%)×(2 - 4%)
```

```
     2006年     2026年     2036年（見込み）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
社会保障費  12億円   16.5億円   19億円（+60%増）
     ↑       ↑       ↑
     ×年3~5%増加
```

#### 「やりくり不可能」なギャップ

```
【2026年の状況】
一般財源：46億円
社会保障費：16.5億円（36%）
人件費：14億円（30%）
公債費：5億円（11%）
━━━━━━━━━━━━━━━━━━━━━━
小計：35.5億円（77%）
投資的経費（学校・道路・施設）：残り10.5億円
```

**しかし、必要な投資額は23.6億円（不足：13.1億円）**

## 🌊 課題6：産業基盤の縮小と雇用機会の喪失

### 問題の構造

#### 産業の地盤沈下パターン

```
人口減少
  ↓
消費市場の縮小
  ↓
地元小売店の経営悪化 → 閉店
  ↓
商業機能の喪失 → 住民の買い物が不便に
  ↓
若年層の流出が加速
```

#### 雇用機会の喪失

- **かつての雇用基盤** - 農業、工業団地、公務員
- **現在の状況** - 農業就業者高齢化、工業団地の企業減少
- **新規雇用** - サービス業中心だが、賃金は低い
- **結果** - 「給料が良い仕事は都市部」という構造的課題
