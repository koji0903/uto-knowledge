## ユースケース 1: 農家 - 山田太郎さん（米農家）

### Before（ウトマチ百貨店利用前）

**状況：**
- 米生産農家（自営農業20年）
- 年産300トンの米を生産
- JAに出荷 → 全量同一価格での販売（60円/kg）
- **年収：約1,800万円**（生産コスト控除後）
- 販売先が限定的で、価格交渉の余地なし
- 農業の後継者がいない（息子は都市部で会社勤務）

**課題：**
- 「米は商品化されすぎ。差別化ができない」
- 「農業では生活できる世代が来ない」
- 「直売所は週末だけで手間がかかる」
- 「有機栽培に切り替えたいが、販路がない」

### After（ウトマチ百貨店利用後・1年目）

**新しい販売戦略：**

```
【販売チャネル別の売上構成】
年産300トン（300,000kg）

1. JAへの出荷（在来農法）
   └─ 150,000kg × 60円 = 9,000万円
   └─ 利益率 30% = 2,700万円

2. ウトマチ百貨店経由
   
   a) 実店舗販売
      └─ 月20,000kg × 150円 = 月300万円
      └─ 年間360万円
   
   b) EC販売（「山田さんの有機米」ブランド）
      └─ 月15,000kg × 200円 = 月300万円
      └─ 年間360万円
   
   c) ふるさと納税（高付加価値）
      └─ 月10,000kg × 300円相当 = 月300万円
      └─ 年間360万円
   
   ウトマチ経由小計：75,000kg年間販売
   ウトマチからの支払い：75,000kg × 卸売75円 = 5,625万円

【年間収入改善】
従来の農業収入：2,700万円（JAのみ）
ウトマチ百貨店経由：5,625万円
総年収：**8,325万円**
→ 増加額：**+5,625万円（約3倍）**
```

**変化した点：**

1. **販路多角化**
   - JAだけでなく、複数チャネルで販売可能
   - 販売機会が週365日になった

2. **価格向上**
   - 「山田さんの米」としてブランド化
   - 実店舗では150円/kg（JAの2.5倍）
   - ふるさと納税では300円/kg相当

3. **有機栽培への転換**
   - 高付加価値での販売で採算が取れる
   - 「山田さんの有機米」ブランド
   - 認証取得サポートをウトマチが提供
   - 実現可能性が高まった

4. **事業の見える化**
   - 生産者ポータルで月次売上確認
   - チャネル別の販売実績が明確
   - 顧客フィードバック（レビュー）が直接見える

5. **後継者問題の解決**
   - 「農業で年8,000万円稼ぐことは可能」
   - 息子（都市勤務）が「農業事業化」に興味
   - 2027年に帰郷・農業参入予定

### Impact（ウトマチ百貨店のシステムが実現した価値）

| 指標 | Before | After | 改善 |
|------|--------|-------|------|
| 年収 | 2,700万円 | 8,325万円 | **+5,625万円（+208%）** |
| 販売価格帯 | 60円/kg | 150-300円/kg | **2.5～5倍** |
| 販売方法 | JAへの一括出荷 | 4チャネル並行 | **多角化** |
| 働き方 | 生産に専念（農作業） | 生産+ブランド発信 | **付加価値向上** |
| 後継者見通し | 不可能 | 2027年帰郷予定 | **解決** |

## ユースケース 2: 消費者 - 田中花子さん（東京都在住、福岡への移住検討中）

### Before（ウトマチ百貨店利用前）

**状況：**
- 東京在住（35才、会社員）
- 福岡への移住を検討中
- オーガニック・地元産食材への関心が高い
- 「福岡の食事環境」が移住決定の重要な判断要因

**課題：**
- 「福岡の農産物について、どこで買えるのか不明」
- 「東京のように品揃え豊かなオーガニックスーパーがあるか不安」
- 「生産者がどういう人か不透明」
- 「移住後の食材調達先が本当にあるか確認したい」

### After（ウトマチ百貨店利用後・利用開始から3ヶ月）

**購買経験：**

1. **初回購入：ウトマチ.jpでの野菜セット試購**
   - ウトマチ.jp で「春の野菜セット」を発見
   - 生産者「山田太郎さん」の顔写真＆プロフィール付き
   - 農法・こだわり説明を読んで好感を持つ
   - 月額5,000円の定期便購入開始

2. **継続購入：定期便 3ヶ月継続**
   ```
   毎週金曜日に配送
   
   【第1週】
   └─ 野菜セット（キャベツ・人参・ほうれん草等）
   └─ 生産者メモ付き：「今月は異例の早霜でしたが、丁寧に対応しました」
   
   【第2週】
   └─ 有機卵（地元養鶏場）
   └─ 地元チーズ
   
   【第3週】
   └─ 加工品：干し野菜、味噌
   
   【第4週】
   └─ 米（山田さんの有機米）
   
   → 生産者の顔が見える、季節感のある食材が毎週到着
   ```

3. **ふるさと納税経由の試購**
   - 「楽天ふるさと納税」で「宇土のいちご詰合」を返礼品購入
   - 年2回（4月・6月）で継続
   - ふるさと納税での支援を通じて、宇土への愛着が増加

4. **移住後のシミュレーション**
   - ウトマチの実店舗情報（営業時間・商品情報）を確認
   - 「移住後は毎週末に実店舗で買い物」をシミュレート
   - 定期便を続けながら、実店舗も利用する計画

### Impact（ウトマチ百貨店が提供した価値）

| 指標 | Before | After | 変化 |
|------|--------|-------|------|
| 食材入手手段 | 不明確 | 複数チャネル（EC・実店舗・ふるさと納税） | **安心感** |
| 生産者との関係 | 不透明 | 顔写真・メッセージを通じた信頼構築 | **信頼醸成** |
| 移住への心理障壁 | 中程度 | 大幅に軽減 | **決定促進** |
| 月間食費 | 東京スーパー並み | +20%（質向上・手間削減）| **納得価格** |
| **移住決定** | **未定** | **2026年7月決定、2027年1月転居予定** | **実現** |

**推奨の言葉：**
> 「ウトマチ百貨店があることで、『福岡の食材は充実している』という確信が生まれました。これが移住決定の大きな後押しになりました。定期便で毎週、宇土の農家さんとつながっている感覚も素敵です。」

## ユースケース 3: 市政 - 宇土市の雇用・財源化

### Before（ウトマチ百貨店立ち上げ前）

**状況：**
- 宇土市の財政危機：14億円の赤字見通し
- 農業従事者の高齢化（平均67才）
- 若年層の転出（毎年200～300名）
- 地域産業の低迷：農畜産物は生産量の割に低収益

**課題：**
- 「市の自主財源が不足」
- 「若い世代が宇土に残らない理由の筆頭が『仕事がない』」
- 「せっかくの農産物も、付加価値がついていない」
- 「商店街の空き店舗が増加」

### After（ウトマチ百貨店3年目の成果）

**事業成績（2028年度見通し）：**

```
【年間売上】
2026年（初年度）：3.2億円
2027年（2年目）：4.8億円
2028年（3年目）：6.5億円

【利益・還元額】
年間利益：1.5億円
  └─ 生産者への支払い：3.5億円
  └─ 従業員給与：1.5億円
  └─ 市への配当：1.0～1.5億円（自主財源化）

【雇用創出】
初年度：10名
2年目：25名
3年目：40名
→ 累計75名の新規雇用（3年で達成）
→ うち新卒地元就職：30名以上
```

**市への財政インパクト：**

```
【直接収入】
├─ ウトマチ百貨店からの市配当：年1.0～1.5億円
├─ 関連雇用の税収増：推定3,000万円/年
└─ ふるさと納税関連の市税：推定5,000万円/年
  
【間接効果】
├─ 商店街活性化（実店舗周辺の客足増）
├─ 農業所得向上による消費増（域内経済循環）
├─ 移住促進による人口増加
│  └─ 2026-2028年で50家族（150人）の転入見込み
│  └─ 定住支援施設（移住・定住OS連携）の利用促進
└─ 教育OS との連携：ジオパーク×農業学習
   └─ 地域産業教育の充実 → 地元就職率向上

【財源化への到達経路】
2026年：初期投資回収期間中（市投資2.3億円）
2027年：年間利益の一部を市に配当開始（5,000万円）
2028年：年間利益1.5億円の一部を市に配当（1.0～1.5億円）
→ 14億円の赤字基調を、単年度黒字化への足がかりに
```

**雇用創出の具体例：**

| 職種 | 初年度 | 3年目 | 特徴 |
|------|--------|--------|------|
| 店舗スタッフ | 8名 | 25名 | 地元パート・新卒採用が主体 |
| EC・マーケティング | 5名 | 15名 | 高卒・大卒の地元人材 |
| 営業（卸売） | 2名 | 8名 | 営業経験者の地元Uターン |
| 管理職・本社機能 | 5名 | 12名 | 市職員の兼務も含む |

**移住・定住OS との連携効果：**

```
【シナジー効果】
移住・定住OS で転入予定の世帯
  ↓
試験住宅で3-4ヶ月滞在
  ↓
ウトマチ百貨店での就職機会を提示
  ↓
「仕事×住まい×地域」のセットで定住促進
  ↓
2026-2028年で50世帯（150人）の定住実現
  ↓
税収・雇用の安定化へ
```

**市民からの声：**

| グループ | コメント | 効果 |
|---------|---------|------|
| 農家（50名以上） | 「ようやく農業で食べていける算段がついた。後継者に引き継げる」 | **農業経営の継続性確保** |
| 若年層（地元就職者） | 「宇土でこんなに成長する会社があるとは。キャリアを積める」 | **地元就職の魅力化** |
| 商店街 | 「実店舗周辺の客足が増え、他の店舗の売上も上がった」 | **商店街活性化** |
| 市民全般 | 「宇土の農産物が全国で売れてるって、嬉しい」 | **シビックプライド向上** |

### Impact（市政レベルでの成果）

| 指標 | Before | After（3年目） | 改善 |
|------|--------|---------------|------|
| 市の自主財源 | 基本的にゼロ（交付税依存） | **年1.0～1.5億円** | **新規財源化** |
| 農家平均年収 | 1,200万円（低迷） | **2,500万円以上** | **+100%以上** |
| 新規雇用 | ほぼゼロ | **年20～30名** | **継続創出** |
| 移住世帯 | 年5～10世帯 | **年30～50世帯** | **3～5倍増** |
| 商店街空き店舗率 | 35% | 15% | **改善トレンド** |
| 人口減少率 | -0.8%/年 | -0.2%/年（改善傾向） | **歯止め** |

## 統合効果（8層構造での位置づけ）

### L4財源レイヤ：自主財源化の実現
- **ウトマチ百貨店の年間利益1.5億円**が市の直接的な自主財源に
- 市への配当：1.0～1.5億円/年で、14億円の赤字基調を単年度黒字化へ

### L6政策レイヤ：産業政策の実装
- 農業の高付加価値化（6次産業化）
- 地域商社という新しい産業の創出
- 移住・定住OSとの連携で「仕事×住まい」の統合支援

### L7ビジョン：2040年の宇土
- 「人口40,000人・年間売上20億円の地域産業プラットフォーム」
- 「全国で『宇土ブランド』が認識される産地」
- 「若い世代が営みたいと思える地域経済」
