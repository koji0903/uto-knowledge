## 🎯 レイヤの役割

**まちの"器"をどうするか。「全部維持する」時代は終わり、選択と集中へ。**

### L5の戦略的位置づけ
```
L4（財源確保）
    ↓ 資金配分を受けて
L5（インフラ最適化）← ← ← 市の物理的基盤を再設計
    ↓ 施設配置に支えられて
L6（政策実装）
```

---

## 🔍 背景：施設老朽化と財政危機

**詳細な分析は [[L4L5_facility_finance_crisis]] を参照。**

簡潔に言えば：
- 全施設の40年間の必要更新費：23.6億円/年
- 現在の積立額：9.2億円/年
- 年間不足：14.4億円（毎年、未来へのツケ）

つまり、「全部維持」は物理的にも財政的にも不可能。

## 🏢 公共施設の最適化戦略

### 現状：「全部維持」の限界

#### 面積過多の客観的数値
```
宇土市：人口当たり施設面積が類似市の130%
東京都内の市部平均：人口1人当たり4.5㎡
類似都市（熊本県内他自治体）：人口1人当たり4.0㎡
宇土市：人口1人当たり5.2㎡ ← 30%過剰
```

#### 年間維持費の増加
```
2016年：年20億円
2021年：年23億円（+15%）
2026年：年26億円（+30%）
2031年：年30億円（+50%）
```

#### 老朽化による追加費用
- 築40年以上の施設：維持費が通常の2~3倍
- 2010～2030年が「老朽化施設の更新ピーク」

### 最適化目標

```
【2026年現在】
延床面積：約60万㎡
年間維持費：26億円

【2036年目標】
延床面積：約48万㎡（20%削減）
年間維持費：18～20億円（25%削減）
```

## 📚 学校跡地の活用戦略

### 跡地活用の基本方針

#### A小学校跡地
**現状：** 市街地、アクセス良好
**活用案：** 子育て支援複合施設
```
1階：認可保育園 + 一時預かり施設
2階：子育て支援センター + 親子交流室
3階：学習支援教室 + 放課後デイサービス
```
**効果：** 雇用20人、子育て家庭への支援強化

#### B小学校跡地
**現状：** 市街地
**活用案：** 新統一校舎（前述）

#### C小学校跡地
**現状：** 農村部、広い敷地
**活用案：** 農産物加工施設 + 地域商社
```
1階：農産物加工施設（ウトマチ商品開発）
2階：販売・事務スペース
敷地：駐車場、農産物検査スペース
```
**効果：** 雇用15～20人、1次産業の6次産業化

#### D小学校跡地
**現状：** 郊外、交通アクセス
**活用案：** テレワークセンター + 関係人口施設
```
機能：
- リモートワークスペース（月5千円程度の利用料）
- 宿泊機能（移住体験者向け）
- カフェ・交流スペース
- 会議室
```
**効果：** 移住促進、関係人口創出

### 統計：跡地活用による経済効果
```
4跡地の活用による：
- 新規雇用：50～60人
- 年間事業売上：3～5億円
- 年間地方税獲得：4千～6千万円
```

## 💧 下水道インフラの計画的更新

### 現在の経営状況（R6年度実績より）

#### 下水道事業の規模
| 項目 | 数値 | 備考 |
|------|------|------|
| **水洗化処理人口** | 26,711人 | 公共下水道 |
| **水洗化戸数** | 11,790戸 | 公共下水道 |
| **普及率（人口）** | 95.6% | 高い普及率 |
| **普及率（戸数）** | 93.3% | 前年+125戸 |
| **施設利用率** | 86.37% | 前年比+2.55pp |
| **負荷率** | 84.94% | 安定稼働 |

**出典**: R06_公営企業会計決算審査意見書（R7.7.4～8.1審査）

#### 危機的状況：敷設年と更新時期
```
1970年敷設（1970年） → 2026年で56年 ← 【更新時期】
1980年敷設（1980年） → 2026年で46年 ← 【近い将来】
1990年敷設（1990年） → 2026年で36年 ← 【準備期】

※注: R6から漁業集落排水施設整備事業を公営企業会計に移行
```

#### 更新が必要な理由（審査意見より）
- 管路寿命：一般的に50年（コンクリート管）
- 劣化症状：破損、沈下、内面腐食
- 広範囲での同時故障リスク
- 事業開始から約50年を迎え、老朽化が進行中

### 20年間の更新計画

#### 年間更新スケジュール
```
2026～2028年：年4.0億円（古い管路の緊急更新）
2029～2035年：年3.5億円（段階的更新）
2036～2045年：年3.0億円（新規敷設分の更新）

平均：年3.5億円を20年間持続
```

#### 財源確保の内訳（例：2027年）
```
市の一般財源：1.5億円（市債を除く）
国庫補助金：1.5億円（L4で確保）
ふるさと納税：0.5億円（下水道枠）
───────────
合計：3.5億円
```

### 効率化施策

#### 低需要地区での廃止検討
```
対象：市街地から3km以上、かつ利用世帯10以下の地区

廃止による効果：
- 更新投資削減
- 単独処理浄化槽への転換（利用者負担）
```

#### 管路検査の実施
```
2026年から、CCTV調査により劣化状況を可視化
→ 優先度付けの精密化
→ 効率的な更新順序の決定
```

## 🌉 道路・橋梁の老朽化対応

### 橋梁の現状

#### 老朽化状況
```
総橋梁数：150橋
築後40年以上：35橋（23%）
築後50年以上：15橋（10%）
耐震対応外：40橋（27%）
```

#### 優先度付けの基準
```
【優先度1：緊急補修】
- 交通量500台/日以上
- 築後50年以上
- 劣化が明らかに進行

対象：5～8橋
年間事業費：1.5～2.0億円

【優先度2：改築計画中】
- 交通量100～500台/日
- 築後40～50年
- 機能低下の兆候

対象：10～15橋
年間事業費：1.0～1.5億円

【優先度3：監視継続】
- 交通量100台/日未満
- 築後30～40年
- 現在問題なし

対象：30～40橋
年間事業費：0.5億円
```

### 25年間の更新計画

```
2026～2030年：年2.0億円（優先度1の完了）
2031～2040年：年1.5億円（優先度2の段階的対応）
2041～2050年：年1.0億円（優先度3の順序対応）

累計投資額：約40～50億円（市債・補助金活用）
```

## 🏗️ その他の重要インフラ

### 上水道（R6年度の経営分析）

**現状（R06_公営企業会計決算審査意見書より）：**
- 給水人口: 31,259人（前年+22人）
- 給水戸数: 13,966戸（前年+252戸）
- 給水普及率: 88.9%（人口）, 88.1%（戸数）
- 施設利用率: 89.88%（前年比+1.43pp）
- 配管の経年化（平均年齢35年）
- 更新が段階的に進行中
- 水質・安定供給：全国平均以上

**経営指標（R6）：**
| 指標 | 数値 | 評価 |
|------|------|------|
| 総収益 | 657.2百万円 | 前年比99.77% |
| 総費用 | 582.3百万円 | 前年比99.16% |
| 経常利益 | 74.9百万円 | 黒字（営業利益0.3%） |
| 水道料金収入 | 625.0百万円 | 総収益の87% |
| 受水費 | 271.4百万円 | 総費用の43.48% |
| 減価償却費 | 128.5百万円 | 総費用の20.59% |

**課題（審査意見より）：**
- 事業開始から約70年による施設老朽化
- 管渠・建築構造物・機械設備の老朽化が進行中
- 小規模だが漏水等が頻繁に発生
- 老朽化対策と経営健全化の同時推進が必須

**対応：**
- 下水道と並行して更新スケジュール化
- 年1.0～1.5億円を継続投資
- 事業開始から約70年で施設寿命に接近中

### 道路舗装

**現状：**
- 市道約500km（推定）
- 舗装率：約70%
- 劣化路線：約20%（優先補修対象）

**対応：**
- 優先度付け（交通量×劣化度）
- 年1.0～1.5億円を継続投資
- 20年で主要路線の全面更新達成

## 📊 L5実装による総合効果

### 施設面積の推移

```
2026年：60万㎡
  ↓ 学校統廃合（フェーズ1）
2029年：58.5万㎡
  ↓ 学校統廃合（フェーズ2）
2036年：54万㎡
  ↓ その他施設整理（複合化・廃止）
2045年：48万㎡（20%削減達成）
```

### 維持費の削減効果

```
2026年：26億円（年間）
  ↓ 施設削減による削減
2036年：20.5億円（21%削減）
  ↓ 継続的効率化
2045年：18～19億円（27%削減）
```

### 市民生活への影響

#### ポジティブ効果
- ✅ 新しい学校施設による教育環境向上
- ✅ 子育て支援施設の整備
- ✅ 産業拠点の形成
- ✅ 若年層の移住受け入れ環境整備

#### 調整項目
- 統廃合に伴う通学距離増加（スクールバス等で対応）
- 学校跡地周辺の遊休地解消（活用計画で対応）
