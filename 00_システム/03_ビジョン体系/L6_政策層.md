# L6 政策レイヤ（Policy Layer）

## レイヤの役割

L6は、L0からL5までで整理した制約、事実、課題、組織、財源、インフラを、市民生活に届く政策へ変換する層。

政策を単独の施策として並べるのではなく、下位レイヤの根拠と上位のビジョンを接続する。

```
L0-L2: 現実と課題
L3: 実行組織
L4: 財源
L5: インフラ
  ↓
L6: 政策パッケージ
  ↓
L7: 選ばれるまち
```

## 基本方針

- 課題起点で政策を設計する
- 政策ごとに財源、実行組織、評価指標を持つ
- 子育て、教育、産業、移住を分断せず連動させる
- 施設統廃合や財政制約を前提に、サービス品質を高める

## 政策設計テンプレート

政策を追加するときは、最低限以下を記録する。

| 項目 | 内容 |
| --- | --- |
| 対応課題 | どのL2課題を解くか |
| 実行主体 | どのPFUまたは担当組織が動くか |
| 財源 | L4のどの財源を使うか |
| インフラ | L5のどの施設・仕組みを使うか |
| KPI | 何をもって成果とするか |
| 関連OS | どの機能OSと連動するか |

## 優先順位

### 1. 財政制約に直結する政策

- 公共施設再編
- 学校統廃合と跡地活用
- 自主財源化につながる産業政策

### 2. 人口減少を緩和する政策

- 子育て支援の品質向上
- 教育環境の再設計
- 空き家と仕事を組み合わせた移住支援

### 3. 市民参加を高める政策

- RMOを通じた地域運営
- PFUによる課題別参加
- 議会・行政・市民が同じ構造で議論する仕組み
