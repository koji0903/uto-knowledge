## 🎯 レイヤの役割

**お金の調達と配分のOS。税収だけに依存しない、多元的で持続可能な財源確保体制を構築。**

### L4の戦略的位置づけ
```
L3（PFU形成）
    ↓
L4（財源確保）← ← ← 「課題を解く力」を金銭化
    ↓
L5（インフラ投資）
```

---

## 🔍 背景：なぜこの戦略が必要なのか

**詳細な分析は [[L4L5_facility_finance_crisis]] を参照。**

ここでは概要を示す：

```
公共施設の老朽化は避けられない物理的現実。
40年間の必要更新費用：940億円 = 年均23.6億円

ところが、現在の宇土市が積み立てられるのは：9.2億円/年

年間不足額：14.4億円 = 毎年、未来へのツケを積み重ねている
```

この不足を埋めるために、以下4つの財源戦略が必須。

|------|--------|--------|------------|------|
| **実質赤字比率** | ― | ― | 13.30% | ✅ 健全 |
| **連結実質赤字比率** | ― | ― | 18.30% | ✅ 健全 |
| **実質公債費比率** | 12.0% | 11.6% | 25.0% | ✅ 健全 |
| **将来負担比率** | **0.0%** | ― | 350.0% | ✅ 健全 |

**出典**: R06_財政健全化判断比率審査意見書（宇土市監査委員、審査期間R7.7.4～8.1）

### 一般財源の推移と見通し

```
年度    実績/見込み    増減
━━━━━━━━━━━━━━━━━━━━━━
2016年  50.0億円       基準年
2021年  48.5億円       -1.5億円（-3%）
2026年  46.0億円       -4.0億円（-8%）※予想
2031年  44.0億円       -6.0億円（-12%）※予想
2036年  42.0億円       -8.0億円（-16%）※予想
```

**R6年度実績** (決算カード等より):
- 歳入総額: 225.9億円（前年比-12.6%）
- 一般財源等: 104.5億円（経常一般財源ベース）
- 実質単年度収支: -6.7億円（赤字、前年-23.1億円から改善）

### 課題

**①歳入が減る**
- 人口減少 → 市民税減少
- 企業数減少 → 法人税減少
- 高齢化 → 所得減少

**②歳出が増える**
- 社会保障費が年3~5%増加（人口減の一方で高齢化率は上昇）
- インフラ老朽化対応費が増加

**③投資的経費が圧迫される**
```
2026年の使途（46億円）
社会保障費：16.5億円（36%）
人件費：14.0億円（30%）
公債費：5.0億円（11%）
━━━━━━━━━━━━━
小計：35.5億円（77%）
投資的経費：残り10.5億円（23%）

しかし必要投資額は23.6億円
→ ギャップ：13.1億円/年
```

## 🎯 L4の対策：4つの財源戦略

### 戦略1：外部資金OS（国庫補助金の毎年スキャン）

#### 仕組み
- **現状** - 各部局が個別に補助金申請（申請率は低い）
- **改善** - 企画課が全国の補助金制度を毎年スキャン、市の課題とマッチング

#### 対象となる主な補助金
| 補助金 | 金額 | 対象事業 |
|-------|------|--------|
| 地方創生交付金 | 年2～3億円 | 移住促進、産業振興 |
| 公共施設最適化事業 | 年0.5～1.5億円 | 施設統廃合、複合化 |
| 下水道補助 | 年0.5～1.0億円 | 管路更新 |
| 学校施設整備 | 年0.2～0.5億円 | 統廃合に伴う新校舎 |
| 道路特例交付金 | 年0.5～1.0億円 | 橋梁改築 |
| **合計** | **年4～7億円** | - |

#### 実現のステップ
1. **企画課に「補助金スカウト専任」を配置**（年1人）
2. **年1回、全補助金制度をリスト化**（300～400件）
3. **市の課題とのマッチング分析**
4. **各PFUへの提案**（「この補助金は学校統廃合に使える」など）
5. **申請支援と進捗管理**

#### 期待される効果
- **現在の申請率** - 市が活用できる補助金の約30%
- **目標申請率** - 60～70%へ向上
- **増加額** - 年2～3億円の追加確保

---

### 戦略2：ふるさと納税「課題解決枠」

#### 仕組み
- **現状** - ふるさと納税は「地域の特産品返礼」で獲得（年3～4億円）
- **改善** - 寄付金を「課題解決」に振り当て、明確な成果報告

#### 課題解決枠の例

```
【子育て支援枠】寄付金1万円 → 認定こども園の新設に充当
  返礼品：育児サポートチケット（市内での託児利用券）

【学校統廃合枠】寄付金3万円 → 新校舎建設に充当
  返礼品：「新しい学校の校歌CD」「開校記念品」

【産業振興枠】寄付金5千円 → 地域商社の商品開発に充当
  返礼品：「完成した商品」（農産物加工品など）

【空き家活用枠】寄付金5万円 → リノベーション支援に充当
  返礼品：「リノベーション工事の設計図」「完成写真」
```

#### 期待される効果
- **現在** - ふるさと納税年3～4億円
- **目標** - 年5～6億円（2～3年で達成）
- **追加効果** - 「課題解決への参加」という市民の満足度向上

---

### 戦略3：ふるさと納税「返礼品強化」による増加

#### ウトマチ百貨店ブランドの活用

**現在の課題：**
- ふるさと納税の返礼品が「地場産品の低付加価値」に留まっている
- 全国の自治体と競争できていない

**改善案：**
```
1次産品 → 6次産業化（加工） → ウトマチ百貨店ブランド → 返礼品化

例：
宇土市産米（単価2千円/10kg）
  ↓
「ウトマチプレミアム米」（単価5千円/5kg）
  ↓
ふるさと納税返礼品として全国展開
  ↓
年間5千箱販売 → 2.5億円の売上（ふるさと納税手数料は10~15%）
```

#### 実現のステップ
1. **地域商社の立ち上げ**（L3産業振興PFUと連携）
2. **宇土市の1次産物の6次産業化**（加工、パッケージング）
3. **ウトマチ百貨店ブランド化**
4. **ふるさと納税サイトでの掲載**
5. **全国販売開始**

#### 期待される効果
- **ふるさと納税増加** - 年5~6億円へ
- **地元産業活性化** - 1次産業従事者の所得向上
- **雇用創出** - 加工・販売で年5~10人の新規雇用

---

### 戦略4：稼ぐ公共施設（レベニュー確保）

#### 公営住宅の有料化・複合化

**現状：**
- 公営住宅は原価割れの家賃設定
- 空き家が多い（入居率70%程度）
- 管理コストが増加

**改善案：**
```
従来型（単機能）：公営住宅のみ → 赤字
改善型（複合化）：1階に認可保育園 + 2~3階に公営住宅
  ↓
保育園利用料（2.5万円/月）× 30人 × 12月 = 9百万円/年
公営住宅家賃（5万円/月）× 40戸 × 12月 = 2.4億円/年
  ↓
施設複合化による維持費削減：30%削減
  ↓
年間1.5～2.0億円のレベニュー確保
```

#### 駐車場有料化

**導入箇所：**
- 市役所駐車場（月額5千円 × 200台）
- 中央図書館駐車場（200円/2時間）
- 体育館駐車場（月額3千円 × 100台）

**期待される効果：**
- **年間レベニュー** - 3千～5千万円
- **付帯効果** - 公共施設への車の過度な流入を緩和

#### 施設の有料利用拡大

**現在の使用料体系の見直し：**
- 図書館会議室：無料 → 有料化（300円/2時間）
- スポーツセンター利用料：割引 → 適正化
- 公民館利用料：廃止 → 有料化（500円/時間）

**期待される効果：**
- **年間レベニュー** - 2千～3千万円
- **利用効率化** - 「使わない」利用者の削減

## 📊 L4財源戦略の総合効果

### 4つの戦略の組み合わせ

```
現在の一般財源：46.0億円
   ↓
追加施策による増加：
  外部資金OS：+2.0億円
  ふるさと納税強化：+1.5億円
  地域商社収益：+0.5億円
  施設レベニュー：+0.5億円
─────────────────
新たな一般財源：50.5億円

財政ギャップ（従来）：13.1億円/年
施設削減による節約：5.0億円/年（面積20%削減）
─────────────────
残余ギャップ：3.1億円/年 → 5～7年で解消可能
```

## 🔗 L4と他レイヤーの関連

### 各PFUへの財源配分モデル

```
【学校統廃合PFU】
- 需要額：年2.0億円（新校舎建設初期費用）
- 財源：公共施設最適化補助金（1.0億円）
       + ふるさと納税「学校統廃合枠」（1.0億円）

【施設最適化PFU】
- 需要額：年1.5億円（各施設の改築・廃止）
- 財源：外部資金OS（0.8億円）
       + 施設レベニュー（0.7億円）

【産業振興PFU】
- 需要額：年0.5億円（地域商社立ち上げ）
- 財源：地方創生交付金（0.5億円）

【移住・空き家PFU】
- 需要額：年0.3億円（リノベーション補助）
- 財源：ふるさと納税「空き家活用枠」（0.3億円）
```

## 💡 市民への説明方法

### 「財源戦略の見える化」

従来的説明：
> 「市の財政が厳しいので、施設を削減します」

宇土OS的説明：
> 「現在の46億円の一般財源を、以下の施策で50.5億円に増やします：
> 1. 外部資金OS（国庫補助金スキャン）：+2.0億円
> 2. ふるさと納税強化（地域商社商品化）：+1.5億円
> 3. 地域商社経営：+0.5億円
> 4. 施設レベニュー：+0.5億円
>
> これにより、施設削減（5.0億円節約）と組み合わせて、
> 持続可能な財政基盤を作ります」
