## 📌 コンセプト

**宇土市の課題を「8層構造＋機能OS」で体系化・実装するためのナレッジベース**

- **層構造**：L0（前提）→ L1（事実）→ L2（課題）→ L3（組織）→ L4（財源）→ L5（インフラ）→ L6（政策）
- **機能OS**：RMO OS、子育てOS、教育OS、産業OS、移住・定住OS、ウトマチ百貨店 等
- **実装フォーム**：議会活動、政策実行カード、財政分析、農業DSS、データリンク 等
