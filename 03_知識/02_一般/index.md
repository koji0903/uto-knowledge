### **L2 課題レイヤ - 「なぜダメなのか」の構造**

[[00_システム/03_ビジョン体系/L2_issue_layer|L2 課題レイヤ]]

農業・産業の衰退の根本原因：

```
農産物が「商品化されすぎ」
  ↓
同一品質 = 同一価格（差別化不可）
  ↓
所得向上できない
  ↓
後継者がいない、若年層転出
  ↓
地域経済の衰退スパイラル
```

---

### **L3 組織レイヤ - 「誰がやるのか」**

[[00_システム/03_ビジョン体系/L3_organization_pfu|L3 組織レイヤ - PFU設計]]

市庁舎を横断して課題を解く組織設計：

**PFU** = Project Fusion Unit（プロジェクト融合ユニット）

| PFU | 役割 | 例 |
|-----|------|-----|
| **学校統廃合PFU** | インフラ最適化 + 教育質向上 | L5インフラ → L6政策 |
| **施設活用PFU** | 跡地を産業・子育て支援に転用 | L5インフラ → L6産業OS |
| **財源確保PFU** | ふるさと納税・外部資金発掘 | L4財源 → L6全政策 |

---

### **L4 財源レイヤ - 「お金をどこから」**

[[00_システム/03_ビジョン体系/L4_finance_layer|L4 財源レイヤ]]

14億円の赤字を埋めるための多元的財源戦略：

| 財源 | 手段 | 規模 |
|------|------|------|
| **内部改革** | 施設統廃合、人員最適化 | 年 2～3億円削減 |
| **ふるさと納税** | 農産物・返礼品戦略 | 年 5～10億円 |
| **産業創出** | ウトマチ百貨店・地域商社 | 年 1～1.5億円配当 |
| **外部資金** | 国庫補助、企業版ふるさと納税 | プロジェクト毎 |

**財政危機の正体**:
[[00_システム/03_ビジョン体系/L4L5_facility_finance_crisis|施設老朽化と財政危機分析]]
- 学校・庁舎・上下水道 の同時老朽化
- 補助金の急減
- 地元産業の衰退に伴う税収減

---

### **L5 インフラレイヤ - 「施設をどう配置」**

[[00_システム/03_ビジョン体系/L5_infrastructure_layer|L5 インフラレイヤ]]

限られた資源で最大の効果を生む施設配置：

**統廃合の考え方**：

```
現在: 学校5校（児童650人）
  → 将来: 学校2校（児童500人）
  → 1学年 80～120人
  → クラス替え・グループ学習が可能

現在: 公共施設 60万㎡、年維持費 26億円
  → 将来: 48万㎡（20%削減）、年維持費 18～20億円
  → 「質は維持、量は選別」
```

**跡地活用**：
- 学校跡地 → 子育て支援複合施設 / テレワークセンター
- 庁舎移転跡 → 産業施設 / 交流拠点

### **RMO OS - 「市民が主体で運営する」**

地域運営組織による市民参画・自治実現：

[[00_システム/03_ビジョン体系/rmo_os_specification|RMO OS 仕様書]]  
[[00_システム/03_ビジョン体系/rmo_os_implementation|RMO OS 実装ガイド]]  
[[00_システム/03_ビジョン体系/rmo_os_use_cases|RMO OS ユースケース]]

**RMOとは**：

```
自治会 + PTA + 商工会 + 農業組合 + 福祉委員会 の
「統合された市民主体の地域運営体」

市政の「下請け」ではなく「パートナー」として
地域課題を自治的に解決する
```

**具体例**：

| 地域課題 | RMO の役割 |
|---------|----------|
| 統廃合した学校跡地利用 | 地域ニーズ把握 → 施設設計への参画 |
| ウトマチ百貨店の企画 | 地元農産物の発掘 → 品質管理 |
| 移住受け入れ | ご近所づきあい → 地域コミュニティへの受け入れ |

### **L7 ビジョンレイヤ - 「2040年、こうなりたい」**

[[00_システム/03_ビジョン体系/vision_uto_os|2040年の宇土市像（Vision_uto_os 最終章）]]

```
【人口維持】
定住人口：3.0万人（2026年 3.6万人から17%減）
  +
交流・関係人口：年数千人～数万人

「活力ある小規模都市」へのシフト
```

**実現方法**：

| 時期 | 目標 |

## 📊 層構造の全体関係

```
L7: ビジョン（2040年、縮むのではなく選ばれるまち）
   ↑
   目指す状態
   ↓
L6: 政策（教育OS、産業OS、移住OS、RMO OS）
   ↑
   実行組織
   ↓
L5: インフラ（施設統廃合、効率化）
   ↑
   資金確保
   ↓
L4: 財源（ふるさと納税、産業創出、施設売却）
   ↑
   誰がやるか
   ↓
L3: 組織（PFU設計、市民参画）
   ↑
   何をするか
   ↓
L2: 課題（なぜ衰退するのか、構造的原因）
   ↑
   現在地の理解
   ↓
L1: 事実（資産・人材・インフラの棚卸し）
   ↑
   前提条件
   ↓
L0: 前提（人口減・財政危機・地理的制約）
```

## 💡 使用例

### 「新しい政策立案をしたい」
1. L0 前提で「本当の制約」を確認
2. L1 事実で「使える資源」を確認
3. L2 課題で「本当の問題」を分析
4. L3 組織で「実行体制」を検討
5. L4 財源で「予算源」を確認
6. L5 インフラで「物理的配置」を検討
7. L6 政策で「実装内容」を設計
8. L7 ビジョンで「2040年への貢献」を確認
