# MCP 設定

Claude、Gemini、ChatGPT などの AI クライアントから Vault を参照するための設定を置く場所。

## 注意

- 実設定に秘密情報を入れない
- 作業前に `AGENTS.md` と `tmp/ai_context.md` を確認する
- クライアント別の例は `clients/` を参照する
- AI の役割定義は `ai_profiles/` を参照する
- 別AIへ作業を渡す場合は `ai_profiles/handoff_prompt.md` を使う
