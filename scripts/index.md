# 自動化スクリプト

検証、生成、同期、Firestore / Google Drive 連携のスクリプトを置く場所。

## 入口

- `start_work.sh`: 作業開始チェック
- `end_work.sh`: 作業終了チェック
- `maintenance_check.sh`: ローカル / フルメンテナンス
- `validate_vault.sh`: Vault 構造検証

## 注意

スクリプト名は他の設定から参照されるため変更しない。
