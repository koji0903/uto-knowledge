# ChatGPT統合ダッシュボード

## 目的

ChatGPT由来の知識を、宇土OSのどの領域に接続するかを確認する入口。

現在のVaultでは、詳細ログよりも宇土OS本体の構造化を優先しているため、このノートは統合状況の索引として扱う。

## 接続先

| 領域 | 主な接続先 |
| --- | --- |
| 行政・政策 | [[L6_policy_layer]], [[vision_uto_os]] |
| 議会・市政 | [[04_データリンク/01_議会活動/index]] |
| 産業・地域商社 | [[industry_os]], [[utomachi_100_store_specification]] |
| 技術・AI運用 | [[mcp/index]], [[mcp/ai_profiles/task_router]] |

## 運用メモ

- ChatGPTから得た重要知識は、単独で溜めずに宇土OSの各レイヤへ接続する
- 体系化できない断片は、一時的にInboxまたは該当領域の索引へ置く
- 重要な判断は意思決定ログとして記録する
