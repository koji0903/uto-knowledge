## 1️⃣ 海苔養殖シーズンの定義

### 📅 **シーズン期間**

```
┌─────────────────────────────────────────────────────────────────┐
│ 海苔養殖シーズン（1年間）                                       │
├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│  秋季: 9月～10月      → 種付け・苗床準備                         │
│  冬季: 11月～2月      → 成長・最盛期（収穫主体）                │
│  春季: 3月～4月       → 春のり・シーズン終盤                     │
│  夏季: 5月～8月       → オフシーズン（整備・準備）               │
│                                                                   │
└─────────────────────────────────────────────────────────────────┘
```

### 🗓️ **シーズン表記法**

```
シーズン表記: YY-YY形式 (前年度-当年度)

例:
  2025-26シーズン = 2025年9月 ～ 2026年4月
  2026-27シーズン = 2026年9月 ～ 2027年4月
  
数値参照:
  開始年月: 202509（2025年9月）
  終了年月: 202604（2026年4月）
```

### 📊 **各フェーズの特性**

| フェーズ | 期間 | 月数 | 重点 | 主要活動 |
|---------|------|------|------|---------|
| **種付け・準備** | 9月～10月 | 2ヶ月 | リスク評価 | 水温・栄養塩監視、病害予測 |
| **成長・冬季本格** | 11月～2月 | 4ヶ月 | 最大収穫 | 赤潮検出、品質管理、収穫推奨 |
| **春のり・終盤** | 3月～4月 | 2ヶ月 | 品質維持 | 水温上昇対応、シーズン終了準備 |
| **オフシーズン** | 5月～8月 | 4ヶ月 | 維持管理 | 施設整備、翌シーズン準備 |

**合計:** 12ヶ月 = 1シーズン

### 🔄 **データ切り分けロジック**

```python
def assign_to_season(date: str) -> str:
    """
    日付をシーズンに割り当てる
    
    例:
    2025-09-01 → "2025-26"
    2025-12-15 → "2025-26"
    2026-02-28 → "2025-26"
    2026-04-30 → "2025-26"
    2026-05-01 → "2026-27" (オフシーズン開始)
    2026-09-01 → "2026-27"
    """
    import datetime
    
    date_obj = datetime.datetime.strptime(date, "%Y-%m-%d")
    year = date_obj.year
    month = date_obj.month
    
    # 9月～12月: 前年度から始まるシーズン
    if month >= 9:
        return f"{year}-{year+1}"
    # 1月～8月: 前年度9月から始まるシーズン
    else:
        return f"{year-1}-{year}"
```

## 🔟 実装上の注意点

### ⚠️ **重要な考慮事項**

#### 1. **オフシーズン期間のデータ**
```
Q: 5月～8月のオフシーズンデータをどうするか？

A: 
  - シーズン前年の末尾（3-4月）に含める
  - または別途 "off_season_YYYY" フォルダで管理
  - 環境モニタリングは継続（次シーズン予報用）
```

#### 2. **跨年シーズン識別**
```
SQL WHERE句の例:
  WHERE (month >= 9 AND year = 2025) 
     OR (month < 5 AND year = 2026)
  
この場合は season = '2025-26'
```

#### 3. **月ごとのサブシーズン分析**
```
シーズン内の月別分析:
  phase_preparation: 9月-10月（2ヶ月）
  phase_main_winter: 11月-2月（4ヶ月） ← 最重要
  phase_spring_nori: 3月-4月（2ヶ月）
```
