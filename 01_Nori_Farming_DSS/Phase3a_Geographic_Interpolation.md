## 🧮 補間計算方法

### ハバーサイン公式（Haversine Formula）

2地点間の大円距離を計算：

```python
def haversine_distance(lat1, lon1, lat2, lon2):
    R = 6371  # 地球の半径（km）
    lat1, lon1, lat2, lon2 = map(radians, [lat1, lon1, lat2, lon2])
    dlat = lat2 - lat1
    dlon = lon2 - lon1
    a = sin(dlat/2)² + cos(lat1) × cos(lat2) × sin(dlon/2)²
    c = 2 × asin(√a)
    distance = R × c
    return distance
```

### 逆距離加重補間（Inverse Distance Weighting）

```
重み = 1 / 距離
正規化重み = 重み / Σ全重み

補間値 = Σ(観測値 × 正規化重み)
```

**利点:**
- 近い観測地点ほど大きく寄与
- 計算が単純で透明性が高い
- 複数パラメータに対応可能

## 📈 精度・信頼性

### 精度レベル

```
🟢 高精度（距離 < 10km）
   └─ 河内（三角まで 4.84km）

🟡 中精度（距離 10-20km）
   ├─ 松尾（熊本まで 11.23km）
   └─ 沖新（岱明まで 12.75km）

🔴 低精度（距離 > 20km）
   └─ なし
```

### 信頼性への考慮

- **地形による影響**: 有明海沿岸の地形変化を全て反映できるとは限らない
- **季節変動**: 地形による影響は季節により変わる可能性
- **改善案**: 実際にそれぞれの地点でデータ取得できれば、補間を廃止可能
